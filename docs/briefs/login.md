## 1. 누가, 무엇을

본인 한 명이 작업실을 열 때 지나가는 문이다. 하루에 한 번도 안 볼 수 있다(7일 유지). 오는 때는 셋이다.
- 처음 계정을 만든 직후, 또는 7일 넘게 쓰지 않은 뒤 북마크한 작업 화면을 열었을 때.
- 다른 브라우저·기기에서 처음 열 때.
- 쓰는 중 세션이 끝나 화면 안내의 '로그인'을 눌렀을 때.

## 2. 결과와 증거

- 성공은 이메일·비밀번호를 넣고 Enter 한 번에 원래 열려던 화면에 돌아가는 것이다. 다른 선택지가 없다.
- 실패는 판 안 한 줄로 이유를 알리고 입력은 남긴다(비밀번호 칸만 비우고 포커스).
- 소유자가 아닌 계정은 무엇을 할 수 없는지와 빠져나갈 버튼 하나(로그아웃)만 본다.

## 3. 방향

- **메뉴 없는 빈 바탕 위 판 하나.** 본문 바탕(옅은 회색) 가운데 흰 판(카드 반경·그림자는 DESIGN.md 카드 그대로), 폭 360px(390px 화면에서는 좌우 16px 여백). 세로로는 화면 가운데보다 조금 위(위쪽 여백이 아래보다 작다).
- **판 안 위에서 아래로:** 글자 로고 "TTS Pilot"(사이드바와 같은 굵은 글자, 아이콘 없음) → 한 줄 회색 "본인 계정으로 로그인해 주세요." → 이메일 칸 → 비밀번호 칸 → 오류 한 줄(있을 때만) → '로그인' 버튼(판 폭 꽉, 기본 `Button`). 그 아래 링크는 없다.
- **칸:** 라벨은 칸 위에 보이는 글자('이메일', '비밀번호'). 이메일 `type=email`, `autocomplete=username`, 첫 포커스. 비밀번호 `autocomplete=current-password`. 비밀번호 보기 버튼은 두지 않는다.
- **보내는 중:** 버튼 안 `Loader2` 회전 + "로그인 중", 잠금. 칸도 잠그지 않는다(값만 유지).
- **오류:** 판 안 버튼 바로 위 경고색 글자 한 줄 `role="alert"`, 아이콘 없음. 문구는 스펙 5.1.
- **접근 권한 없음:** 같은 판. 로고 → 제목 "접근 권한 없음"(18px 굵게, `break-keep`) → "{이메일} 계정은 이 작업실을 쓸 수 없어요."(이메일은 굵게, 길면 줄바꿈 `break-all`) → '로그아웃' 버튼(neutral, 판 폭 꽉). 로그아웃 중 "로그아웃 중" 잠금.
- **메뉴 아래 줄(공통 틀):** '로컬 관리자' 글자 자리에 이메일(14px 회색, 한 줄 말줄임, `title`에 전체). 그 오른쪽에 '로그아웃' 아이콘 버튼(`LogOut`, 툴팁·접근 이름 "로그아웃"), 맨 오른쪽 테마 버튼. 보이는 순서와 Tab 순서는 이메일(포커스 없음) → 로그아웃 → 테마. 768~1199px 아이콘 사이드바에서는 이메일 글자를 숨기고(지금 '로컬 관리자'처럼 화면 낭독기에만) 두 아이콘을 세로로 둔다. 767px 이하 더보기 안 줄도 같은 순서.
- **세션 만료 안내(화면마다 쓰는 안내 하나):** 지금 루프백 안내 자리에 같은 모양. 아이콘 `LogIn`, "로그인이 끝났어요. 다시 로그인해 주세요." + 밑줄 링크 '로그인'.
