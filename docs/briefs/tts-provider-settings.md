# 공급자별 생성 설정과 제작 도구

- **대상과 모드:** 개인 콘텐츠 제작자의 기존 HTML 작업실. Operate. 2026-09-26 사용자 요청에 따라 속도/형식만 있는 설정을 양사 공식 API 기능으로 확장한다. 기존 HTML 우선 개발 방식과 Wanted/Pretendard를 유지한다.
- **성공 장면:** 성우 → 지원 모델 → 전달 방식/세부 설정 → 출력 확인 → 프리셋 저장. 모델을 바꾸면 지원하지 않는 설정이 전송 대상에서 빠지고 이유가 보인다. 모든 API 요청 필드는 설정 컨트롤, 대본/성우 선택, 서버 자동 처리, 별도 기능 중 한 곳에 매핑한다.
- **구조:** 작은 떠 있는 팝오버를 편집기 안의 넓은 생성 설정 영역으로 바꾼다. 현재 모델/핵심 설정 요약과 펼치기 버튼은 항상 보인다. 기본 설정, 감정·표현, 발음·문맥·재현성의 고급 설정으로 묶고 상세 항목은 점진적으로 연다. 모델 미지원·계정 조건·문서 확인 필요를 구분한다. 모바일에서는 한 열로 흐르고 대본/생성 버튼을 가리지 않는다.
- **연결 흐름:** 대본 맞춤 추천, 내 목소리 복제, 감정 자동화, 목소리 찾기, 보이스 체인저, 대본 가져오기/화자 감지를 작업실에서 찾을 수 있게 만든다. API 직접 지원 기능과 앱이 별도로 분석/편집해야 하는 기능을 구분한다. 후속 제작 도구는 명확히 표시한 설계 시연이며 원문을 몰래 바꾸거나 실제 업로드/과금 요청을 하지 않는다.
- **범위:** 이번에는 HTML 설정 조작·모델 조건·프리셋/생성 스냅샷 연결과 제작 도구 흐름을 구체화한다. 실제 API·파일 변환·문단 합성·추천 엔진은 이후 단계다. Vrew 상세 조사와 자막 편집기 확장은 사용자의 다음 요청을 기다린다. 기존 숫자 교정/대본 저장/클론 시연은 보존한다.

## 상호작용 계약

1. 설정은 공급자·모델별로 구분해 보관하며 모델 전환 때 적용 범위를 명시한다. 프리셋은 단순 요약 문자열 대신 구조화한 값을 복원한다.
2. Typecast의 자동/기본 감정/스마트 지시 등은 API의 조건에 맞는 상호 배타적 모드로 제시한다. Eleven v3와 v2의 컨트롤이 같다고 가정하지 않는다.
3. 고급 필드에 사람이 이해할 수 있는 이름·설명·범위·기본값을 제공한다. 인증 헤더, 서버 로깅 정책, 내부 요청 ID는 일반 사용자 슬라이더로 노출하지 않는다.
4. 설정을 바꾸면 기존 결과는 이전 설정의 결과로 표시한다. 잘못된 숫자·범위·필수값·상호 배타값은 생성과 프리셋 저장 전에 막는다.
5. 샘플 청취, 시험 생성, 생성 결과 재생은 구분한다. UI 시연에서는 실제 음성이 재생되거나 API로 전송됐다고 표시하지 않는다.
6. 추천은 이유와 후보 비교 후 선택, 감정 자동화는 제안 검토 후 적용, 가져오기는 화자·문단 미리보기 후 확정 흐름이다. 정확도 퍼센트·무료·복제 소요 시간은 검증되지 않은 수치를 사용하지 않는다.

## 근거와 검증

공식 API 필드의 정본은 `docs/research/typecast-api-options.md`, `docs/research/elevenlabs-api-options.md`. 첨부 화면과 공개 소개 페이지는 기능 발견/배치의 근거이며 API 지원을 증명하지 않는다. 1440/390px, 키보드, 모델 전환, 옵션 상한, 초기화, 전체 설정 프리셋 복원, 이전 결과 판정으로 검증한다.
