# 성우 캐스팅 페이지

2026-09-29 사용자 요청과 선택(보관함 유지, 추가·제거는 분류와 즐겨찾기, 시험 생성은 성우 하나씩, 나머지는 브리프대로): Typecast 보이스 캐스팅처럼 성우를 먼저 고르는 별도 페이지를 둔다. 이 페이지에서 대본을 넣어 들어 보고, 공급자 분류로 찾고, 채널·카테고리·타입으로 거르고 넣고 빼는 등 성우 중심으로 처리한다. 모드는 Operate이고 기존 Wanted/Pretendard 세계를 유지한다. HTML 프로토타입에 반영하며 실제 공급자 API는 부르지 않는다.

## 참고: Typecast 보이스 캐스팅 (2026-09-29 로그인 상태에서 관찰, 크레딧 사용 없음)

- 맨 위에 검색이 있고 "스타일 묘사 또는 이름"으로 찾는다. 그 아래 필터 줄에는 언어·성별·연령층 드롭다운과 콘텐츠 빠른 칩(다큐멘터리·오디오북·뉴스 리포터·아나운서·라디오/팟캐스트)이 있다. `필터`를 누르면 대화상자가 열리고 언어·연령층·성별·콘텐츠·신규 조건과 "731개 보이스 보기" 버튼이 나온다.
- 첫 화면은 인기, 보이스 카테고리(숏폼·아나운서·다큐·사투리·중년 묶음), 전체 보이스(731) 순서다. `전체 보기`를 누르면 목록만 보인다(`?view=all`).
- 목록 행에는 캐릭터 그림, 이름, `신규`, `#용도 | 체험 | 한국어+5`가 나온다. 오른쪽 끝에 북마크와 `사용하기`가 있다.
- 행을 누르면 기본 샘플이 재생되고 하단 재생 막대가 뜬다. 막대에는 성우, 정지, 랜덤 선택, 북마크, 사용하기가 있다. 재생은 한 번에 하나다.
- 북마크 목록은 오른쪽 위 팝오버에 뜨고, 그 안에서 재생하고 해제한다.
- 이 화면에는 내 대본으로 들어 보는 기능이 없다. 그 확인은 에디터에서 생성해야 한다.
- 가져오지 않는 것:
  - 설명으로 찾기: 추천 API의 비용이 확인되지 않았다.
  - 캐릭터 그림.
  - 인기·카테고리 묶음·신규·체험·커스텀은 처음에 뺐다가 사용자 요청으로 API가 주는 만큼 넣었다(아래 "수정 1").

## 수정 1: 인기·콘텐츠별 묶음과 신규·체험·커스텀 필터 (2026-09-29 사용자 요청)

요청: "공급자가 제공하는 인기, 카테고리 별 성우 구분도 API 에서 제공해주면 이렇게 잘 구분해서 배치해서 보여주면 좋을거같아", "콘텐츠 필터와, 신규, 체험, 커스텀 구분 필터도 추가되면 좋을거같아". API가 주는 것만 쓴다. 공식 문서는 2026-09-29에 재확인했다.

| 항목 | Typecast `GET /v3/voices` | ElevenLabs `GET /v1/shared-voices` | Fish Audio `GET /model` |
|---|---|---|---|
| 인기 | 없음 | `sort=trending`(인기 급상승) | `sort_by=score`(점수 순) |
| 콘텐츠(카테고리 묶음) | `use_cases` 13종. Typecast 화면의 '콘텐츠' 13개와 같다 | `use_cases` | 없음. 대신 `tag` |
| 신규 | 없음 | 응답 `date_unix` | 응답 `created_at` |
| 체험 | 없음 | 응답 `free_users_allowed`(무료 플랜 사용 가능) | 없음 |
| 커스텀 | `voice_type=custom` | 계정 성우 | `self=true` |

- 커스텀은 공급자 목록을 쓰지 않는다. 모든 사용자가 서버 키 하나를 같이 써서 남의 클론이 섞이기 때문이다(tts-provider). 앱이 기록한 내 클론·연결 보이스만 거르고, 용어사전대로 칩 이름을 `내 보이스`로 붙인다.
- '카테고리'는 용어사전에서 내 분류(채널·카테고리·타입)의 이름이다. 그래서 공급자 묶음은 `콘텐츠별 성우`로 부르고, 필터 이름도 `용도`에서 Typecast 화면과 같은 `콘텐츠`로 바꾼다(성우 선택 창·보관함 포함).
- 신규는 공개 뒤 30일 이내다. 프로토타입은 기준일을 2026-09-29로 고정한다.

배치:
- 검색, 공급자 탭 아래 조건을 세 줄로 둔다.
  1. 콘텐츠: 펼친 칩. 성우가 많은 값부터 6개를 보이고, `더보기 N`·`접기`로 나머지를 연다. Fish Audio 탭에서는 이름이 `태그`다.
  2. 공급자 분류: 드롭다운 칩(성별·연령·언어·모델·억양)과 켜고 끄는 칩(신규·체험·보증 성우만). 공급자가 주지 않는 칩은 그 탭에 나오지 않는다. 전체 탭에서 켜면 그 정보가 없는 공급자는 빠지고, 기존 안내 줄로 알린다.
  3. 내 분류: 채널·카테고리·타입과 `내 보이스`. 내 보이스는 앱 기록이라 이 줄에 두고, 이 줄의 `조건 해제`로 함께 푼다.
  - 켜고 끄는 칩의 설명(예: "무료 플랜에서도 쓸 수 있는 성우")은 사용자 말로 쓰고, 스크린리더에는 aria-describedby로 준다.
  - 767px 이하는 조건 줄을 `조건` 토글 뒤로 접고, 토글은 검색 칸 옆에 둔다.
- 조건이 하나도 없으면(검색어 없음, 보기 전체) 목록 위에 둘러보기를 둔다. 조건을 고르면 둘러보기는 사라지고 목록만 남는다(Typecast `전체 보기`와 같은 흐름).
  - 인기: 공급자마다 인기 기준이 달라(인기 급상승, 점수 순) 한 번에 한 공급자만 보인다. 제목 옆 칩(`ElevenLabs · 인기 급상승`, `Fish Audio · 점수 순`)으로 바꾼다. 카드 6장은 한 줄로 두고 가로로 넘겨 본다. 카드는 샘플 재생과 선택 버튼이다. `모두 보기`는 그 공급자 탭으로 옮기고 그 정렬을 건다. Typecast 탭에는 카드 대신 "Typecast 목록 API에는 인기 순이 없어요."를 둔다.
  - 콘텐츠별 성우: 성우가 많은 콘텐츠 6개를 세 칸 타일로 둔다. 타일에는 성우 이니셜 3개(1279px 이하는 숨김), 이름, 인원, `›`가 있다. 누르면 그 콘텐츠 조건이 걸리고 포커스는 목록 첫 행으로 간다.
  - 결과 줄에 `전체 성우 N명` 제목을 붙이고 목록이 온다.
  - 목록 첫 행이 첫 화면에 보여야 한다(2026-09-29 critique P1: 1440 첫 행 y=1115 → 763).
- 767px 이하: 인기 카드와 콘텐츠 타일 모두 한 줄 가로 넘김이고, 인기 공급자 칩도 한 줄로 넘긴다.
- 내 보이스가 0명일 때 켜면 빈 상태에 "아직 내 보이스가 없어요"와 `내 보이스로 가기`를 보인다.

## 할 일과 대상

- 대상은 채널 콘텐츠를 만들기 전에 성우를 정하는 1인 제작자다. 후보를 좁히고, 같은 대본으로 비교해 들어 보고, 고른 성우를 내 채널·카테고리·타입에 넣어 두고, 작업실로 가져간다.
- 성공 기준: 이 흐름을 페이지를 떠나지 않고 끝낸다. 필터로 찾기 → 샘플이나 내 대본으로 듣기 → 분류에 넣기 → 작업실에서 사용.

## 구성

- **위치**: 내비의 `성우 보관함` 위에 `성우 캐스팅`을 새로 둔다. 주소는 `#casting`이다. `성우 보관함`은 분류를 정리하는 목록으로 그대로 둔다(2026-09-29 사용자 선택: 둘 다 둔다). 캐스팅은 찾기·듣기·고르기를 맡는다.
- **배치**:
  - 1024px 이상: 왼쪽에 목록, 오른쪽에 성우 패널을 둔다.
  - 1023px 이하: 성우 패널은 기존 오른쪽 드로어로 연다.
  - 모바일: 성우 패널을 전체 화면으로 연다.
- **목록 위 조건**:
  - 검색. 공급자에 맞춘 안내 문구는 이번 라운드의 것을 그대로 쓴다.
  - 공급자 탭(전체·Typecast·ElevenLabs·Fish Audio). 각 탭에 성우 수를 표시한다.
  - 공급자 분류 줄. 이번 라운드의 드롭다운 칩을 재사용한다.
  - 내 분류 줄. 채널·카테고리·타입을 같은 드롭다운 칩 모양으로 둔다.
  - 보기(전체·즐겨찾기·자주 사용)와 정렬.
- **목록 행**:
  - 이니셜, 이름, 공급자, 공급자 분류 요약, 내 분류 태그를 보여 준다.
  - 행 안에 두 버튼을 둔다. 하나는 기본 샘플 재생·정지이고, 다른 하나는 즐겨찾기 별이다.
  - 행을 누르면 성우 패널에 그 성우가 뜨고, 선택한 행을 강조한다.
  - 목록에는 유료 동작을 두지 않는다.
- **성우 패널**(선택한 성우 하나에 집중):
  1. 머리: 이름, 공급자, 공급자 분류 칩, 설명.
  2. 듣기:
     - `기본 샘플`을 재생한다. 과금이 없다.
     - `내 대본으로 듣기`를 둔다. 대본 칸은 작업실 첫 문단으로 채우고, `저장 대본 불러오기`도 제공한다. 칸 옆에 글자 수(Fish Audio는 UTF-8 바이트)와 예상 사용량을 표시한다. `시험 생성` 버튼은 누를 때만 요청한다.
     - 결과는 "성우 + 대본"별로 남는다. 다시 들어도 다시 부르지 않는다. 대본을 바꾸면 기존 결과에 "이전 대본"을 표시한다.
     - 대본 칸은 페이지 전체에 하나다. 성우를 바꿔도 같은 대본이 유지되어 비교하기 쉽다.
  3. 내 분류:
     - 채널·카테고리·타입마다 붙은 칩을 보여 주고, `×`로 뺀다.
     - `+ 추가`는 검색해서 고르거나 새로 만든다. 기존 분류 편집기의 동작과 저장소를 쓴다.
     - 즐겨찾기와 자주 사용을 켜고 끄는 토글, 메모 칸을 둔다.
  4. 하단 고정: 주 버튼 `작업실에서 사용`. 동작은 기존 보관함의 작업실 사용과 같고, 작업실 성우로 선택된다.
- **작업실 연결**: 작업실 성우 선택 창에 `성우 캐스팅에서 찾기` 링크를 둔다.
- **재생**: 샘플과 시험 생성 결과를 통틀어 한 번에 하나만 재생한다(REQ-03). 다른 것을 재생하면 앞의 것은 멈춘다.

## 상태와 범위

- 목록 결과가 0명이면 기존 빈 상태와 조건 해제를 쓴다. 전체 탭에서 조건 때문에 빠진 공급자는 이번 라운드의 안내 줄로 알린다.
- 시험 생성의 상태:
  - 준비: 대본이 비었거나 상한을 넘으면 버튼을 비활성하고 이유를 보여 준다. 상한은 200자다(사용자 확인).
  - 요청 중: 버튼을 잠근다.
  - 완료: 결과를 재생할 수 있다.
  - 실패와 처리 여부 미확인: 기존 `시연 모드`에서 결과를 골라 본다.
  - 프로토타입은 음성을 만들지 않고 상태만 시연한다.
- 분류 저장에 실패하면 성공으로 표시하지 않는다(기존 규칙).
- 가상 성우는 이번 라운드의 21명을 그대로 쓴다.

## 범위 밖

- 실제 API 호출, 페이지 나눔, 설명으로 찾기, 캐릭터 그림. 인기 카드의 좌우 넘김(`모두 보기`가 대신한다).
- 공급자 북마크 연동. 즐겨찾기는 앱 기록이다.
- ElevenLabs 공유 성우를 계정에 추가하는 호출. 공급자 상태를 바꾸는 호출이고 필요 여부도 확인되지 않았다.
- 여러 성우에 같은 대본으로 한 번에 시험 생성하기(사용자 선택: 성우 하나씩).

## 검증

- 1440·1024·390·320에서 가로 스크롤이 없다.
- 키보드: 행 → 패널 → (드로어면) Esc로 행에 돌아간다. 팝오버 동작은 이번 라운드와 같다.
- 한 번에 하나만 재생되고, 시험 생성은 누른 횟수만큼만 시연된다.
