# 공급자별 성우 필터

2026-09-29 사용자 선택: "HTML 프로토타입에 반영". 모드는 Operate, 기존 Wanted/Pretendard 세계를 유지한다. 실제 공급자 API는 부르지 않는다.

## 할 일과 근거

- 문단 카드의 성우 칩으로 연 성우 선택 창, 또는 성우 보관함에서 성우를 찾는다. 공급자가 실제로 주는 조건으로 좁혀 원하는 성우를 빨리 고르는 것이 목표다.
- 조건은 공급자 목록 API의 조회 조건만 쓴다(2026-09-29 공식 문서 재확인).
  - Typecast `GET /v3/voices`: `gender`, `age`(child·teenager·young_adult·middle_age·elder), `use_cases`(13종), `model`. 이름 검색·언어·페이지 나눔 없음.
  - ElevenLabs `GET /v1/shared-voices`: `search`, `language`, `gender`, `age`, `accent`, `use_cases`, `sort`(최신·사용량·인기 급상승·클론 수). 30~100개씩.
  - Fish Audio `GET /model`: `title`, `tag`, `language`, `licensed`, `sort_by`(점수·사용량·최신). 1~100개씩.

## 구성

- 공급자 탭(전체·Typecast·ElevenLabs·Fish Audio)은 그대로 둔다. 그 아래 필터 줄을 늘 보이게 둔다. 접힌 "상세 조건"은 없앤다.
- 필터 줄은 조건마다 드롭다운 칩이다(`성별 ▾` `연령 ▾` `용도 ▾` …). 누르면 팝오버에 선택지 칩이 나오고, 고르면 칩이 `성별 · 여성`처럼 바뀐다. 선택이 있으면 줄 끝에 `초기화`가 나온다.
- 공급자를 고르면 그 공급자 API에 있는 조건만 나온다.
  - 전체: 성별, 연령, 용도, 언어
  - Typecast: 성별, 연령, 용도, 모델
  - ElevenLabs: 성별, 연령, 용도, 언어, 억양, 정렬
  - Fish Audio: 언어, 태그, 보증 성우, 정렬
- 선택지 값은 그 탭에 보이는 성우에서 뽑는다(실제 앱에서는 API 응답과 문서 enum).
- 전체 탭에서 조건을 고르면 그 정보를 주지 않는 공급자의 성우는 빠진다. 조건 줄 아래 안내 줄에 "Fish Audio는 성별 정보가 없어 빠졌어요"와 그 공급자 탭으로 가는 버튼을 보인다(2026-09-29 critique 반영).
- 검색창 안내 문구를 공급자에 맞춘다. Typecast는 이름 검색만 되고, 설명으로 찾기는 기존 추천 도구로 안내한다.
- 성우 보관함 페이지에도 같은 필터 줄을 둔다.
- 가상 성우를 공급자별 8명 안팎으로 늘리고 필드를 API 응답 모양(성별·연령·용도·언어·억양·태그·모델·보증 여부)에 맞춘다.

## 범위 밖

- 실제 API 호출, 페이지 나눔과 더 보기, 캐시.
- 공급자 쪽 커스텀 목록(Typecast `voice_type=custom`, Fish Audio `self`, ElevenLabs 계정 성우). 공용 서버 키라 남의 클론이 섞인다. 내 클론은 기존대로 앱 기록으로만 보인다.
- 신규·체험·인기·카테고리 묶음(API에 없음). 2026-09-29 사용자 요청으로 API가 주는 만큼 넣었다: 신규(ElevenLabs `date_unix`, Fish Audio `created_at`), 체험(ElevenLabs `free_users_allowed`), 인기·콘텐츠별 묶음(성우 캐스팅). 필터 줄의 `용도`는 `콘텐츠`로, 커스텀은 앱 기록의 `내 보이스`로 붙였다. 자세한 내용은 `docs/briefs/tts-voice-casting.md`의 "수정 1"을 본다.
- 채널·분류 필터(내 분류), 즐겨찾기·자주 사용·정렬(최근 사용) 선택은 그대로 둔다.

## 상태와 검증

- 같은 조건 안은 OR, 조건 사이는 AND(기존 규칙). 결과 0명이면 기존 빈 상태와 초기화.
- 공급자를 바꾸면 새 공급자에 없는 조건의 선택은 해제하고 알린다.
- 검증: 1440·1024·390·320 가로 스크롤 0, 키보드(칩 → 팝오버 → Esc로 칩 복귀), 팝오버가 화면 안, 드로어 안 포커스, 콘솔 오류 0, `TTSParagraphs._selfTest` 실패 0. 실제 API 호출 0.
