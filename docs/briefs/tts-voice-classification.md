# 성우별 채널·분류 연결

2026-09-26 사용자 승인: 성우별 태그 지정 + 별도 채널·분류 항목 관리 조합을 기존 HTML에 적용한다. 모드는 Operate, 기존 Wanted/Pretendard 유지. bts-ui → impeccable context는 같은 세션 실행 결과를 재사용한다.

## 사용자 흐름

- 성우 보관함에서 공급자와 성우를 확인하고 채널·카테고리·타입을 구분한 태그를 본다. 미분류는 명확히 표시한다.
- `분류 편집`은 데스크톱 오른쪽 패널, 모바일 전체 화면으로 연다. 세 그룹마다 검색/다중 선택/바로 추가를 제공한다. 저장 전 선택은 초안이며 취소/ESC는 성우 연결을 바꾸지 않는다. 항목 추가는 목록 생성 동작임을 알린다.
- 별도 관리 화면에서 항목 추가/이름 변경/삭제와 연결된 성우 수를 본다. `성우 보기`는 보관함의 해당 필터로 이동한다. 이름은 변경돼도 연결은 유지하고 삭제는 연결만 해제한다.
- 성우 보관함 및 작업실 선택 목록에서 채널·카테고리·타입 필터를 적용한다. 공급자와 보기(전체/즐겨찾기/자주 사용)는 독립이며 같은 그룹 다중 선택은 OR, 그룹 사이는 AND다.
- 즐겨찾기와 자주 사용은 분류 태그와 별도 버튼이다. 프리셋은 생성 설정이며 태그가 아니다.

## 상태와 저장 계약

분류 항목은 이름과 별개인 고정 ID, 성우 연결은 공급자+성우 ID로 구분한다. 중복 이름·공백 이름은 막는다. 이 HTML에서는 분류/연결/즐겨찾기/자주 사용을 브라우저 로컬에 보존한다. 저장 실패면 성공으로 표시하지 않고 기존 데이터와 초안을 보존한다. 실제 DB·로그인·실 API는 연결하지 않는다. 새로고침 시 등록한 분류와 성우 연결을 복원하며 손상된 로컬 데이터는 안전하게 초기화 안내한다.

## 범위와 검증

이번 대상은 성우 연결이다. 저장 대본·프리셋의 분류 편집과 채널 기본 프리셋, 다중 성우 일괄 분류는 후속이다. 기존 숫자 교정·생성 옵션·클론 시연을 보존하며 메타데이터 없는 새 클론도 미분류로 표시한다.

검증: 양사 성우 다중 연결, 취소/ESC, 중복 추가, 이름 변경 후 연결 유지, 삭제 후 성우 보존, 필터 AND/OR·초기화, 관리→성우 보기, 새로고침, 저장 실패, 1440/390px·키보드·포커스 복귀·긴 이름.
