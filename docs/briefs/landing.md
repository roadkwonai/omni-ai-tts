- **방문자:** 포트폴리오로 링크를 받고 온 사람(채용 담당자, 개발자). 처음 보는 서비스이고 로그인할 수 없다. 1분 안에 "무엇을 하는 서비스이고, 어떻게 만들었는지"를 알고 싶다.

## 2. 결과와 증거
- 성공: 방문자가 첫 화면에서 '기능 둘러보기'를 눌러(또는 스크롤해) 실제 화면 투어를 끝까지 본다.
- 증거는 사실만 쓴다: 실제 스크린샷, 연동 공급자 다섯, 자동 테스트 수(빌드 때 실제 값), 설계 결정(ADR) 링크 대신 요약. 후기·고객 로고·사용자 수는 없으므로 넣지 않는다.

## 4. 카피 후보 (A5)
- **헤드라인(고르기):**
  1. 성우 찾기부터 음성 파일까지, 다섯 공급자를 한 작업실에서
  2. 대본 한 편, 성우 다섯 곳, 작업실 하나
  3. 한국어 음성을 만드는 개인 TTS 작업실
- **부제:** 성우를 미리 듣고 담아 두고, 대본의 숫자 발음을 검수한 뒤 문단마다 다른 성우로 음성을 만들어 받습니다. 혼자 쓰는 개인 작업실입니다.
- **주 버튼:** 기능 둘러보기 · **보조:** 로그인
- **증거 한 줄:** Typecast · ElevenLabs · Fish Audio · Airy · Gemini 연동 · 자동 테스트 {빌드 때 실제 수}개
- 금지어(B8: 혁신·강력한·손쉽게 등)와 꾸민 수치를 쓰지 않는다.

- 이미지(`/gpt-image`, 여러 안을 보여 드리고 고름): 로고(심볼 + 'Omni AI TTS' 글자), 마스코트(음파·마이크 캐릭터, 히어로·3단계·FAQ·마지막 섹션·404 포즈), README 배너(840 폭), og 이미지(1200×630), 파비콘·앱 아이콘, 스크린샷을 참조한 소개 이미지(기기 틀·기능 묶음). 생성 이미지는 실제 화면처럼 꾸미지 않는다. 실제 화면은 스크린샷 그대로.

## 6. 상호작용과 모션 (보조 animation, emil `animate` 판정 순서)
- **동작(UI SDK `@ui-sdk/react`):** 기능 투어 탭(화살표 키 이동·자동 활성화·ARIA), FAQ 펼침(키보드·`aria-expanded`), 휴대폰 메뉴 패널(포커스 가두기·Esc 닫기·포커스 복귀).
- **판정:** 랜딩은 방문자가 드물게 처음 보는 화면이라 delight 예산이 있다. 다만 투어 탭·FAQ·버튼은 한 방문에 여러 번 누르므로 짧고 절제한다. 무한 반복(Float·Pulse·Idle)과 패럴랙스는 쓰지 않는다.

- **곡선 토큰(새로, `globals.css`):** `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`, `--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1)`, `--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1)`(animate 스킬 표 값). 앱의 색 전환 기본(`cubic-bezier(0.3,0,0,1)` 150ms)은 그대로 쓴다. 임의 Tailwind 값 대신 이 토큰을 쓴다.
- **Never ship(animate):** `transition: all`, `scale(0)`, UI에 `ease-in`, hover 모션을 `@media (hover: hover) and (pointer: fine)` 밖에서, 레이아웃 속성 애니메이션(아코디언 높이 예외), 모든 요소 동시 등장.
- DESIGN.md의 "모션은 색 전환 하나" 규칙은 랜딩에 한해 위 모션을 더하는 것으로 고친다(정본 갱신 때 덮어쓰기 전에 확인).
