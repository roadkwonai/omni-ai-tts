# gowith 로그인 조사 반영 — 문단 작업실 브리프

2026-09-28. 근거: [gowith 로그인 작업실 전수 검토](../research/gowith-studio-logged-in-review.md), 현재 HTML 격차 목록(18개 중 없음 7, 일부 11). 사용자 요청: “유용한 기능은 모두 먼저 UI/UX로 설계하고, 기능으로 구현할 수 있게 배치”. Operate 모드, 기존 Wanted 토큰과 Pretendard 유지. 실제 API·과금·서버 저장은 하지 않는 HTML 시연이다.

## 1. 일과 사용자

본인 한 명이 여러 채널의 한국어 음성을 반복 제작한다. 대본은 한 덩어리 낭독부터 여러 화자의 대화까지 다양하다. 지금 HTML은 한 덩어리 대본에는 강하지만 문단 계획이 읽기 전용이다. 그래서 문단마다 성우·속도·간격·감정을 바꾸거나, 문단을 나누고 합치거나, 전체를 듣고 내려받는 흐름을 한 화면에서 끝낼 수 없다.

## 2. 결과와 증거

- 대본을 문단으로 나눈 뒤 **문단 카드**에서 성우·역할·속도·간격·감정·연기 지시를 바로 고치고, 예상 길이와 예상 사용량을 문단마다 본다.
- 여러 문단을 골라 **일괄 작업**(성우·속도·간격 변경, 분할, 합치기, 삭제)을 하고 되돌릴 수 있다.
- **하단 작업 바**에서 전체 요약(문단 수·글자·예상 길이·사용량)을 확인한 뒤 생성·재생·내려받기를 한다.
- 새로고침이나 초기화로 작업을 잃지 않는다(**복구 창**, **초기화 선택지**, **프로젝트 보관함**).
- 확인 기준: 1440px와 390px 모두에서 위 흐름을 키보드만으로 끝낼 수 있다. 모든 과금 가능 동작은 시연 표기를 달고 생성 확인을 거친다.

## 3. 방향

- **구조 논지:** 작업실을 “한 덩어리 대본”과 “문단 작업”의 두 상태로 만든다. 문단으로 나누면 문단 카드 목록이 편집의 주인이 되고, 원문 칸은 문단을 이어 붙인 읽기 전용 보기로 바뀐다. 이때 `문단 해제하고 직접 편집`으로 언제든 돌아갈 수 있다. 숫자 발음 검수는 두 상태 모두에서 이어 붙인 대본을 대상으로 하므로, 문단을 고치면 검수를 다시 받는다.
- **초점:** 문단 카드 목록의 위쪽에 붙어 따라오는 일괄 작업 막대, 화면 아래에 고정된 작업 바.
- **gowith에서 가져오고 고치는 점:** 클릭 가능한 `span` 대신 버튼을 쓰고, `prompt()` 입력 대신 그 자리의 숫자 입력을 쓴다. 삭제는 되돌리기로 복구할 수 있다. 칩은 입력한 내용을 덮어쓰지 않고 덧붙인다. 추천은 후보마다 근거를 따로 보여 준다. 모바일에서도 일괄 작업과 요약에 닿을 수 있다.

## 5. 상태와 범위값

- 문단: 0개(한 덩어리 상태), 1~200개. 문단당 1~2,000자, 긴 문단 줄바꿈 확인. 화자 0~10명.
- 선택: 0개(일괄 버튼 비활성과 이유), 일부, 전체. 합치기는 2개 이상이 있어야 한다.
- 예상 길이: 한국어 기준 초당 약 6.6자를 속도로 나눈 값에 문단 뒤 간격을 더한다. 추정치라고 표시한다.
- 예상 사용량: Typecast·ElevenLabs는 전송 글자 수, Fish는 UTF-8 바이트와 문서 단가를 쓴다. 실제 청구는 연결 후 확인이라고 표시한다.
- 결과: 없음, 생성 중, 완료(시연 재생 대상), 이전 대본으로 만든 결과, 응답 유실, 공급자 오류(기존 상태 유지).
- 프로젝트: 없음, 1~N개, 저장 실패(로컬 저장소 차단). 복구 초안 있음/없음.
- 녹음: 권한 전(장치 목록 대신 “기본 마이크”), 권한 거부, 장치 없음, 녹음 중 레벨, 시간 초과로 자동 정지.

## 6. 상호작용과 배치

- **데스크톱:** 성우 패널 | 편집 패널(원문/발음 탭) 아래에 문단 작업 영역이 전폭으로 온다. 일괄 막대는 문단 목록 위쪽에 붙어 따라오고, 작업 바는 화면 아래에 고정된다. 작업 바 때문에 문단 카드의 마지막 줄이 가려지지 않게 한다.
- **문단 카드:** 윗줄은 식별(번호·역할·성우), 둘째 줄은 본문, 셋째 줄은 조절(속도·간격·감정·지시), 오른쪽은 행동 버튼이다. 행동 버튼은 아이콘과 접근 가능한 이름을 가진다. 좁은 폭에서는 조절 줄이 두 줄로 접힌다.
- **모바일(390px):** 일괄 막대는 선택이 있을 때 아래쪽 작업 바 위에 나타나는 시트가 된다. 작업 바는 요약 한 줄과 생성 버튼으로 줄고, 요약은 누르면 펼쳐진다. 터치 대상은 44px 이상이다.
- **되돌리기:** 삭제·합치기·분할·일괄 변경은 알림에 `되돌리기`를 두고, 작업 기록은 최대 20단계까지 남긴다.
- **대화상자:** 역할 배정, 분할, 합치기 확인, 복구, 새로 시작, 사용법만 모달이다. 빠른 메뉴와 내려받기는 제자리 팝오버로 연다.

## 7. 제약과 열어 둔 결정

- 정적 HTML·기존 전역 모듈 방식, 새 기능은 기능별 JS/CSS 파일을 추가한다. 로컬 저장은 `tts-pilot.prototype.*` 이름공간에 텍스트와 설정만 저장하고, 음성 파일과 키는 저장하지 않는다.
- 키보드: 모든 조작이 버튼·입력이다. 포커스는 대화상자를 닫으면 연 자리로 돌아온다. 변경은 `live-region`으로 알린다.
- 공급자별 지원 차이: ElevenLabs·Fish는 감정 강도를 비활성하고 이유를 보여 준다. 속도 범위는 공급자 공통 0.5~2.0으로 표시하되, 모델 설정의 실제 범위를 넘으면 경고한다.
- 결정 필요 없음으로 가정: 문단 모드의 발음 검수 대상은 이어 붙인 대본, 기존 헤더의 `음성 만들기`는 하단 작업 바로 이동.
