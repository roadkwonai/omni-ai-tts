# gowith 로그인 조사 반영: 문단 작업실 브리프

2026-09-28 첫 판을 2026-09-29에 구조 개정했다.

**개정 근거**
- critique 24/40: `.impeccable/critique/2026-09-29T00-45-48Z__docs-prototypes-tts-studio-index-html.md`
- gowith 반영 감사: 68개 기능 가운데 반영됐지만 숨은 것이 28개, 약하게 반영된 것이 10개였다.
- 사용자 피드백: "HTML UI/UX를 보니 별로 반영된 게 없다."

**원인**
- 기능은 코드에 들어갔지만 gowith의 배치 원리, 즉 "첫 화면이 곧 문단 작업대이고 문단마다 조절이 늘 보인다"를 옮기지 않았다.
- 새 방문자의 첫 화면에는 문단 카드가 0장이다. `문단으로 나누기`를 두 번 눌러야 카드가 생기고, 그 카드도 y=1395px(1.5화면 아래)에서 시작한다.
- 카드 한 장이 256px로 gowith(약 70px)의 3.7배다.

**사용자 결정** (2026-09-29)
- 문단 카드를 기본 작업면으로 삼는다.
- 성우 목록은 문단의 성우 칩에서 여는 드로어로 옮긴다.
- 범위는 P0~P1 구조 개편과 todo 누락 9건 등록이다.

Operate 모드이고 Wanted 토큰과 Pretendard를 유지한다. 실제 API·과금·서버 저장은 하지 않는 HTML 시연이다.

## 1. 일과 사용자

본인 한 명이 여러 채널의 한국어 음성을 반복 제작한다. 대본은 한 덩어리 낭독부터 여러 화자의 대화까지 다양하다. 제작자는 문단마다 성우·속도·간격·감정이 어떻게 잡혀 있는지 **한눈에 비교하고** 고친 뒤, 전체 길이와 예상 사용량을 확인하고 생성한다.

## 2. 결과와 증거

- **첫 화면에 핵심 영역이 다 보인다.** 새 방문자가 1440×900으로 처음 열면 스크롤 없이 다음이 보인다.
  - 문단 카드 4장 이상
  - 일괄 작업과 AI 보이스 도구
  - 작업 요약
  - 생성 버튼
- **카드가 작다.** 카드 한 장은 데스크톱 약 100px(요약 줄과 본문 두 줄), 390px에서 약 140px이다. 성우·역할·예상 길이·속도·간격·감정 값은 칩으로 늘 보인다.
- **성우를 고르는 패턴은 하나다.** 성우 칩 ▾ 빠른 메뉴에서 "전체 성우에서 찾기"를 누르면 드로어가 열린다. 일괄 성우, 역할 성우, 새 문단 기본 성우를 바꿀 때도 같은 드로어를 연다.
- **키보드로 끝까지 할 수 있다.**
  - 카드 한 장의 탭 정지점은 3개(선택, 조절 툴바, 본문)다.
  - 1440과 390 모두에서 키보드만으로 분할 → 성우 지정 → 생성 → 내려받기 흐름을 끝낸다.
- **이미 반영한 기능을 잃지 않는다.** 분할, 합치기, 되돌리기, 역할 창, 추천 근거, 시연 표기, 복구, 프로젝트 보관함, 녹음 가이드, 보이스 디자인이 모두 그대로 동작한다.

## 3. 방향

- **구조 논지: 대본은 늘 문단 카드 목록이다.**
  - 한 덩어리 대본은 카드 1장이다.
  - "한 덩어리 / 문단" 두 상태 모델과 `문단 해제하고 직접 편집`은 없앤다. 대신 `모두 합치기`를 둔다.
  - `문단으로 나누기`는 모드를 바꾸는 버튼이 아니다. 일괄 작업의 `분할`(선택이 없으면 전체가 대상)과 여러 줄을 붙여넣을 때의 제안으로만 쓴다.
- **화면 골격(데스크톱):** 좌측 내비 | 좌측 레일(일괄 작업 + AI 보이스 도구) | 가운데 작업 영역(작업 툴바 + 보기 탭 + 문단 카드) | 우측 레일(작업 요약 + 작업 설정 + 결과) | 하단 작업 바.
- **보기 탭 세 개**로 원문과 발음용 대본을 나누는 제품 원칙을 드러낸다.
  - `문단`: 기본 탭이고 편집하는 곳이다.
  - `원문 전체`: 문단을 이어 붙여 읽기 전용으로 보여 준다. 복사와 `모두 합쳐 한 문단으로`가 있다.
  - `발음용 대본 N`: 기존 숫자 발음 검수다. 이어 붙인 대본이 대상이다.
- **초점:** 문단 카드 목록이다. 시각적으로 강조하는 것은 생성 버튼(primary) 하나와 선택된 카드뿐이다.
- **gowith에서 가져오는 것:** 상시 노출 밀도, 좌측의 일괄 작업과 도구, 우측의 작업 요약, 상단 토글.
- **gowith와 다르게 고치는 것:**
  - 클릭 가능한 `span` 대신 버튼을 쓴다.
  - `prompt()` 대신 그 자리에서 여는 입력을 쓴다.
  - 크레딧 대신 공급자별 글자·바이트 추정치를 보여 준다.
  - 도움말은 비워 두지 않고 실제 동작을 설명한다.
  - 추천 근거는 후보마다 따로 보여 준다.
  - 생성 전의 편집이 과금 생성을 시작하지 않는다.

## 6. 상태와 범위값

- **문단 수:** 1~200개. 0개는 없다. 대본을 비우면 빈 카드 1장이 남는다.
  - 문단당 0~2,000자다.
  - 빈 카드는 생성 대상에서 빠지고, 요약에 "빈 문단 N개 제외"로 표시한다.
- **새 방문자의 첫 로드:** 예시 대본을 마침표 기준으로 나눠 문단 4장으로 연다. 역할은 없다.
- **이전 저장 데이터 호환:** 예전 임시 작업·프로젝트가 한 덩어리 상태(segments 없음)이면 원문 전체를 카드 1장으로 불러온다.
- **선택:** 0개, 일부, 전체.
  - 0개일 때 분할은 전체를 대상으로 하고, 나머지 버튼은 비활성과 사유를 보여 준다.
  - 합치기는 2개 이상을 골랐을 때만 쓸 수 있다.
- **드로어 적용 대상:** 4종이다. 드로어가 열린 동안 대상 문단이 사라지면 드로어를 닫고 그 사실을 알린다.
- **붙여넣기:** 카드 본문에 여러 줄이나 "이름: 대사" 형식을 붙여넣으면 "N개 문단으로 나눌까요?"를 제안한다. 기존 화자 감지와 역할 창 흐름을 재사용한다.
- **대본 가져오기·저장 대본:**
  - `삽입`은 선택하거나 포커스한 문단 뒤에 문단으로 더한다. 그런 문단이 없으면 끝에 더한다.
  - `교체`는 전체를 바꾸고 되돌리기를 남긴다.
- **결과:** 없음, 생성 중, 완료, 이전 대본으로 만든 결과, 응답 유실, 공급자 오류. 오류가 나도 기존 상태는 유지한다.
- **공급자 차이:**
  - ElevenLabs·Fish는 감정 강도를 비활성하고 사유를 보여 준다.
  - 속도 범위는 0.5~2.0으로 표시한다.
  - Fish 사용량은 UTF-8 바이트로 센다.

## 7. 제약과 열어 둔 결정

- **구현 방식:** 정적 HTML과 기존 전역 모듈(`window.TTS*`) 방식을 유지한다. 영역별 파일 분담:
  - `index.html`: 골격
  - `styles.css`: 레이아웃과 반응형
  - `paragraph-studio.js/.css`: 카드, 칩 팝오버, 레일의 일괄 작업
  - `app.js`: 브리지, 성우 드로어, 우측 레일, 작업 바
  - `studio-tools.js`: 도구를 드로어로 열기
  - `project-tools.js`: 복구 배너
- **토큰:** 색·간격·반경은 기존 토큰만 쓰고 새 hex 값을 넣지 않는다.
- **이번에 함께 고칠 코드 검사 지적:**
  - 전역에 `word-break: keep-all`과 `overflow-wrap: break-word`를 둔다. ID·URL처럼 긴 문자열에만 예외를 둔다.
  - `#voice-list`의 `aria-live`를 없애고, 결과 수에만 `role=status`를 준다.
- **접근성:**
  - 카드 요약 줄은 roving tabindex 툴바로 만든다(방향키 이동, Home/End).
  - 드로어는 `showModal`로 열어 포커스가 갇히고, 닫으면 연 자리로 돌아간다.
  - 변경은 `#live-region`으로 알린다.
- **하지 않을 것:**
  - 실제 합성·과금·파일 생성, 크레딧·요금제 화면
  - 성우 얼굴 사진(이니셜 아바타만 쓴다)
  - 단축키 체계와 스포트라이트 둘러보기(P1-16)
  - `prompt()`·`confirm()`의 전면 교체(시간이 되면 한다)
  - 파형·자막·무음 편집기(P2)
  - 로컬 PC 엔진(P4-08), MCP 키(P4-06)
- **결정할 필요가 없다고 본 것:**
  - 감정 자동화는 토글이 아니라 드로어 도구로 둔다. 규칙 기반 제안을 검수하는 흐름을 유지한다.
  - 발음 검수의 대상은 이어 붙인 대본이다.
  - 문단 성우 빠른 메뉴(이 대본에서 사용 중 N곳, 최근 사용)는 팝오버로 유지한다.
