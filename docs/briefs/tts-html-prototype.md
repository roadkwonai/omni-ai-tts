# 개인 음성 작업실 HTML 프로토타입 브리프

- 날짜: 2026-09-26. 사용자 요청: 참고 자료 심층 분석 → HTML로 초기 UI/UX 설계 → HTML 기준 앱 구현 계획. 개인 작업실 우선은 사용자 확정 사항이다.
- 대상: `docs/prototypes/tts-studio/index.html`, `styles.css`, `app.js`. 모드: **Operate**.
- 코드 우선 HTML 제작은 이번 사용자 요청에 따른다. 새 시각 세계를 만들지 않고 `DESIGN.md`의 원티드 스타일을 적용한다. 완성 HTML 자체가 검토할 설계안이며, 실제 Next.js 기능 구현은 다음 단계다.

## 방향 계약

### WORLD

밝은 개인 제작 도구. 흰 편집면, 옅은 회색 작업 배경, 원티드 파란색 선택/주요 행동, 일관된 가는 선. Pretendard 한 가족. 이모지나 가짜 인물 사진 대신 동일 굵기 SVG 아이콘과 이름 이니셜을 사용한다.

### FIRST VIEWPORT

1440px에서 200px 안팎의 내비게이션, 280px 안팎의 성우 탐색 패널, 남은 넓은 대본 편집면. 별도 설정 열을 항상 열지 않고 편집면 상단에 현재 성우/모델, 하단에 교정과 생성 행동을 둔다. 가로 3개 영역 중 대본이 가장 넓다. 화면 위쪽은 작은 작업 제목·채널·저장 상태, 아래쪽은 생성 결과. 랜딩페이지의 히어로/통계/가격 표는 없다.

### SIGNATURE INTERACTION

대본의 숫자를 원문→발음 표기로 비교하고 항목마다 적용·유지·직접 수정한다. 검수를 마친 실제 생성문을 별도 탭에서 확인한다. 원문 편집 후 이전 교정은 무효화한다. 성우의 샘플 청취·선택·즐겨찾기는 독립 행동이다.

### CONTENT AND PROOF

샘플 대본: “2026년 9월 26일, 하루 3분으로 시작하는 경제 이야기입니다. 커피 한 잔은 4,500원. 지난달보다 12.5% 올랐습니다. 오늘은 3가지 변화를 살펴볼게요.” 성우는 Typecast/ElevenLabs별 명시적인 가상 예시다. 결과는 UI 상태 시연이며 공급자 음성·실제 비용·소요 시간을 만들지 않는다.

### INTERACTION AND STATES

- 작업실: 공급자/검색/즐겨찾기 필터, 성우 선택, 대본 수정과 저장/불러오기, 원문/발음용 탭, 검수 패널, 모델 설정, 생성 준비/진행/완료/실패 시연.
- 성우 보관함: 카드 또는 밀도 있는 목록, 카테고리/타입/채널/프리셋 필터, 즐겨찾기·메모·작업실 사용.
- 대본 보관함: 검색, 등록/수정/삭제/복제, 삽입/교체. 로컬 브라우저 저장은 시연용이라는 표시.
- 프리셋: 모델·성우·설정을 저장하고 적용 전 확인. 채널·분류는 별도 관리 화면에서 추가/이름 변경/삭제.
- 내 보이스: 빈 상태·목록·만들기. 공급자/이름 → 녹음 또는 파일 → 원본 확인/동의 → 생성 상태 → 검증 필요/사용 가능. 프로토타입은 샘플 파일/녹음 흐름만 시연하고 서버로 전송하지 않는다.
- 연결 상태: 키값 입력 없이 Typecast/ElevenLabs 미연결 상태, 실제 앱에서 필요한 후속 설정 설명. 개인 정보/팀/결제 메뉴 없음.
- 시험 오디오는 실제 제공사 샘플인 것처럼 재생하지 않는다. 가능하면 UI 흐름만 안내, 완성 결과에도 실제 API 연결 전임을 명시한다.
- 중복 클릭 방지, 빈 입력/2000자 초과 차단, 데이터 없음, 저장 실패 안내, 공급자 실패를 선택 가능한 시나리오로 검토할 수 있게 한다.

### RESPONSIVE AND DELIVERY

390px에서는 상단 메뉴와 작업실/성우/설정 전환으로 한 번에 한 작업에 집중한다. 터치 대상 44px, 입력 라벨, 키보드 포커스, dialog ESC/포커스 복귀, status 알림. 긴 내용에서 가로 스크롤이 생기지 않는다. 상태는 색과 텍스트를 함께 쓴다. Pretendard는 `../../../apps/web/src/app/fonts/PretendardVariable.woff2`를 참조해 repository root의 로컬 정적 서버에서 확인한다.

## 검토 경계

HTML은 디자인·동작 계약이다. 모의 데이터를 사용하는 프로토타입에서 실 공급자 샘플·생성·클론·DB 연동을 완료했다고 하지 않는다. API 키, 실제 음성 파일을 localStorage에 저장하지 않는다. 테스트용 텍스트와 선택 상태만 이름공간을 정해 보관한다. 신규 의존성을 추가하지 않는다.

## 선택 이유와 다른 구조

단계형 마법사는 처음 쓰기 쉽지만 반복 제작 시 화면 전환이 많다. 전체 타임라인 스튜디오는 편집 능력이 넓지만 현재 단일 성우 생성에 불필요하다. **상시 작업실 + 필요할 때 교정/설정 패널**을 이번 시안의 기본으로 채택한다. 미디어 분석에서 새 근거가 나오면 이 문서와 프로토타입에 함께 반영한다.
