## 1. 누가, 무엇을
본인 한 명이 캐스팅에서 맞춘 성우·모델·설정에 이름을 붙여 두고, 다음 방문이나 같은 공급자의 다른 성우에서 다시 쓴다. 오는 때는 셋이다.
- 내 문장으로 들으며 설정을 맞춘 직후(저장)
- 다른 성우를 같은 설정으로 들어 보고 싶을 때(불러오기)
- 이름·채널·채널 기본을 정리할 때(`/presets`, 자주 오지 않는 정리 화면)

## 2. 결과와 증거
- 성공은 저장한 프리셋이 새로 고침 뒤에도 캐스팅 메뉴와 `/presets`에 이름순으로 남고, 불러오면 옵션 칸이 그 값으로 다시 그려지는 것이다. 불러오기 전에 무엇이 바뀌는지 보인다.
- 저장되는 값은 화면에서 들은 값이다(U1). 프리셋 메뉴·창은 소리를 내지 않고 유료 호출을 부르지 않는다. 듣기는 기존 '내 문장 듣기' 버튼이 한다.
- 발견성: 1440·390 첫 방문에서 프리셋 메뉴까지 누르는 횟수를 대조표 21행 증거에 적는다(리뷰 D1).

## 3. 방향
- **설정 바로 옆에 둔다.** 프리셋은 '내 문장 듣기' 설정을 저장하고 적용한다. 그 구역 머리에 메뉴 하나를 두고 저장·불러오기·덮어쓰기·관리 화면 가기를 모은다.
- **불러오기는 비교 창을 거친다.** 바뀌는 값을 보고 누른다. 저장·고치기는 T6 입력 창, 덮어쓰기·지우기는 기존 확인 창이다.
- **`/presets`는 `/classes`와 같은 한 목록이다.** 흰 그릇, 가름선, 오른쪽 44px 아이콘 버튼. 설정 값은 여기서 고치지 않는다.
- **청록은 늘던 곳에만 둔다.** '기본' 배지와 '현재 이용 불가'는 무채색이고, 고칠 일이 있는 상태만 경고색이다.

**승인 시안과 다른 자리.** `t4-casting-audition.png`은 패널 맨 아래(담기 뒤)에 '프리셋' 소제목, '프리셋 적용 ▾' 상자, '지금 설정을 프리셋으로 저장' 글자를 따로 그렸다. 이 구역은 만들지 않고 '내 문장 듣기' 머리의 메뉴 버튼으로 옮긴다.
- 프리셋이 저장·적용하는 값은 바로 아래 옵션 칸이다. 패널 맨 아래에 두면 결과 목록과 담기 칸을 지나야 닿고, 서랍(1199px 이하)과 휴대폰 시트에서는 스크롤 맨 끝이다.
- '내 문장 듣기' 바닥 줄(예상 사용량·듣기 버튼)은 스크롤 칸 바닥에 붙는다(sticky, casting.md 12절 U3). 머리는 이 줄에 가리지 않는다.

## 4. 범위와 만들지 않는 것
포함: 캐스팅 '내 문장 듣기' 머리의 '프리셋' 메뉴와 불러온 프리셋 줄, 저장·불러오기·덮어쓰기 창, `/presets`와 고치기 창·지우기 확인, 앱 메뉴 '프리셋' 열기, `/voices` '프리셋' 보기와 빼기 확인 문구. 만들지 않는 것은 스펙 6절 그대로다. 화면에서 특히 두지 않는 것:
- `/presets`의 설정 값 칸, 재생·듣기 버튼, '캐스팅에서 이 성우 열기'
- 프리셋 검색·필터·정렬 고르기·끌어서 순서 바꾸기, 채널별 묶음
- 메뉴에 다른 공급자 프리셋 보이기(지금 공급자 것만), 다른 공급자 설정으로 바꿔 불러오기
- 다음 방문에 마지막 프리셋 자동 불러오기, 불러온 프리셋 표시를 주소나 저장소에 남기기
- 메뉴 밖 덮어쓰기 지름길(사용자 결정 2)
- `/classes` 채널 행의 기본 프리셋 표시, 작업실의 프리셋 적용(T9), 교정 모드(T11), 내 보이스(T13), 내보내기·가져오기

## 5. 캐스팅 '내 문장 듣기'의 프리셋

**머리 줄.** 왼쪽 굵은 '내 문장 듣기', 오른쪽 묶음 '프리셋 ▾' → '처음 값으로'. 두 버튼 사이는 `gap-2`(8px)다. 붙어 있으면 휴대폰에서 '처음 값으로'를 잘못 눌러 값을 잃는다(critique 2026-10-20).
- '프리셋'은 `Button` outline `lg`(44px) + `ChevronDown`이다. outline은 이 앱의 보조 동작 버튼(청록 경계·글자, 카드색 바탕)으로, 같은 패널의 '새로 만들기'와 같은 위계다. 같은 구역의 '모델 · …' 드롭다운은 값을 고르는 조건 버튼(회색 경계)이고 프리셋은 동작 메뉴라 모양을 나눈다. 리뷰 D1 괄호의 "옅은 경계"는 실제 outline 변형과 다르다. 계획 코드(`variant="outline"`)를 따른다.
- '처음 값으로'는 ghost 회색 그대로다. 설정이 처음 값이 아니거나 불러온 프리셋이 있으면 켜지고, 누르면 불러온 프리셋 줄도 지운다(계획 리뷰 E5).
- 좁으면(320px 시트) 버튼 묶음이 제목 아래 줄로 내려가 왼쪽에 선다.

**불러온 프리셋 줄.** 머리 바로 아래 회색 14px 한 줄 "프리셋 ‘{이름}’". 설정이 그 프리셋과 달라지면 뒤에 " · " + 굵은 진한 글자 '바뀐 값 있음'(D16). 지금 성우가 프리셋의 성우와 다르면(성우가 빠진 프리셋 포함) 그 뒤에 " · " + 회색 `savedVoiceLine`('저장할 때 성우 {이름}', 빠졌으면 '성우를 다시 골라 주세요')을 붙인다. 불러오기는 설정만 적용하므로 같은 공급자의 다른 성우로 옮겨도 줄이 남는데, 그때 어느 성우의 프리셋인지 보이게 한다(critique P1, 2026-10-20). `aria-live="polite"`. 불러오기·저장·덮어쓰기 직후에 생기고, '처음 값으로'·다른 탭에서 지움·화면 떠남으로 사라진다. 공급자마다 하나다. 음수 여백 없이 머리 아래 보통 간격이다.

**메뉴(`DropdownMenu`, 버튼 오른쪽 끝에 맞춤, 폭 `w-72`).** 위에서 아래로:
1. 목록(이 공급자 프리셋, 이름순): 항목은 두 줄이다. 위는 굵은 이름(한 줄 말줄임, 접근 이름에는 전체), 아래는 회색 14px '저장할 때 성우 {이름}'(성우가 빠졌으면 '성우를 다시 골라 주세요'). 목록만 `max-h-80`에서 스크롤하고 그 아래 항목은 늘 보인다(D15). 지금 불러온 프리셋 항목은 오른쪽 끝에 회색 16px `Check`를 두고 접근 이름 끝에 ", 불러옴"을 붙인다(덮어쓰기 항목이 가리키는 프리셋을 목록에서 맞춰 볼 수 있다, critique 2026-10-20).
   - 받아 둔 목록이 없을 때 받는 중: 작은 스피너 + "프리셋 목록을 받고 있어요". 받아 둔 목록이 있으면 그대로 보이고 조용히 다시 받는다(항목이 움직이지 않는다).
   - 없음: 회색 "이 공급자 프리셋이 아직 없어요".
   - 받지 못함: 경고색 "프리셋 목록을 받지 못했어요" + 항목 '다시 받기'(눌러도 메뉴가 닫히지 않는다).
   - 세 상태 줄은 `RadioMenu` 빈 안내와 같은 방식(`DropdownMenuLabel` + 메뉴 설명 `aria-describedby`)으로 메뉴를 열 때 읽힌다.
2. 가름선, '지금 설정으로 새 프리셋 저장'(늘 누를 수 있다).
3. 불러온 프리셋이 목록에 있을 때만 "‘{이름}’에 지금 성우·설정 덮어쓰기"(줄바꿈해 다 보인다).
4. 가름선, '프리셋 관리' + `ArrowRight` → `/presets`. 화면을 떠나는 항목이라 동작 항목과 가름선으로 나누고, 다른 화면으로 가는 링크 문법(화살표)을 쓴다.

**저장 창(`PresetFormDialog`).** 767px 이하는 아래 시트, 768px 이상은 가운데 `max-w-md`. 모양과 동작은 T6 입력 창(classes.md 5절)과 같다.
- 제목 '프리셋 저장'. 그 아래 회색 14px 두 줄: "{공급자} · {성우 이름} · {설정 요약}"(감겨서 다 보인다), "이 성우는 성우 보관함에도 담겨요"(D5).
- 칸 순서: 이름 → 채널 → 기본 체크.
  - 이름: 라벨 '이름', 오른쪽 'N / 40자'(40자를 넘으면 경고색).
  - 채널: 위 글자 라벨 없이 창 폭을 채운 `RadioMenu` '채널 · 채널 없음'(D6). '채널 없음'이 맨 위, 나머지 이름순. 받는 중이거나 받지 못하면 누를 수 없고, 받지 못하면 아래 경고색 "채널 목록을 받지 못했어요".
  - 채널이 하나도 없으면 아래 회색 "채널은 '채널·분류' 화면에서 만들 수 있어요". 링크는 두지 않는다. 캐스팅을 떠나면 쓰던 창과 설정이 사라진다.
  - 기본 체크: 줄 전체가 라벨인 44px 줄(`Checkbox` + '이 채널의 기본 프리셋으로', D7). 채널이 없으면 꺼지고 라벨 글자도 회색(`text-muted-foreground`)이 되며, 아래 회색 "채널을 고르면 켤 수 있어요"가 체크 설명이다(꺼진 줄이 누를 수 있는 줄로 보이지 않게, critique 2026-10-20). 채널을 바꾸면 체크가 풀린다. 고른 채널에 다른 기본이 있으면 아래 회색 "지금 기본 프리셋: ‘{이름}’".
- 버튼 '취소'(outline)·'저장하기'. 휴대폰 시트에서는 가로 반반.

**불러오기 창(`Dialog`, 저장 창과 같은 반응형).**
- 제목 "‘{이름}’ 프리셋을 불러올까요?", 설명 "바뀌는 값"(없으면 "지금 설정과 같아요").
- 지금 성우가 프리셋의 성우와 다르면(성우가 빠진 프리셋 포함) 설명 맨 앞에 진한 14px 한 줄 "지금 성우 {지금 성우 이름}에 설정만 불러와요."를 둔다(`settingsOnly`). 불러오기는 성우를 바꾸지 않는데, 프리셋은 어디서나 '성우 + 설정'으로 보여 성우까지 바뀐다고 믿고 유료 '내 문장 듣기'를 누를 수 있다(critique P1, 사용자 결정 2026-10-20 "문구로 알리기"). 성우가 같으면 붙이지 않는다.
- 창의 설명(`DialogDescription`)은 위 한 줄, '바뀌는 값' 머리, 바뀌는 값 목록, 알림 줄을 모두 감싼다. 화면 낭독기가 창을 열 때 비교 내용과 경고까지 읽는다(덮어쓰기 확인과 같다, critique P2). 저장 창의 요약 두 줄도 그 창의 `DialogDescription`이다.
- 바뀌는 값 목록(14px, `tabular-nums`, 한 줄에 하나, 모델 먼저): "속도 1.0배 → 1.1배"처럼 옵션 칸과 같은 이름이다.
- 그 아래 알림 줄, 이 순서: 성우 맞춤 "모델 ssfm-v30 → ssfm-v21 (이 성우에서 쓰는 값)"(회색) → 성우 다름 "저장할 때 성우 {이름}"(회색) 또는 성우 빠짐 "프리셋의 성우가 보관함에서 빠졌어요"(경고) → 처음 값으로 바뀐 값 "지금 쓸 수 없는 값이 있어 처음 값으로 불러와요: 모델, 감정"(경고). 경고 줄은 `text-warning` + 16px `TriangleAlert`(D14).
- 버튼 '취소'(outline)·'불러오기'(채운 청록). 바뀌는 값이 없어도 '불러오기'는 남는다(불러온 프리셋 줄을 붙인다). 최신 목록에서 다시 찾는 동안 '불러오기' 안 스피너이고 다시 누를 수 없다(U2).

**덮어쓰기 확인(`ConfirmDialog`).**
- 제목 "‘{이름}’ 프리셋을 지금 성우·설정으로 바꿀까요?". 설명은 줄바꿈으로 이은 줄이다. 성우가 다르면 "성우 {프리셋 성우} → {지금 성우}"(프리셋 성우가 비었으면 "성우 없음 → {지금 성우}"), 이어서 바뀌는 설정 값(프리셋 → 지금). 바뀌는 것이 없으면 "지금 설정과 같아요".
- 버튼 '취소'·'덮어쓰기'. **'덮어쓰기'는 `ConfirmDialog`의 위험 동작 색(`destructive`)을 그대로 둔다.** 덮어쓰면 이전 성우·설정을 되돌릴 수 없어 지우기·빼기와 같은 '되돌릴 수 없음' 표시가 맞고, 공용 확인 창도 고치지 않아도 된다. 디자인 리뷰에는 이 항목의 추천이 없다(eng 리뷰 E9가 브리프 항목으로 넘겼다).

**캐스팅 상태**
| 상황 | 표현 |
|---|---|
| 저장·덮어쓰기 성공 | 창 닫힘, 알림, 불러온 프리셋 줄이 그 프리셋. 옵션 칸은 서버가 정리한 값으로 다시 그린다 |
| 불러오기 성공 | 창 닫힘, 옵션 칸 다시 그림, 알림 "‘{이름}’ 설정을 불러왔어요." |
| 불러오기·덮어쓰기 때 이미 지워짐 | 창 닫힘, 알림 "이미 지워졌거나 찾을 수 없어요.", 목록 다시 받음 |
| 이름 비었음·41자, 이름 중복 | 이름 칸 아래 경고색 T6 문구 또는 "같은 이름의 프리셋이 이미 있어요.", 포커스 이름 칸 |
| 저장 중 고른 채널이 지워짐 | 창 유지, 채널 '채널 없음'·체크 풀림, 창 안 "고른 채널이 지워졌어요. 채널을 다시 골라 주세요.", 포커스 이름 칸 |
| 저장·덮어쓰기 실패(그 밖) | 창 유지·입력 보존, 창 안 "저장하지 못했어요. 잠시 뒤 다시 해 주세요." |
| 저장·덮어쓰기 중 | 칸 읽기 전용, 버튼 잠김 + 버튼 안 스피너, 두 번 눌러도 한 번 |
| 소유자 없음 | 캐스팅 전체가 주소 안내라 메뉴가 없다(계획 '스펙과 다른 점' 9) |

## 6. `/presets`

**구성.**
- 페이지 머리(`PageHeader`): 제목 '프리셋', 설명 "자주 쓰는 성우와 듣기 설정을 이름 붙여 두고 성우 캐스팅의 '내 문장 듣기'에서 불러와요. 설정 값은 거기서 고친 뒤 덮어써요." 설정을 어디서 고치는지는 이 설명 한 곳에만 둔다(D18). 머리에 동작 버튼은 없다.
- 본문 폭 `max-w-3xl`(채널·분류와 같다).
- 개수 줄(목록을 받은 뒤 늘 있다): 왼쪽 회색 16px `tabular-nums` "프리셋 N개"(스크립트 포커스 자리, 키보드로 왔을 때만 윤곽), 오른쪽 44px 링크 버튼 '성우 캐스팅으로' + `ArrowRight`. 목록이 비면 링크는 숨는다(빈 상태가 같은 링크를 가진다).
- 채널 목록을 받지 못하면 개수 줄 아래 경고색 "채널 목록을 받지 못했어요" + '다시 불러오기' 한 번. 줄에서는 채널 줄만 빠진다.
- **배치: 한 목록, 이름순**(T6 `byName`, 한국어·숫자 순서. 리뷰 추천 1). 채널별 묶음을 두지 않는다. 채널 없는 프리셋 묶음 머리가 하나 더 생기고 프리셋 수가 적다. 채널별 보기는 T9에서 다시 본다.
- 목록 그릇은 `/classes`와 같다(`boxClass`: 반경 16px, 카드색, 안쪽 경계, 줄 사이 가름선).

**줄(안쪽 16px), 글자 칸 위에서 아래로.**
1. 이름(16px 굵게, 띄어쓰기 없는 긴 이름도 줄바꿈해 다 보인다) + 같은 줄 끝 회색 '기본' 배지(`Badge` secondary, 채널 기본일 때). 이름 줄에 있어 채널 목록이 늦거나 실패해도 흔들리지 않는다(D4).
2. 회색 14px "{공급자} · {성우 이름}". 성우가 비었으면 "{공급자} · 성우 없음".
3. 14px "채널 {채널 이름}"('채널'은 회색, 이름은 진한 글자, 줄바꿈). 채널이 없거나 이름을 아직 모르면 이 줄이 없다.
4. 회색 14px 설정 요약(결과 줄과 같은 `settingsSummary`, 감긴다). 예: "ssfm-v30 · 속도 1.1배 · 감정 기본".
5. 상태 배지(있을 때만, 이 순서): '성우를 다시 골라 주세요'(경고), '현재 이용 불가'(회색, voices.md B6 사용자 결정과 같은 배지), '처음 값으로 바뀐 값 있음'(경고). 경고는 `Badge` warning이다. 글자가 뜻을 말해 색만으로 구분하지 않는다.

**동작 아이콘.** `RowAction` 셋(44px ghost 회색, 툴팁 '고치기'·'복제'·'지우기'): 고치기 `Pencil` → 복제 `Copy` → 지우기 `Trash2`(위험한 것이 맨 끝). 접근 이름 '{이름} 고치기'·'{이름} 복제'·'{이름} 지우기'.
- 640px 이상: 줄 오른쪽. 버튼 가운데를 이름 첫 줄에 맞춘다.
- 640px 미만: 글자 칸 아래에 오른쪽 정렬로 내려간다(D8). 글자 칸이 줄 폭을 다 쓴다.

**고치기.** 저장 창과 같은 창이다. 제목 '프리셋 고치기', 요약 두 줄 없음, 이름·채널·기본이 지금 값으로 차 있다. 성공 알림 "‘{이름}’ 프리셋을 고쳤어요."

**복제.** 창 없이 바로 만든다. 성공 알림 "‘{새 이름}’ 프리셋을 만들었어요."(새 이름 '{이름} 사본', '사본 2'…). 복제 중에 다시 눌러도 한 번이다.
- **새 줄 찾기:** 사본은 이름순 자리(대개 원본 바로 아래)에 들어간다. 포커스는 누른 복제 버튼에 남고(연달아 복제할 수 있다) 알림이 새 이름을 읽는다. 강조나 자동 스크롤은 하지 않는다(D19). QA S8에서 사본 위치를 본다.

**지우기 확인(`ConfirmDialog`).** 제목 "‘{이름}’ 프리셋을 지울까요?", 설명 "이미 만든 내 문장 결과는 그대로 남아요." 채널 기본이면 이어서 "채널 ‘{채널 이름}’의 기본 프리셋도 비워져요."(채널 이름을 모르면 "고른 채널의 기본 프리셋도 비워져요.", D17). 버튼 '취소'·'지우기'(destructive). 성공 알림 "‘{이름}’ 프리셋을 지웠어요."

**상태**
| 상태 | 표현 |
|---|---|
| 첫 로딩 | 목록 자리 회색 자리 표시 하나(그릇 높이), 개수 줄 없음, 영역 `aria-busy` |
| 빈 | `Notice`(아이콘 없음, 보관함 빈 상태와 같다). 제목 "아직 프리셋이 없어요", 설명 "성우 캐스팅의 '내 문장 듣기'에서 지금 설정을 프리셋으로 저장할 수 있어요.", outline 링크 버튼 '성우 캐스팅으로' + `ArrowRight` → `/casting`(테두리가 보이는 `Button` outline 모양. `buttonVariants`를 `cn` 없이 쓰면 테두리가 투명해진다, critique P2) |
| 목록 오류 | 회색 한 줄 "프리셋 목록을 받지 못했어요" + '다시 불러오기'. 성공하면 포커스를 개수 줄로(채널·분류 묶음 머리와 같은 규칙) |
| 소유자 없음 | 목록 대신 `LoopbackNotice` 하나 "이 주소에서는 프리셋을 쓸 수 없어요" |
| 고치기 실패 | 저장 창과 같다(5절). 프리셋이 지워졌으면 알림 "이미 지워졌거나 찾을 수 없어요.", 창 닫힘 |
| 복제 실패 | 알림 "저장하지 못했어요. 잠시 뒤 다시 해 주세요."(지워졌으면 "이미 지워졌거나 찾을 수 없어요.") |
| 지우기 실패 | 창 유지, 창 안 "지우지 못했어요. 잠시 뒤 다시 해 주세요.", 포커스 '취소' |
| 다른 탭·화면의 변경 | 변경 뒤와 캐스팅 메뉴를 열 때 목록을 다시 받는다. 보관함 빼기·채널 지우기 뒤에도 다시 받는다 |

## 7. 성우 보관함 `/voices`
- **보기 칸 넷:** '전체' · '즐겨찾기' · '자주 사용' · '프리셋'. '프리셋'은 프리셋에 쓰는 담은 성우만 보이고 주소는 `view=preset`이다. 칸 안쪽은 `px-3`(768px 이상 `px-4`), 글자 14px 그대로다(D9). 320px에서도 넘치면 QA S16 뒤 그 줄만 가로로 넘긴다(캐스팅 탭 줄의 767px 규칙).
- **상태 줄:** 문구는 그대로("담은 성우 N명 중 M명"). '프리셋' 보기에서 프리셋 목록을 받는 중이면 끝에 " · 프리셋 목록을 받고 있어요", 받지 못하면 " · 프리셋 목록을 받지 못했어요"(계획 '스펙과 다른 점' 4). 그동안 결과는 비어 있다. 결과가 0명이면 기존 '조건 결과 0명' 표현이다. 단 '프리셋' 보기에서는 원인을 나눈다(critique P2, 사용자 결정 2026-10-20 "전용 빈·실패 상태"):
  - 프리셋 목록을 받았는데 프리셋에 쓰는 성우가 하나도 없으면: `Notice`(아이콘 없음) 제목 "아직 프리셋에 쓰는 성우가 없어요", 설명 "성우 캐스팅의 '내 문장 듣기'에서 프리셋을 저장하면 그 성우가 여기 보여요.", outline 링크 버튼 '성우 캐스팅으로' + `ArrowRight` → `/casting`. '조건 모두 해제'는 두지 않는다(누르면 '전체' 보기로 돌아가 이 보기를 잃는다).
  - 프리셋 목록을 받지 못하면: 회색 한 줄 "프리셋 목록을 받지 못했어요" + `ReloadButton`('다시 불러오기', `/presets` 목록 오류와 같다). 다시 받기에 성공하면 결과가 그려진다.
  - 받는 중이면 결과 자리에 안내를 두지 않는다(상태 줄 덧붙임만).
  - 프리셋에 쓰는 성우가 있는데 검색·조건 때문에 0명이면 기존 '조건 결과 0명'이다.
- **'보관함에서 빼기' 확인(캐스팅·보관함 담기 칸 공통):** 설명 "즐겨찾기·자주 사용·메모·분류 연결도 함께 지워져요." 뒤에, 이 성우를 쓰는 프리셋이 있으면 "이 성우를 쓰는 프리셋 N개는 성우를 다시 골라야 해요.", 프리셋 목록을 받지 못했으면 "프리셋에서 쓰는 성우인지 확인하지 못했어요."(D10). 받는 중이면 덧붙이지 않고 '빼기'는 그대로 누를 수 있다.

**문구 규칙**
- `-어요` 보이스. 알림·칸 오류·창 설명처럼 문장인 것은 마침표로 끝내고, 한 줄 상태(메뉴 상태 줄, 목록 오류, 빈 상태 제목, 배지, 도움 줄, 상태 줄 덧붙임)는 마침표 없이 쓴다(classes.md 6절).
- 이름(프리셋·채널·성우)은 둥근 따옴표 ‘ ’, 화면·동작 이름('내 문장 듣기', '채널·분류')은 곧은 따옴표 ' '로 쓴다.
- 이름 뒤에는 받침에 따라 모양이 바뀌는 조사(을/를, 이/가, 은/는, 와/과, (으)로)를 붙이지 않고 '프리셋'·'설정'을 사이에 둔다("‘{이름}’ 프리셋을 …"). 받침과 무관한 '의'·'에'는 붙인다(스펙 4절 덮어쓰기 항목, 리뷰 D17).
- 값이 바뀌는 줄은 화살표 문법 "{옵션 이름} {전} → {후}"이고 값에 따옴표를 쓰지 않는다. 성우 맞춤 줄도 같은 문법 뒤에 " (이 성우에서 쓰는 값)"을 붙인다(D11).
- 목록을 받는 일은 '받기'('받고 있어요', '받지 못했어요', '다시 받기'), 프리셋을 설정에 적용하는 일은 '불러오기'다(D13). 공용 `ReloadButton`의 '다시 불러오기'(`/presets` 목록·채널 목록 오류)는 앱 공통 문구라 그대로 둔다.
- '저장할 때 성우 {이름}'은 콜론 없이 쓴다(메뉴 항목과 불러오기 창이 같다). '지금 기본 프리셋: …'과 처음 값 안내만 콜론 뒤에 값을 잇는다.

## 11. 계획 기본값과 다른 결정, 열린 질문
**계획 코드와 다른 결정(브리프가 이긴다).**
1. '기본' 배지는 `primary`(옅은 청록) 대신 `secondary`(회색)다. DESIGN.md의 Badge primary는 '재생 중'만 쓰고, 이름 옆 상태 배지는 회색이다(voices.md B8 '자주 사용').
2. 상태 배지 '현재 이용 불가'는 warning 대신 secondary(회색)다(voices.md B6 사용자 결정과 같은 배지). 나머지 둘은 warning이다.
3. `/presets` 줄 셋째 줄은 "채널 {이름}"이다(8절 초안과 다른 점 4).
4. 메뉴 목록 상태 줄(받는 중·없음·받지 못함)은 `<p>` 대신 `DropdownMenuLabel` + 메뉴 `aria-describedby`다. 메뉴 안 `<p>`는 화면 낭독기가 읽지 않는다.
5. '프리셋 관리' 앞에 가름선을 두고 끝에 `ArrowRight`를 붙인다.
6. `/presets` 목록 '다시 불러오기'가 성공하면 포커스를 개수 줄로 옮긴다.
7. 문구 셋(8절 초안과 다른 점 1~3).

계획 기본값을 그대로 확정한 것: 한 목록·줄 순서·아이콘 순서·640px 미만 배치, outline '프리셋' 메뉴와 `w-72`·`max-h-80`, 불러온 프리셋 줄, 저장·고치기 창 구성, 불러오기 창 줄 순서와 경고 문법, 덮어쓰기 `destructive` 색, 보기 칸 이름 '프리셋'과 상태 줄 문구.
