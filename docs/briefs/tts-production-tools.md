# 제작 도구 전체 작업 흐름

2026-09-26 사용자 승인: 앞서 지적한 여섯 기능의 미완성 UI를 조작 가능한 HTML로 완성한다. Operate, 기존 Wanted/Pretendard 유지. 기존 개인용·HTML 우선 범위이며 실제 API/유료 생성은 호출하지 않는다.

## 기능별 완료 장면

- **맞춤 성우 추천:** 현재 대본/직접 설명과 공급자·분류 조건 입력 → 추천 시연 → 근거 있는 예시 후보 → 비교 목록·샘플 상태 → 작업실 성우 적용. 재추천/빈 결과/오류/재시도/취소를 제공한다. 실제 AI 분석 결과라고 표현하지 않는다.
- **목소리 찾기:** 로컬 음성 또는 URL 입력 → 원본 확인 → 검색 시연 → 유사 후보 비교·선택. URL은 HTTPS 유효성만 확인하며 다운로드하지 않는다. 동일 화자 식별·정확도 보장 문구는 쓰지 않는다.
- **보이스 체인저:** 원본 준비 → ElevenLabs 대상 성우·설정·동의 → 변환 상태 시연 → 원본/결과 비교와 다시 시도. Typecast의 공개 변환 API는 미확인이므로 대상에서 제외. 실제 변환 파일이 없는 상태를 명시하고 가짜 다운로드를 만들지 않는다.
- **대본 가져오기:** 직접 붙여넣기와 로컬 TXT/CSV/SRT/DOCX 파일 → 원문 확인·화자 감지 ON/OFF → 문단 미리보기·수정·화자 이름/성우 배정 → 교체/삽입 확인 → 작업실에 대본과 문단 계획 반영. 파일은 브라우저에서만 읽으며 지원 형식/크기/오류를 안내한다. Vrew식 자막 편집은 제외한다.
- **감정 자동화:** 현재 문단을 불러와 규칙 기반 시연 제안 → 문단별 감정/강도/성우 검토 → 일괄 적용·직접 수정·되돌리기 → 작업실 문단 계획에 적용. 공급자별 표현 지원을 구분한다. 실제 AI 분석·감정 추론과 구분한다.
- **내 목소리 복제:** 기존 단계형 흐름의 원본 준비를 실제 로컬 파일 선택/재생과 사용자 클릭으로 시작하는 마이크 녹음으로 보강한다. 권한 거부·취소·파일 오류·다시 녹음·원본 삭제를 제공한다. 공급자 전송/검증/생성은 시연이며 실제 클론이 아니다.

## 2026-09-26 서비스 리서치 반영 — 기존 동선 보완

사용자의 Typecast·ElevenLabs·Vrew 조사 후 진행 요청에 따라 기존 여섯 도구를 재배치한다. Operate·Wanted·Pretendard를 유지한다. 새 영상 편집기나 실제 API 연동은 이번 HTML 변경에 포함하지 않는다.

- 접힌 제작 도구를 작업실 상단의 상시 노출 메뉴로 바꾼다. 대본 준비(가져오기·감정), 성우 선택(추천·찾기), 내 음성 활용(복제·변환)으로 구분한다. 다섯 도구는 선택한 패널만 펼치며 닫으면 대본 편집으로 돌아간다. 내 목소리 복제는 내 보이스로 이동하는 링크임을 설명하고 해당 화면에서 작업실로 바로 돌아온다.
- Vrew의 문서 중심 작업을 참고하여 가져오기 화면에서 작업실 대본·기존 화자 배정을 불러와 문단별로 수정한다. 이미 작성한 가져오기 초안은 덮어쓰기 전에 확인한다. 원문은 명시적으로 반영하기 전까지 유지한다.
- 기존 문단 계획에 대본·화자 편집과 감정 검토 진입점을 구분한다. 다시 반영할 때 기존 감정·강도를 보존한다. 텍스트 변경 후 감정 재검토 안내를 제공한다.
- 검증: 첫 화면 여섯 메뉴 노출, 키보드 진입/닫기/복귀, 여섯 도구 연결, 원문·화자·감정 왕복 보존, 초안 교체 취소, 1440/390px에서 가로 넘침 없음. 실제 음성 결과는 시연 표기를 유지한다.

## 공통 계약

도구 사이를 이동해도 입력과 검토 결과를 세션에서 유지한다. 입력 변경은 이전 분석/결과를 무효화한다. 처리 중 중복 요청을 막고 취소/늦은 응답을 처리한다. 저장·작업실 적용은 명시적인 버튼으로만 한다. 예시 데이터와 실제 로컬 원본을 구분한다.

로컬 음성은 Object URL로 재생하며 다른 음성 재생 시 앞 재생을 중지한다. 마이크는 사용자 녹음 버튼에서만 요청하고 도구/화면 이탈·중지·취소 시 트랙을 해제한다. 실제 결과 음원이 없으면 플레이어/다운로드를 활성화하지 않는다. 로컬 파일/녹음은 localStorage나 서버에 저장하지 않는다.

문단 계획에는 텍스트·화자·성우·감정 설정을 보관하고 작업실에 표시한다. 원문이 변경되면 이전 문단 계획이 맞지 않을 수 있음을 알리고 다시 검수한다. 단일 성우 생성이 다중 화자 계획을 조용히 무시하지 않도록 문단 생성 시연 경로를 구분한다.

검증: 여섯 happy path, 입력 없음/오류/빈 결과/취소/재시도, 적용 전 원문 보존, 파싱과 화자 배정, 문단 편집·감정 undo, 지원 공급자, 원본/결과 구분, 녹음 정리, 탭 이동 상태 유지, 1440/390px·키보드·포커스.
