# 성우 보관함 브리프 (T7)

- 작성: 2026-10-07. 상태: **사용자 확인(2026-10-07, "확인, 이대로")**. 결정 셋(별 색, 페이지 설명, 이용 불가 행)은 사용자 답(2026-10-07)이다.
- 정본: 화면 동작은 [T7 스펙](../plans/tasks/T07-voice-library.md) 4·5절(계획 리뷰 U1~U4 포함)이 정한다. 이 브리프는 [T7 계획](../plans/tasks/T07-voice-library-plan.md) '브리프로 넘길 결정' B1~B8만 정한다. 스펙에 있는 문구·동작은 여기서 다시 쓰지 않는다.
- 모드: Operate. 시각 기준: `DESIGN.md`, [앱 틀](app-shell.md), [성우 캐스팅](casting.md)(행·패널·조건 줄 문법), [채널·분류](classes.md)(확인 창·문구 규칙). 새 시각 세계·시안·새 프리미티브는 없다.

## 1. 누가, 무엇을
본인 한 명이 성우 캐스팅에서 마음에 든 성우를 담아 두고, 대본을 만들 때 채널·카테고리·타입으로 다시 찾는다. 캐스팅 중에는 별 하나로 빠르게 담고, 정리는 패널의 '담기' 칸에서 한다. `/voices`는 담아 둔 성우만 보는 캐스팅 화면이다.

## 2. 결과와 증거
성공은 담은 성우가 `/voices`에 최근 담은 순으로 보이고, 조건(보기·공급자·채널·카테고리·타입·검색)으로 좁혀지며, 주소를 다시 열어도 같은 조건이 남는 것이다. 공급자가 없다고 답한 성우도 메모와 분류를 잃지 않고 '현재 이용 불가'로 남는다.

## 3. 방향
- **캐스팅과 같은 행·패널을 그대로 쓴다.** 보관함은 새 목록 모양이 아니라 캐스팅 행에서 '내 문장 듣기'만 빠진 것이다.
- **청록은 늘던 곳에만 둔다.** 별·자주 사용·내 분류 칩·이용 불가는 모두 무채색이다. 청록은 1차 동작, 재생 중, 고른 조건에만 남는다(DESIGN.md).
- **정리는 패널 안에서 끝낸다(U4).** 분류 붙이기는 떠 있는 창이 아니라 담기 칸 안에서 펼쳐진다.

## 4. 범위와 하지 않을 것
포함: `/voices`, 캐스팅 행의 별·내 분류 칩·'자주 사용' 배지, 패널 담기 칸, `/classes`의 '성우 N명' 링크와 삭제 덧붙임, 메뉴 열기. 하지 않을 것은 스펙 6절 그대로다. 화면에서 특히 두지 않는 것:
- 보관함 안 '내 문장 듣기', 여러 성우 한꺼번에 바꾸기, 끌어서 순서 바꾸기, 정렬 고르기
- 이용 불가 성우 자동 바꾸기, 보관함 내보내기
- 휴대폰 위 막대 4칸 바꾸기(앱 틀 결정, 범위 밖)

## 5. 결정 (B1~B8)

**B1 행의 별.** 44px 아이콘 버튼(`ghost`), 행 오른쪽 끝(내 문장 듣기 뒤). 빈 별은 회색(`muted-foreground`) 윤곽, **채운 별은 글자색(`foreground`) 채움**(사용자 결정). 툴팁 '즐겨찾기'/'즐겨찾기 해제'. 담은 성우 목록 전이면 흐리게(`aria-disabled`, 50%) 두고 툴팁이 이유를 말한다("성우 보관함을 불러오고 있어요", 실패면 "성우 보관함을 불러오지 못했어요"). 행 전체 '고르기' 위에 놓인다(재생 버튼과 같은 층).

**B2 담기 칸(패널).** 자리: 캐스팅은 U2('내 문장 듣기' 뒤, '내 문장 결과' 앞). `/voices`는 '기본 샘플' 바로 뒤(critique 반영, 사용자 선택 2026-10-07)이고 ElevenLabs 공개 라이브러리 안내는 담기 칸 바로 위. 위에서 아래로:
1. 머리 '담기'(패널 다른 칸 머리와 같은 크기·굵기). 저장 중이면 머리 오른쪽에 작은 스피너, 화면 밖 `role="status"` "저장하는 중이에요".
2. 한 줄: 즐겨찾기 윤곽 토글(`outline`, 44px, 별 아이콘 + '즐겨찾기', 켜지면 별 채움·글자색) + 자주 사용 스위치(라벨 '자주 사용'). 좁으면 줄바꿈.
3. 붙은 분류: 그룹마다 한 줄. 왼쪽 회색 14px 그룹 이름(채널·카테고리·타입, 고정 폭으로 칩 시작을 맞춘다), 오른쪽 윤곽 칩들. 붙은 것이 없는 그룹 줄은 두지 않는다.
4. '분류 붙이기'(`link` 모양, 44px 높이). 펼치면 '접기'가 아니라 같은 버튼이 `aria-expanded`로 상태를 말한다.
5. 메모 칸(2~3줄), 아래 줄 왼쪽 "저장하지 않은 변경이 있어요"(회색, 바뀌었을 때만), 오른쪽 'N / 200자'(190자부터 주황), 그 아래 '메모 저장'(`outline`, 바뀌었을 때만 눌림).
6. 담긴 성우면 맨 아래 '보관함에서 빼기'(회색 글자 버튼, 휴지통 아이콘 없음).

**B3 분류 붙이기 펼침(U4).** 담기 칸 안, '분류 붙이기' 바로 아래:
- 검색 칸(44px, 자리표시 '이름으로 찾거나 새로 만들기'). 분류가 하나도 없으면 칸 아래 회색 "이름을 쓰면 바로 만들어 붙일 수 있어요". 40자를 넘기면 칸 아래 주황 한 줄(T6 이름 규칙 문구).
- 그룹 머리(회색 14px 굵게: 채널·카테고리·타입) 아래 체크 줄. 줄 높이 44px, 왼쪽 체크박스 + 이름(줄바꿈해 다 보임). 그룹 안 T6 이름순.
- 검색어에 맞는 항목이 없는 그룹은 "일치하는 이름이 없어요" 회색 한 줄. 같은 이름이 그 그룹에 없으면 그룹 끝에 "+ ‘{검색어}’ {그룹} 만들기"(`ghost`, 왼쪽 정렬, 줄바꿈).
- 펼침 전체 최대 높이 약 20rem, 넘치면 펼침 안에서 스크롤(패널 스크롤과 따로). 검색 결과 수는 화면 밖 `role="status"`.
- 분류 목록 로딩·실패는 펼침 안 회색 한 줄("채널·분류 목록을 불러오지 못했어요" + '다시 불러오기').

**B4 `/voices` 조건 줄(D6).** 캐스팅 조건 줄 문법 그대로(casting.md 5절, `VoiceConditions` 재사용): 검색 칸(자리표시 '이름·메모로 찾기', critique 반영) → 보기 네 칸(전체·즐겨찾기·자주 사용·프리셋, 토글 그룹. T8 개정: '프리셋'은 프리셋에 쓰는 담은 성우만, 주소 `view=preset`, 칸 안쪽 `px-3`(768px 이상 `px-4`). 상태 줄과 상세는 [프리셋 브리프](presets.md) 7절) → '공급자' 드롭다운(하나) → '채널'·'카테고리'·'타입' 드롭다운(여러 개 체크) → '성별'·'연령' 드롭다운(각각 하나만 고른다. 캐스팅 '전체' 탭과 같은 단일 선택, 사용자 요청·결정 2026-11-20). 성별·연령은 담을 때 저장한 성우 정보로 메타 줄과 같은 한국어 이름(여성·남성·중성, 어린이·청소년·청년·중년·노년. Fish Audio는 태그)으로 거르고, 선택지는 담은 성우에 있는 값만 보인다. 값이 없는 성우는 그 축을 고르면 빠진다. 주소 쿼리는 `gender`·`age`(한국어 이름이 아닌 `female`·`young` 같은 공통 키). 고르면 '카테고리 · 2'로 쓰고 옅은 청록, 접근 이름 '카테고리, 2개 선택됨'. 그룹에 항목이 없으면 그 드롭다운은 열리고 "아직 카테고리가 없어요" 한 줄과 '채널·분류에서 만들기' 링크. 767px 이하는 검색 칸 + '조건' 버튼으로 접는다(캐스팅과 같다). 상태 줄은 스펙 4절 그대로, 16px 회색 `tabular-nums`, '조건 모두 해제' 링크는 인원 글자 옆.

**B4-2 정렬과 공통 태그(사용자 결정 2026-11-20).**
- **정렬:** 상태 줄 오른쪽에 공급자 탭과 같은 정렬 선택(`SortMenu` 재사용, 버튼 '정렬: 최근 담은 순', 메뉴 하나 고르기, 담은 성우가 0명이면 잠김). 값 다섯, 주소 `sort`(기본값이면 쓰지 않는다): `recent` 최근 담은 순(기본, 서버가 준 담은 순서), `used` 최근 쓴 순(`lastUsedAt` 큰 순, 쓴 적 없으면 뒤, 같으면 담은 순서), `count` 사용 횟수순(`useCount` 큰 순, 같으면 담은 순서), `name` 이름순(한글 이름 가나다 → 그 밖 ABC, 같은 무리 안은 `Intl.Collator('ko')`), `popular` 서비스 인기순(화면 글은 GLOSSARY대로 '서비스', critique 뒤 이름 다듬기 2026-11-20. 이 정렬일 때만 목록에 묶음 머리 줄 'ElevenLabs · 최근 1년 글자 수', 'Fish Audio · 사용 횟수', '인기 수치 없음'을 회색 작은 글자로 넣는다(행이 있는 묶음만, 접근성 트리에도 읽힌다). 공급사가 준 수치 `voice.usage`가 있는 성우만 위로, ElevenLabs(최근 1년 글자 수) 묶음 → Fish Audio(사용 횟수) 묶음, 묶음 안은 큰 순. 수치 없는 성우는 뒤에 담은 순서. 단위가 달라 공급사끼리 섞지 않는다). 정렬은 거른 뒤 보이는 목록에만 걸고 인원 글자는 바꾸지 않는다. '조건 모두 해제'는 정렬을 풀지 않는다(조건이 아니다).

**B5 문구.** 스펙 4절과 `apps/web/src/lib/saved-voice-view.ts` `LIBRARY_TEXT`가 정본이다. 여기서 정하는 것:
- 페이지 설명(사용자 결정): **"담은 성우를 즐겨찾기·자주 사용·채널·분류로 다시 찾아요. 성우 캐스팅에서 별을 누르면 여기에 담겨요."**
- 별 툴팁: B1. 칩 × 툴팁 '떼기', 접근 이름 '{그룹} {이름} 떼기'(audit 반영).
- 붙임·뗌 알림은 화면 밖 `role="status"`만(토스트 없음): "‘{이름}’ 카테고리를 붙였어요."·"… 뗐어요." 메모 저장만 토스트 "메모를 저장했어요."

**B6 이용 불가 행(사용자 결정).** 행을 흐리게 하지 않는다. 회색 배지 '현재 이용 불가'(기존 회색 배지 모양)를 배지 목록 맨 앞에 둔다. 재생 버튼은 저장한 샘플이 있으면 그대로 동작한다(공급자가 지웠으면 재생 실패는 기존 샘플 오류 표현). 패널 맨 위 안내 한 줄은 스펙 4절 문구, 회색 `bg-muted` 한 줄 안내 상자(trial-confirm 안내와 같은 모양, Ruling 12. 빈 상태용 `Notice`는 쓰지 않는다).

**B7 행 칸 예산(D1).** 별 칸(44px)이 늘어 오른쪽 144px 칸이 보이는 목록 너비를 32rem에서 **36rem**으로 올린다(`@[36rem]:flex`, 아래는 배지가 메타 줄 아래로). 이름은 줄바꿈하지 않고 말줄임(기존). QA S17에서 1200·1280px 이름 칸에 한글 6자 이상이 보이는지 본다. `DESIGN.md` 성우 행 절을 고친다(대조표 25행).

**B8 담은 성우 행(U3).** 공급자 알약 자리에 내 분류 칩: 채널 → 카테고리 → 타입 순으로 최대 2개 + '+N'(회색 글자). 칩 모양은 기존 알약(12px, `muted` 바탕, 안쪽 경계, 최대 128px 말줄임) 그대로이고 묶음 맨 앞에 회색 12px 태그 아이콘(`Tag`) 하나로 공급자 알약과 구별한다(critique 반영, 사용자 선택 2026-10-07). 그룹 이름은 없다(이름만, 전체는 패널). 좁은 행(목록 칸 28rem 미만)에서는 공급자 알약 대신 내 분류 1개 + '+N'만 보이고, 칩 하나도 들어갈 자리가 없으면(320px 캐스팅처럼) 묶음을 통째로 숨긴다(목록은 화면 밖 설명이 대신 읽는다). 담았지만 분류가 없으면 공급자 알약을 그대로 둔다. '자주 사용'은 이름 옆 회색 배지(기존 회색 배지). 즐겨찾기는 별이 말하므로 배지를 두지 않는다.

## 6. 상태
스펙 4·5절과 같다. 브리프가 더하는 표현:
| 상태 | 표현 |
|---|---|
| 보관함 첫 로딩 | 행 뼈대 5줄(행 높이와 같음), 목록 `aria-busy` |
| 담기 칸 목록 전 | 칸 자리 뼈대 3줄(토글 줄·칩 줄·메모) |
| 확인 중 | 상태 줄 끝 " · 이용 가능 여부를 확인하고 있어요"(타이머 없음) |
| 저장 실패 | 별·토글이 서버 값으로 돌아감 + 토스트 "저장하지 못했어요. 잠시 뒤 다시 해 주세요." |

## 7. 상호작용과 접근성
- 행 roving: 재생 → 고르기 → (캐스팅만) 내 문장 듣기 → 별. 목록 안내 '방향키로 성우와 버튼 사이를 옮겨요'.
- **'보관함에서 빼기' 확인 문구(T8 개정, 캐스팅 담기 칸과 공통):** 설명 "즐겨찾기·자주 사용·메모·분류 연결도 함께 지워져요." 뒤에, 이 성우를 쓰는 프리셋이 있으면 "이 성우를 쓰는 프리셋 N개는 성우를 다시 골라야 해요.", 프리셋 목록을 받지 못했으면 "프리셋에서 쓰는 성우인지 확인하지 못했어요."를 띄워 잇는다. 받는 중이면 덧붙이지 않고 '빼기'는 그대로 누를 수 있다([프리셋 브리프](presets.md) 7절).
- 포커스: 빼기 뒤 캐스팅은 담기 칸 머리, 보관함은 스펙 4절 '조건에서 빠지는 행' 규칙. 칩 뗀 뒤는 스펙 4절. 펼침의 Esc는 펼침만 접고 포커스를 '분류 붙이기'로(서랍은 닫지 않는다).
- 인터랙티브 요소 44px 이상, `focus-visible` 고리, 입력 칸 767px 이하 16px 글자.
- 모션: 스피너와 기존 서랍·확인 창뿐. 펼침은 바로 열린다(애니메이션 없음).

## 8. 시각 자산과 제약
- 아이콘(lucide): 별 `Star`, 이동 `ArrowRight`, 칩 떼기 `X`, 만들기 `Plus`, 내 분류 표시 `Tag`. 메뉴 '성우 보관함'은 앱 틀 아이콘 그대로.
- 토큰과 Tailwind 기본 눈금만, 굵기 400·700, 원시 색·임의 값 금지(B7의 `@[36rem]` 컨테이너 크기는 기존 `@lg` 자리 교체라 예외로 기록).
- 프리미티브: 기존 `Button`·`Toggle`·`ToggleGroup`·`Switch`·`Checkbox`·`Textarea`·`Input`·`DropdownMenu`·`AlertDialog`·`Tooltip`·`Skeleton`·`Spinner`·`Badge`. 새로 더하지 않는다.
- 이 브리프와 스펙에 없는 문구·색을 구현하는 쪽이 새로 만들지 않는다.
