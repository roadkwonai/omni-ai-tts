## 1. 누가, 무엇을

본인 한 명이 유튜브 대본을 문단 작업실에서 다듬고 음성으로 만든다. 보관함에 오는 때는 셋이다.
- 지난 대본을 다시 찾아 작업실로 가져갈 때(검색 → '작업실에서 열기')
- 대본을 정리할 때(이름·채널·분류 고치기, 복제, 지우기)
- 이름 붙이지 않고 만든 작업을 되찾을 때('최근 만든 대본')

## 2. 결과와 증거

- 성공은 검색어 한두 글자와 채널·분류로 몇 초 안에 그 대본을 찾고, 한 번 눌러 작업실에 그대로 여는 것이다.
- 목록은 대본 수와 상관없이 첫 화면이 같은 속도로 뜬다(30개씩, 스펙 5절). QA는 120개 가짜 목록으로 스크롤해 본다.
- 이 화면은 소리를 내지 않고 공급자를 부르지 않는다.

## 3. 방향

- **`/presets`와 같은 한 목록, `/voices`와 같은 조건 줄.** 이미 익힌 두 화면의 문법을 합친다. 흰 그릇, 가름선, 오른쪽 44px 아이콘 버튼.
- **주 동작은 '작업실에서 열기' 하나.** 줄의 글자 칸 전체가 아니라 줄 오른쪽 첫 버튼(채운 청록이 아닌 `neutral` 버튼 '열기')이다. 고치기·복제·지우기는 아이콘.
- **미리 보기가 제목을 돕는다.** 제목 아래 원문 앞부분 두 줄(회색, 말줄임)로 같은 이름 대본도 구분한다.
- **최근은 저장한 대본의 아래가 아니라 옆 구역이다.** 구역 전환(토글 그룹 두 칸)으로 오간다. 최근은 이름이 없어 첫 문장이 제목 자리다.

## 4. 범위와 만들지 않는 것

포함: `/scripts` 페이지, 구역 전환, 조건 줄, 두 목록, 고치기 창·지우기 확인·보관함에 저장 창, 앱 메뉴 열기. 스펙 7절 '만들지 않는 것'에 더해 화면에서 두지 않는 것:
- 줄 펼치기·미리 듣기·원문 전체 보기, 여러 줄 고르기와 한꺼번에 지우기
- 정렬 고르기(최근 바꾼 순 하나), 목록·격자 전환, 끌어서 순서 바꾸기
- 검색 결과 수 세기(상한 없는 목록이라 "N개 찾음"을 세지 않는다. 받은 줄 수만 화면 밖으로 읽는다)

## 5. `/scripts`

**머리.** `PageHeader` 제목 '대본 보관함', 설명 "음성 작업실에서 저장한 대본과 최근 만든 대본을 찾아 다시 열어요." 머리에 동작 버튼은 없다(대본은 작업실에서 만든다). 본문 폭 `max-w-3xl`.

**구역 전환.** `ToggleGroup` 두 칸 '저장한 대본' | '최근 만든 대본'. 주소 `?view=recent`(기본은 저장한 대본, 주소에 없음). 전환은 스크롤을 맨 위로, 포커스는 전환에 남는다.

**조건 줄(저장한 대본만).** `/voices` 조건 줄 문법: 검색 칸(44px, 자리표시 '제목·대본 글로 찾기', 지우기 ×) → '채널' 드롭다운(하나, '모든 채널'·'채널 없음'·채널들) → '카테고리'·'타입' 드롭다운(여러 개 체크. 그룹 안은 하나라도, 그룹끼리는 모두 — 성우 보관함과 같다). 고른 조건은 '카테고리 · 2'처럼 쓰고 옅은 청록. 조건은 주소(`q`, `channel`, `category`, `type`)에 남는다. 767px 이하는 검색 칸 + '조건' 버튼으로 접는다. 조건이 하나라도 있으면 줄 끝 '조건 모두 해제'.

**저장한 대본 줄(안쪽 16px), 글자 칸 위에서 아래로.**
1. 제목(16px 굵게, `break-keep`, 긴 제목도 줄바꿈해 다 보인다).
2. 원문 미리 보기 회색 14px 두 줄 말줄임(`line-clamp-2`). 검색어 강조는 하지 않는다(미리 보기는 앞부분이라 맞는 곳이 대개 밖에 있다).
3. 회색 14px `tabular-nums` "문단 N개 · 1,234자 · 바꾼 때"(바꾼 때: 오늘이면 "오후 3:05", 올해면 "11월 18일", 그 전은 "2025. 3. 4.").
4. 채널·분류 칩(있을 때만, `Badge` secondary). 채널 칩은 '채널 {이름}'으로 써서 분류와 구분한다. 감긴다.

**줄 동작.** 오른쪽: '열기'(`Button` neutral 36px, 접근 이름 '{제목} 작업실에서 열기') → 고치기 `Pencil` → 복제 `Copy` → 지우기 `Trash2`(`RowAction` 44px ghost, 툴팁). 640px 미만은 글자 칸 아래 오른쪽 정렬.
- '열기' → `/studio?script=<id>`. 확인은 작업실이 한다(studio.md 18.3).
- 고치기 창: 제목 '대본 고치기', 칸 제목(100자, 남은 글자 없음 — 넘기면 칸 아래 주황 한 줄)·채널(라디오 메뉴, '채널 없음' 포함)·분류(`ClassChecklist` 카테고리·타입, 성우 담기 칸과 같은 펼침). '저장하기'·'취소'. 원문은 고치지 않는다는 회색 한 줄 "대본 글은 음성 작업실에서 열어 고쳐요."
- 복제: 창 없이. 새 줄은 맨 위(바꾼 시각이 지금)에 생긴다. 포커스는 누른 복제 버튼에 남고 알림이 새 제목을 읽는다.
- 지우기 확인(`ConfirmDialog`): "‘{제목}’ 대본을 지울까요?", 설명 "이미 만든 음성 결과는 그대로 남아요. 작업실에서 열어 둔 작업도 그대로지만, 다음 저장은 새 대본으로 해요." '취소'·'지우기'(destructive).

**최근 만든 대본 줄.** 1번 자리에 첫 문장(제목 크기, 앞 60자 말줄임), 2번 없음, 3번 "문단 N개 · 1,234자 · 만든 때". 동작: '열기' → '보관함에 저장'(`BookmarkPlus` 아이콘, 창: 제목 '보관함에 저장', 칸은 고치기 창과 같고 제목 처음 값은 첫 문장 앞 100자, 버튼 '저장하기') → 지우기(확인 창 "이 최근 대본을 지울까요?"). 개수 줄 아래 회색 한 줄 "만들기를 누른 작업이 최근 20개까지 남아요."

**무한 스크롤.** 목록 끝 아래에 감시 줄을 두고 화면에 들어오면 다음 30개를 받는다. 받는 동안 그 자리에 회색 자리 표시 한 줄(`aria-busy`). 같은 자리에 '더 보기' 버튼도 늘 둔다(키보드·감시 실패 대비). 다 받으면 둘 다 없어지고 회색 "끝까지 봤어요"는 두지 않는다. 다음 쪽 오류는 그 자리 한 줄 "더 받지 못했어요" + '다시 불러오기'(이미 받은 줄은 그대로).

**상태**
| 상태 | 표현 |
|---|---|
| 첫 로딩 | 목록 자리 회색 자리 표시 셋(줄 높이), `aria-busy` |
| 저장한 대본 없음 | `Notice` "아직 저장한 대본이 없어요", 설명 "음성 작업실 위쪽 '대본' 메뉴에서 지금 작업을 새 대본으로 저장할 수 있어요.", outline 링크 '음성 작업실로' + `ArrowRight` → `/studio` |
| 검색 결과 없음 | 회색 한 줄 "조건에 맞는 대본이 없어요" + '조건 모두 해제' |
| 최근 없음 | `Notice` "아직 만든 대본이 없어요", 설명 "음성 작업실에서 만들기를 누르면 그 작업이 여기에 남아요.", 같은 링크 |
| 목록 오류 | 회색 한 줄 "대본 목록을 불러오지 못했어요" + '다시 불러오기' |
| 채널·분류 목록 오류 | 조건 줄 아래 경고색 "채널·분류 목록을 불러오지 못했어요" + '다시 불러오기'. 줄의 칩만 빠진다 |
| 소유자 없음 | 목록 대신 `LoopbackNotice` "이 주소에서는 대본 보관함을 쓸 수 없어요" |
| 고치기·저장 실패 | 창 유지. 같은 제목이면 칸 아래 "같은 이름의 대본이 있어요", 그 밖 "저장하지 못했어요. 잠시 뒤 다시 해 주세요." |
| 지워진 대본에 동작 | 알림 "이미 지워졌거나 찾을 수 없어요.", 목록 다시 받기 |

## 6. 상호작용과 접근성

- 탭 순서: 앱 틀 → 머리 → 구역 전환 → 조건 줄 → 목록 줄마다(열기 → 고치기 → 복제 → 지우기) → '더 보기'.
- 검색 칸은 입력을 멈추고 0.3초 뒤 찾고, 받은 결과는 화면 밖 `role="status"`로 "대본 N개를 보여요"(받은 줄 수).
- 창은 닫히면 연 버튼으로 포커스를 돌린다. 지운 뒤에는 다음 줄의 '열기'(없으면 앞 줄, 둘 다 없으면 구역 전환).
- 긴 목록 줄은 `content-visibility: auto`(스펙 5절). 줄 높이가 바뀌어도 스크롤이 튀지 않게 자리 높이를 준다.
- 390px: 줄 동작이 글자 칸 아래로, 조건은 '조건' 시트. 한글 제목은 `break-keep`.
