## 2. 방향

- **화면의 주인공은 대본 텍스트와 그 낭독이다.** 색과 형태는 이 재료가 읽히도록 물러서고, 위계는 글자가 짊어진다.
- **돈이 드는 동작에는 앱 전체에서 같은 표식 하나를 쓴다.** 무료 재생(▷)과 과금 생성은 기호부터 다르다(PRODUCT.md 원칙 3).
- 새 세계는 디자인 카탈로그에서 고른다(아래 4절, 사용자 선택). 고른 세계의 색·모서리·밀도·컴포넌트 성격을 따르고, 한국어 서체는 Pretendard를 유지한다.

## 3. 지킬 것 (새 세계에서도 그대로)

1. 제품 사실: 세 공급자(Typecast, ElevenLabs, Fish Audio), 혼자 쓰는 작업실, 로그인 없는 로컬 관리자 모드. 경고색 없는 "로컬 관리자" 한 줄과 "로그인 없이 이 컴퓨터에서만 쓰는 모드예요".
2. 정보 구조: 메뉴 9개의 이름과 순서, 반응형 3단(1200px 이상, 768~1199px, 767px 이하)과 휴대폰 위 막대 + 더보기. '준비 중' 메뉴는 사용자 결정(사이트맵 "예외")이라 결정은 두고 표현만 바꿀 수 있다(5절).
3. 말투: `-어요` 존댓말, 동사로 끝나는 버튼. 정해진 문구("페이지를 찾을 수 없어요", "주소가 바뀌었거나 아직 없는 화면이에요.", "작업실로 가기", "대본과 성우를 골라 한국어 음성을 만들 곳이에요.", "다시 확인하기")와 [연결 상태 브리프](provider-status.md) 6·7절의 문구와 값 형식.
4. 서체: Pretendard Variable 자체 호스팅(OFL), 한국어 어절 줄바꿈(`break-keep`), 숫자 `tabular-nums`.
5. 접근성: 본문 건너뛰기, `aria-current`, 아이콘 메뉴의 화면 밖 이름, 44px 터치 대상, `focus-visible`, `prefers-reduced-motion`, 작은 글자와 비활성 글자 4.5:1 이상, 색만으로 상태를 구분하지 않기, 더보기가 열린 동안 Tab은 메뉴 안에서만 돈다(2026-10-03 사용자 결정).
6. 시스템·라이트·다크 3택 테마와 다음 방문 유지.
7. 시안의 제품 원칙 흐름(뒤 TASK의 화면): 원문과 발음용 대본 분리, 생성 앞의 발음 검수 주 버튼, 사용량 "추정" 표시, 시연과 실제 호출 구분, 저장 상태 표시, 되돌리기.
8. 연결 상태: 상태 어휘(연결됨, 키 없음, 키 오류, 권한 부족, 한도 부족, 요청 제한, 공급자 장애, 확인 실패), 카드별 독립 확인, 키를 화면에 보이지 않는 원칙.
9. 구조 규칙: 토큰만 쓰기(시맨틱 이름 구조는 두고 값만 바꾼다, 원시 hex 금지), `packages/ui` 프리미티브, 아이콘은 `iconLibrary`(lucide).

## 4. 버릴 것 (새 세계의 반례)

1. 원티드 파랑 `#0066FF` 하나, 흰 카드, 1px 헤어라인, 파란 활성 알약으로 된 '아무 SaaS' 조합.
2. 자리표시 로고(파란 사각형 안의 "T").
3. '준비 중' 8개가 늘어선 메뉴, 알림 배지로 읽히는 회색 점(768~1199px), 휴대폰 주요 칸 3개 중 누를 수 없는 2칸.
4. 동작 없는 `Empty` 기본형 카드와 그 아래 비어 있는 60%의 본문.
5. `bg-card` 띠와 아래 경계선으로 가른 관리자 템플릿식 페이지 머리.
6. 앱 틀 밖에서 화면 한가운데 떠 있는 없는 주소 화면.
7. (시안, T9 편집기. 2026-10-04 재편 전 T8) 모든 조작이 같은 무게의 테두리 알약이고, 문단마다 조작 12개, 기본값까지 버튼으로 보이는 것.
8. (시안) 유료 미리 생성과 무료 재생이 같은 ▷인 것.
9. (시안) `-습니다`와 `-어요`가 섞인 말투, 명사형 버튼, 3장인데 2열인 연결 상태 카드.
10. (시안) 세 단, 상단 버튼 4개, 하단 막대가 동시에 다투고 주 버튼에만 색이 있는 편집기 구성.

7·8·10은 T9 편집기를 설계할 때 반영한다(이번 범위 밖, 로드맵 T9 메모로 옮긴다. 8은 T5 내 문장 듣기에서 먼저 정한다).

## 5. 표현 바꾸기 (2026-10-03 사용자 답: 모두 반영)

critique가 낸 고칠 방법 가운데 이번 범위(T1 앱 틀, T2)에 걸리는 것이다. 사이트맵의 페이지와 링크는 그대로이고 보이는 방식만 바꾼다.
1. 메뉴: 열린 화면만 위에 두고, '준비 중' 7개는 접힌 묶음 "다음에 열릴 화면" 하나에 넣는다. 항목은 그대로 누를 수 없고 '준비 중'을 글자로 알린다. 768~1199px의 회색 점은 없앤다.
2. 휴대폰 위 막대: 열린 화면(지금은 음성 작업실, 연결 상태)과 더보기만 둔다.
3. 작업실 빈 상태: 제작 흐름 지도(채널 → 성우 → 대본 → 검수 → 생성)로 바꾸고 단계마다 열린 화면 링크나 열리는 순서를 보인다. 개발 순서를 말하는 문장("다음 순서로 …")을 뺀다.
4. 없는 주소: 앱 틀(메뉴) 안에서 보인다. 탭 제목은 "페이지를 찾을 수 없어요 · TTS Pilot".
5. 테마 버튼: 지금 적용된 테마 대신 고른 값(시스템 설정이면 모니터 아이콘)을 보인다.
