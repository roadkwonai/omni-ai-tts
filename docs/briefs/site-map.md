# 사이트맵

- 작성: 2026-10-03. 상태: **사용자 확인(2026-10-04)**. `bts-ui`의 "사이트맵과 상호작용"(bts-starter-kit v0.8.0부터)에 따라 화면 브리프보다 먼저 둔다.
- 2026-10-04: 리디자인([리디자인 브리프](redesign.md) 5절, 시안 1 승인)을 반영했다. 페이지와 링크는 그대로이고, 메뉴 묶음·휴대폰 막대·작업실 빈 상태·없는 주소 화면·테마 버튼의 표현이 바뀌었다.
- 2026-10-04 T3 설계: `/casting`(성우 캐스팅)을 더하고 메뉴 '성우 캐스팅'과 흐름 지도 '성우'를 링크로 바꿨다. 휴대폰 위 막대가 4칸이 된다.
- 2026-10-04 T4 설계: `/casting`에 세 공급자 탭·출처 전환·성우 패널·'더 보기'·'목록 새로 고침'을 더했다. 새 페이지는 없다. 뒤 TASK의 화면은 채널·분류 `/classes`(T6), 성우 보관함 `/voices`(T7), 프리셋 `/presets`(T8)다(T4 스펙 2절 화면 구조).
- 화면을 여는 TASK마다 이 문서를 고친다. 그 TASK의 페이지 행을 더하고, '준비 중' 항목을 링크로 바꾼다.
- 2026-10-05 T5 설계: `/casting`에 공유 문장 입력·내 문장 듣기·모델과 옵션·유료 확인 창·저장된 결과를 더했다. 새 URL은 없다. `/connections`의 요청 제한에는 공급자 대기 시각을 적용한다.
- 2026-10-06 T6 설계: `/classes`(채널·분류)를 더하고 메뉴 '채널·분류'와 흐름 지도 '채널'을 링크로 바꿨다. 휴대폰 위 막대는 4칸 그대로이고, 위 막대에 없는 열린 화면은 더보기 안 '열린 화면' 줄에 둔다.
- 2026-10-07 T7 설계: `/voices`(성우 보관함)를 더하고 메뉴 '성우 보관함'을 '성우 캐스팅' 바로 뒤 열린 화면으로 옮겼다('준비 중'에서 지움). `/casting`에 행의 별과 패널의 담기 칸을, `/classes`에 '성우 N명' 링크를 더했다. 휴대폰 위 막대는 4칸 그대로이고 '성우 보관함'은 더보기 안 '열린 화면' 줄에 둔다.
- 2026-10-13 T7.6 설계: Gemini를 다섯째 공급자로 더했다. `/casting` 탭·'전체' 묶음·패널, `/connections` 카드 5장(1280px 이상 3열), `/voices` 공급자 필터. 새 URL은 없다.
- 2026-10-20 T8 설계: `/presets`(프리셋)를 더하고 메뉴 '프리셋'을 '성우 보관함' 바로 뒤 열린 화면으로 옮겼다('준비 중'에서 지움). `/casting` '내 문장 듣기' 머리에 '프리셋' 메뉴(저장·불러오기·덮어쓰기·'프리셋 관리')를, `/voices`에 보기 '프리셋'과 빼기 확인 문구를 더했다. 휴대폰 위 막대는 4칸 그대로이고 '프리셋'은 더보기 안 '열린 화면' 줄에 둔다. 화면 브리프는 [프리셋](presets.md).
- 화면 브리프: [앱 틀](app-shell.md)(T1, 2026-10-04 개정), [연결 상태](provider-status.md)(T2), [성우 캐스팅](casting.md)(T3, T4 개정), [채널·분류](classes.md)(T6), [성우 보관함](voices.md)(T7), [프리셋](presets.md)(T8). 순서: [서비스 구현 로드맵](../plans/implementation-roadmap.md).

| 휴대폰 위 막대(767px 이하) | 열린 화면 가운데 음성 작업실, 성우 캐스팅, 연결 상태와 더보기 4칸이다. 그 밖의 열린 화면('성우 보관함', '프리셋', '채널·분류')은 더보기 안에 둔다 |
| 더보기(767px 이하) | 맨 위 '열린 화면' 줄('성우 보관함', '프리셋', '채널·분류'), '다음에 열릴 화면' 묶음, 테마·'로컬 관리자' 줄을 펼치고 접는다. 메뉴 이동, Esc, 바깥 누르기로 닫힌다(T2, AF-01). 열린 동안 Tab은 더보기 버튼과 펼친 내용 안에서만 돈다(2026-10-03 사용자 결정). 더보기 안 화면에 있으면 더보기 버튼이 활성 메뉴와 같은 표현이고 접근 이름은 "더보기, 현재 {화면 이름}"(예: "더보기, 현재 성우 보관함")이다. 더보기 안 링크를 누르면 포커스는 더보기 버튼으로 간다(T6) |
| 테마 | 메뉴 바닥 줄 오른쪽 끝의 아이콘 버튼(767px 이하는 더보기 안). 누를 때마다 시스템 설정 → 라이트 → 다크로 바로 바뀌고 다음 방문에도 남는다. 툴팁에 지금 값과 다음 값을 보인다(2026-10-04 사용자 선택) |
| '로컬 관리자' 글자 | 버튼이 아니다. 마우스를 올리면 "로그인 없이 이 컴퓨터에서만 쓰는 모드예요" |

## 예외: '준비 중' 항목 (2026-10-03 사용자 결정, 2026-10-04 표현 개정)

`prokit-ui` 규칙은 만들지 않은 페이지로 가는 링크와 '준비 중' 표시를 두지 않는다. 이 앱은 혼자 쓰는 작업실을 TASK 순서로 짓는 중이라, 앞으로 열 화면을 '준비 중'으로 남겨 둔다.
- 메뉴에서는 접힌 묶음 "다음에 열릴 화면" 안에 둔다(리디자인 5절 1번). 작업실 빈 상태의 제작 흐름 지도도 열리지 않은 단계를 '준비 중'으로 보인다(5절 3번).
- 링크가 아니라서 404로 가지 않는다. 누를 수 없는 항목이고, 글자(767px 이하·1200px 이상, 흐름 지도)나 툴팁과 접근 이름(768~1199px 메뉴)으로 "준비 중"을 알린다. 회색 점은 쓰지 않는다.
- 마감 전 링크·버튼 확인에서 이 항목의 기대 동작은 "누를 수 없음"이다. 누를 수 있게 보이거나 다른 곳으로 가면 결함이다.
- 그 화면을 여는 TASK가 링크로 바꾸고 이 표에서 지운다. 메뉴 항목이 링크가 되면 묶음 밖 위쪽(열린 화면)으로 옮긴다.

| 메뉴 | 여는 TASK |
|---|---|
| 대본 보관함 | T12 |
| 내 보이스 | T13 |
| 프로젝트 | P1(T15 뒤에 순서를 다시 정한다) |

| 흐름 지도 단계 | 이어지는 곳 | 여는 TASK |
|---|---|---|
| 대본 | 음성 작업실(편집기) | T9 |
| 검수 | 음성 작업실(숫자 발음 검수) | T11 |
| 생성 | 음성 작업실(생성·재생·다운로드) | T9 |
