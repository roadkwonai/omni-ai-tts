# 앱 틀 브리프 (T1)

- 작성: 2026-09-29(개편). 상태: **사용자 확인(2026-09-29)**. 스펙: [T1 스펙](../plans/tasks/T01-app-foundation.md).
- 모드: Operate. 시각 기준: `DESIGN.md`(원티드), [HTML 시안](../prototypes/tts-studio/index.html)의 `.app-shell`·`.side-nav`.

- **누가, 무엇을:** 본인 한 명이 로그인 없이 로컬 관리자로 작업실에 들어간다. T1에서 할 일은 메뉴 보기와 테마 고르기다. 앞으로 열릴 화면이 무엇인지 메뉴로 미리 보인다(사용자 결정).
- **구성:** HTML 시안의 앱 틀을 옮긴다.
  - 1200px 이상: 좌측 내비게이션. 위에 로고 "TTS Pilot", 가운데 메뉴 9개(음성 작업실, 성우 캐스팅, 대본 보관함, 성우 보관함, 프로젝트, 프리셋, 채널·분류, 내 보이스, 연결 상태), 아래에 테마 전환과 "로컬 관리자" 표시.
  - 768~1199px: 64px 아이콘 내비게이션. 이름은 툴팁과 `aria-label`로 보인다.
  - 767px 이하: 위쪽 고정 막대에 주요 3개(음성 작업실·성우 캐스팅·대본 보관함)와 더보기. 더보기를 열면 나머지 메뉴가 보인다.
  - HTML의 `시연 모드` 버튼과 계정 메뉴는 옮기지 않는다.
- **로컬 관리자 표시:** 로그인이 없다는 사실을 알리는 조용한 글자 한 줄("로컬 관리자"). 누를 수 있는 요소가 아니다. 경고 색을 쓰지 않는다.
- **준비 중 메뉴:** 음성 작업실만 링크다. 나머지 8개는 링크가 아닌 비활성 항목으로 두고 옆에 '준비 중' 글자를 붙인다. 아이콘 내비게이션에서는 툴팁과 `aria-label`에 "준비 중"을 넣는다. 색만으로 구분하지 않는다. 비활성 글자도 대비 4.5:1 이상이다(`DESIGN.md` 비활성 규칙). 각 화면의 TASK가 끝나면 그 메뉴를 연다.
- **화면 상태:**
  - 빈 작업실: 페이지 머리(제목 "음성 작업실", 설명 한 줄)와 빈 상태("성우와 대본 기능은 준비 중이에요").
  - 없는 주소: "페이지를 찾을 수 없어요"와 작업실로 가는 버튼.
  - 오류 화면("문제가 생겼어요"와 다시 시도)은 첫 서버 조회가 생기는 T2에서 만든다.
  - 문구는 모두 원티드 보이스(`-어요`)다.
- **제약:**
  - 토큰만 쓴다. 원시 hex와 임의 Tailwind 값은 쓰지 않는다.
  - shadcn 프리미티브는 `packages/ui`의 것을 쓴다. 빈 상태는 `Empty`를 쓴다.
  - 터치 대상은 44px 이상이다. `focus-visible`, 본문으로 건너뛰기 링크, `prefers-reduced-motion`을 지킨다.
  - 라이트·다크 모두 `DESIGN.md` 시맨틱 값을 쓴다.
