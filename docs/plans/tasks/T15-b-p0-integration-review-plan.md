## 개요

검수 TASK다. 코드는 검수에서 수용 기준을 막는 문제가 나올 때만 바뀐다. 그래서 대조표의 DB 행(6·8~11)과 계약 행(12)은 바뀐 것이 없으면 N/A이고, 구현 행(5·13·19·25)은 수정이 생길 때만 채운다. 화면 리뷰 행(17·18·23·24·26·27)은 공개 데모 화면 전체를 대상으로 접근성 점검(P0-07)을 겸해 채운다.
