## 1. 목표

성우 캐스팅에서 내가 쓴 문장을 공급자·모델별 옵션으로 들어 본다. 크레딧이 드는 듣기는 누를 때마다 예상 사용량과 남은 크레딧을 보이고, 진행을 확인할 때만 공급자를 부른다. 크레딧을 쓰기 싫으면 무료인 기본 샘플을 들으라고 안내한다. 같은 성우·모델·설정·문장은 저장한 결과를 크레딧 없이 다시 재생한다.

뒤 TASK가 그대로 쓸 것을 만든다.
- 생성 기록(요청 id 선점, 소유자별 동시 1건, 처리 여부 미확인). 작업실 생성(T9·T10)이 쓴다.
- 공급자별 생성 설정 계약(zod)과 정리 규칙. 프리셋(T8)이 저장한다.
- 공급자 클라이언트의 합성 메서드, 오디오를 `File`로 보내기, 크레딧 확인 창과 유료 표식.

## 3. 화면과 흐름

**'내 문장' 바**(승인 시안 자리: 상태 줄·안내 줄 아래, 본문 위. 모든 탭에서 같은 문장. 브리프 12절)
- 문장 입력(최대 200자)과 글자 수. 고른 성우가 Fish Audio면 UTF-8 바이트 수도 함께 보인다.
- 안내 한 줄: "기본 샘플 ▷은 무료예요. 내 문장 듣기는 크레딧을 써요(Fish Audio 무료 모델 제외)."
- 탭을 바꿔도 문장은 남는다. 화면을 떠나면 비워진다(문장 저장은 T12).

**성우 패널의 '내 문장 듣기' 구역**(이용 조건 뒤, 넓은 화면 칸과 좁은 화면 서랍 모두. 패널 순서는 기본 샘플 → 이용 조건(Typecast는 모델별 감정) → 내 문장 듣기 → 내 문장 결과다. 유료 버튼 앞에 무료 플랜 제한 줄이 온다, 사용자 결정 U5, 계획 리뷰 2026-10-05)
1. 모델 고르기. 공급자별 목록과 기본값은 4절이다.
2. 그 모델이 받는 옵션만 보인다. 모델을 바꾸면 받지 않는 옵션은 숨고, 받는 옵션의 값은 남는다. '처음 값으로'가 그 공급자 설정을 기본값으로 되돌린다.
3. 예상 사용량: "약 31크레딧", Fish Audio 유료면 "93바이트 · 약 $0.0014", 무료 모델이면 "무료". 같은 조합이 저장돼 있으면 "저장된 결과 · 크레딧 0", 문장이 비면 이 줄을 숨긴다(계획 리뷰 2026-10-05).
4. [내 문장 듣기] 버튼. 크레딧이 드는 경우 크레딧 표식, Fish Audio 무료 모델이면 '무료' 표식을 붙여 기본 샘플 ▷와 기호부터 다르게 한다(리디자인 critique 8번). 같은 조합이 저장돼 있으면 버튼 아래에 '새로 만들기'(크레딧 표식)가 하나 있다. 예상 사용량과 버튼 줄은 패널 스크롤 칸 바닥에 붙어 옵션이 길어도 보인다(사용자 결정 U3·U4, 계획 리뷰 2026-10-05).
5. 데이터 안내 한 줄(공급자 약관 문구가 있을 때): Typecast "보낸 문장이 Typecast 서비스 개선에 쓰일 수 있어요", Fish Audio 무료 모델 "보낸 문장이 Fish Audio 모델 개선에 쓰일 수 있어요".
6. '내 문장 결과'(구역 밖 형제 소제목): 이 성우의 완료 결과를 최신순 20개까지. 줄마다 ▷, 문장 앞부분, 둘째 줄 "언제 · 사용량 · 설정 요약"(두 줄까지), '지우기'. 결과 줄에는 '새로 만들기'를 두지 않는다. 결과가 없으면 "아직 들어 본 문장이 없어요"(계획 리뷰 2026-10-05).
- 공급자 설정은 공급자마다 하나씩 기억한다. 같은 공급자의 다른 성우로 바꿔도 남고, 화면을 떠나면 처음 값으로 돌아간다(저장은 T8 프리셋).

**행의 '내 문장 듣기'**: 그 성우의 공급자 지금 설정으로 듣는다. '전체' 탭에서도 같다. 문장이 비면 꺼지고 이유("문장을 먼저 써 주세요")를 툴팁·접근 이름에 보인다. 목록 칸이 약 672px 미만이면 글자 없이 44px 아이콘 버튼이다(유료 `Coins`, Fish Audio 무료 모델 `AudioLines`, 사용자 결정 U1·U2). 실패하면 행 메타 줄 끝에 "내 문장을 듣지 못했어요"가 보인다(계획 리뷰 2026-10-05).

**누르면**
1. `trialFind`로 같은 조합의 저장된 결과를 찾는다. 있으면 바로 재생하고 "저장된 결과 · 크레딧 0"을 알린다.
2. 없고 Fish Audio 무료 모델이면 바로 `trialCreate`를 부른다.
3. 그 밖에는 확인 창을 연다.
   - 제목 "크레딧을 써서 들어 볼까요?". 공급자·성우·모델, 예상 사용량, 남은 크레딧(연결 상태 조회를 이때 새로 읽음, 실패하면 "확인하지 못했어요").
   - "크레딧 없이 들으려면 기본 샘플을 들어 보세요" 문장과 [기본 샘플 ▷] 버튼(성우에 샘플이 없으면 숨김).
   - [취소]와 [크레딧 쓰고 듣기]. 첫 포커스는 [취소]다. Esc와 [취소]가 취소다. 바깥을 눌러도 닫히지 않는다(유료 확인 창, Base UI AlertDialog)(계획 리뷰 2026-10-05).
   - [크레딧 쓰고 듣기]를 누를 때 요청 id(uuid)를 하나 만들고 `trialCreate`를 부른다. 누른 뒤 버튼은 잠긴다.

**만드는 동안**
- 누른 버튼은 '만드는 중…'(비활성)이고, 다른 '내 문장 듣기' 버튼도 모두 잠긴다(동시 1건). 기본 샘플은 계속 들을 수 있다.
- 탭·성우를 바꿔도 생성은 이어지고 결과는 그 성우의 결과 목록에 들어간다. 끝나면 지금 소리 나는 샘플이 없을 때만 바로 재생한다(다른 소리를 끊지 않는다).
- 화면을 떠나도 서버는 끝까지 만들어 저장한다. 돌아와 같은 조합을 누르면 저장된 결과가 재생된다.

**재생**: 결과는 기본 샘플과 같은 플레이어로 재생한다(한 번에 하나). 오디오는 `blob:` 주소로 재생하고, 바꾸거나 화면을 떠날 때 `URL.revokeObjectURL`한다. 그 성우의 내 문장 결과가 소리 나는 동안 행에 재생 중 표시(왼쪽 띠, '재생 중' 배지)가 켜지고, 행·패널의 '내 문장 듣기'가 채운 '정지'로 바뀐다(기본 샘플과 같은 문법, 사용자 결정 U8, 계획 리뷰 2026-10-05).

**'새로 만들기'**: 지금 조합이 저장돼 있을 때 패널 버튼('저장된 결과 듣기') 아래에 하나 둔다(결과 줄에는 두지 않는다, 사용자 결정 U4, 계획 리뷰 2026-10-05). 확인 창을 거쳐 같은 조합으로 다시 만든다. 확인 창에 "같은 설정이어도 소리가 달라질 수 있어요"를 더한다(ElevenLabs `seed`도 결정성을 보장하지 않는다). 예전 결과는 지우지 않는다.

**'지우기'**: 확인 한 번("지우면 같은 문장을 다시 들을 때 크레딧을 써요"). 앱 DB에서만 지운다.

## 4. 공급자 호출

공통
- 공급자 호출은 `providers/<공급자>.ts`의 합성 메서드에만 둔다. 요청 본문은 계약 필드로만 서버가 만든다.
- 자동 재시도 없음(ElevenLabs SDK `maxRetries: 0`, Typecast SDK의 재시도 동작은 구현 때 설치본 소스로 확인해 끈다, Fish Audio는 `fetch` 한 번). 시간 제한 60초.
- 보낼 문장 = 말투 태그가 있으면 `"{태그} {문장}"`, 없으면 문장. 예상 사용량은 보낼 문장으로 센다.
- 응답 오디오가 4MB를 넘으면 실패로 본다(200자 MP3는 1MB 안팎).

| 공급자 | 엔드포인트 | 모델(기본 굵게) | 화면 옵션(범위, 기본) | 서버 고정 값 |
|---|---|---|---|---|
| Typecast | SDK TTS(`POST /v1/text-to-speech`) | **`ssfm-v30`**, `ssfm-v21`. 성우 데이터 `models[]`에 있는 것만 | 감정: v30은 '자동'(`emotion_type: "smart"`) 또는 프리셋, v21은 프리셋만. 화면은 감정 모드 '자동 \| 직접'(사용자 결정 U6). 프리셋은 그 성우·모델의 `emotions`에 있는 것만(normal·happy·sad·angry·whisper·toneup·tonedown, 화면 이름은 T4 패널 '모델별 감정'과 같은 기본·기쁨·슬픔·화남·속삭임·높은 톤·낮은 톤(계획 리뷰 2026-10-05)). 강도 0~2(1). 언어: 자동 감지(기본, 필드 생략) 또는 한국어(`kor`). 속도 `audio_tempo` 0.5~2.0(1). 음높이 `audio_pitch` −12~12반음(0). 음량 `volume` 0~200(100) | `audio_format: "mp3"`(320kbps). `target_lufs`·`remove_silence_ms`·`previous_text`·`next_text` 보내지 않음 |
| ElevenLabs | SDK `textToSpeech.convert` | **`eleven_v4`**, `eleven_v3`, `eleven_multilingual_v2`, `eleven_flash_v2_5` | v4: 안정성 0~1(0.5)·유사도 0~1(0.75)·말투 태그. v3: 안정성·말투 태그. multilingual v2: 안정성·유사도·스타일 0~1(0)·속도 0.7~1.2(1)·화자 증폭(켜짐). flash v2.5: 안정성·유사도·속도, 스타일·화자 증폭은 `GET /v1/models`의 `can_use_style`·`can_use_speaker_boost`가 참일 때만 | `output_format: "mp3_44100_128"`. `seed`·`language_code` 보내지 않음 |
| Fish Audio | `POST https://api.fish.audio/v1/tts`(`fetch`) | **`s2.1-pro-free`**(무료), `s2.1-pro` | 속도 `prosody.speed` 0.5~2.0(1). 표현력 `temperature` 0~1(0.7). 말투 태그 | `model` 헤더를 **늘 보낸다**(빠지거나 틀리면 오류 없이 유료 `s2.1-pro`). `reference_id`=성우 id(문자열 하나), `format: "mp3"`, `mp3_bitrate: 128`, `latency: "normal"`. `references`(즉석 클론)·`top_p`·청크 값 보내지 않음 |

말투 태그 목록(공식 문서, 화면에는 한국어 이름과 원문을 함께)
- ElevenLabs v4·v3: `[whispers]` `[sighs]` `[laughs]` `[excited]` `[curious]` `[sarcastic]` `[crying]` `[mischievously]` `[exhales]`, 또는 직접 쓰기(대괄호 안 30자까지).
- Fish Audio S2: `[happy]` `[sad]` `[angry]` `[excited]` `[calm]` `[nervous]` `[confident]` `[surprised]` `[whispering]` 등 Emotion Control 기본 감정, 또는 직접 쓰기(같은 제한).
- 한국어 문장에서 효과가 나는지는 문서에 없다. 화면에 "효과는 들어 봐야 알아요"를 둔다.

예상 사용량(계산 함수 하나를 화면과 서버가 함께 쓴다, `providers/trial-contract.ts`)
- Typecast: 글자 수(코드 포인트) × 1크레딧. 공백·문장부호가 세어지는지 문서에 없어 "약"을 붙인다.
- ElevenLabs: 글자 수 × 모델 배율(`GET /v1/models`의 `model_rates.character_cost_multiplier`, 할인 `cost_discount_multiplier`가 있으면 함께). 모델 목록은 새 프로시저 `trialModels`가 T4 목록 캐시(목록 종류 `models`, 소유자 없음, 24시간)로 받는다. 받지 못하면 배율 1로 계산하고 "배율을 확인하지 못했어요"를 붙인다.
- Fish Audio 유료: UTF-8 바이트 수와 "약 ${바이트 × 15 / 1,000,000}"(출처: Fish Audio 요금 문서, $15/100만 바이트). 무료 모델은 0.
- 남은 크레딧: T2 `providerStatus`의 `quota`(Typecast 플랜 크레딧, ElevenLabs 남은 글자 크레딧, Fish Audio API 충전 잔액). Typecast는 유료 플랜이면 한도를 넘어 청구될 수 있다는 요금 문구가 있어, 남은 값이 0 이하여도 막지 않고 "남은 플랜 크레딧이 없어요. 플랜에 따라 추가 청구될 수 있어요"를 보인다.

Fish Audio 무료 종료: 서버 상수 `FISH_FREE_UNTIL`(2026-11-30 0시 KST, 블로그 날짜보다 하루 이르게)부터 무료 모델을 목록에서 빼고, 그 모델로 온 요청은 `BAD_REQUEST`(`free_ended`)로 거절한다. 공급자 문서가 바뀌면 상수만 고친다.

## 5. 생성 기록과 저장된 결과 (ADR 0003 '듣기 결과')

**표 `trial_generation`**(새 마이그레이션, `db:generate`)

| 칸 | 타입·제약 | 뜻 |
|---|---|---|
| `id` | uuid pk | 결과 id(목록·재생·지우기 입력) |
| `owner_id` | text not null | `context.ownerId`. 외래 키는 걸지 않는다(로드맵 T6 메모) |
| `request_id` | uuid not null | 사용자 동작 하나에 브라우저가 만든 값 |
| `combo_key` | text not null | 정리한 (공급자, 성우 id, 모델, 설정, 문장, 계약 판)의 sha256 |
| `provider` | text not null, CHECK 세 공급자 | |
| `voice_id` | text not null | 공급자 성우 id |
| `model` | text not null | |
| `settings` | jsonb not null | 정리한 설정(4절 계약) |
| `text` | text not null | 사용자가 쓴 문장(태그 제외, NFC, 앞뒤 공백 제거) |
| `usage_amount`, `usage_unit` | numeric, text(`credit`·`byte`·`free`) | 예상 사용량 |
| `status` | text not null, CHECK `pending`·`done`·`failed`·`unknown` | |
| `failure_reason` | text null | 공급자 오류 `reason` |
| `audio` | bytea null | `done`일 때만 |
| `audio_type` | text null | `audio/mpeg` |
| `created_at` | timestamptz not null default now | |
| `expires_at` | timestamptz not null | 만든 때 + 30일, 재생할 때마다 지금 + 30일 |

- 유니크 `(owner_id, request_id)`.
- 부분 유니크 `(owner_id) where status = 'pending'`: 소유자별 동시 1건.
- 인덱스 `(owner_id, combo_key, created_at desc) where status = 'done'`(찾기), `(owner_id, provider, voice_id, created_at desc)`(목록).
- `bytea`는 drizzle `customType`으로 만든다(`packages/db`에 아직 없다).

**프로시저**(모두 `protectedProcedure`, 소유자는 `context.ownerId`만, 모든 읽기·쓰기에 `owner_id` 조건)

| 이름 | 입력 | 출력 | 공급자 호출 |
|---|---|---|---|
| `trialModels` | `{ provider: "elevenlabs" }` | 모델별 배율·`can_use_style`·`can_use_speaker_boost`·글자 상한 | 무료 목록 조회(24시간 캐시) |
| `trialFind` | 공급자, 성우 id, 모델, 설정, 문장 | 저장된 결과 `{ id, createdAt, usage, audio: File }` 또는 `null`. 찾으면 `expires_at` 연장 | 없음 |
| `trialCreate` | 요청 id + 위 입력 | `{ id, createdAt, usage, audio: File }` | 유료(또는 Fish Audio 무료) 1회 |
| `trialList` | 공급자, 성우 id | 완료 결과 최신 20개의 정보(오디오 없음) | 없음 |
| `trialAudio` | 결과 id | `File`, `expires_at` 연장 | 없음 |
| `trialDelete` | 결과 id | `{ deleted: true }` | 없음 |

`trialCreate` 순서
1. 입력 검사: 문장 1~200자(코드 포인트, 공백만 거절), 설정은 공급자·모델별 zod(4절 범위), 말투 태그 30자. 서버가 설정을 정리한다(그 모델이 받지 않는 값 빼기, 빠진 값은 기본값, 슬라이더 단위로 반올림). 슬라이더 단위는 0~1 값과 배속 0.05, 감정 강도 0.1, 음높이 1반음, 음량 5다. 조합 키는 서버만 만든다.
2. Fish Audio 무료 모델이 `FISH_FREE_UNTIL` 뒤면 `free_ended`로 거절.
3. 키가 없으면 `no_key`.
4. 공급자 대기 시각을 읽는다. 대기 중이면 `rate_limit`(`retryAt`). **DB를 읽지 못하면 공급자를 부르지 않고 `storage`로 거절**(로드맵 T5 메모).
5. 소유자의 5분 넘은 `pending`을 `unknown`으로 바꾼 뒤 `pending` 행을 넣는다(선점).
   - `(owner_id, request_id)` 충돌: 기존 행이 같은 조합이면 공급자를 부르지 않고 그 상태를 돌려준다(`done`이면 결과, `pending`이면 `in_progress`, `failed`면 그 `reason`, `unknown`이면 `unknown_outcome`). 다른 조합이면 `BAD_REQUEST`(`request_mismatch`).
   - 부분 유니크 충돌: `TOO_MANY_REQUESTS`(`in_progress`).
   - DB 실패: `storage`.
6. 공급자를 한 번 부른다.
   - 성공: 행을 `done`, 오디오 저장, 소유자의 만료 행 지우기(`expires_at < now`, `pending` 제외), 결과 반환.
   - 429: 대기 시각 기록(T4 `provider_cooldown`, 1시간 상한, `Retry-After`가 없으면 T4와 같은 기본값), 행 `failed`.
   - 시간 초과·연결 끊김: 행 `unknown`, `GATEWAY_TIMEOUT`(`unknown_outcome`). 자동으로 다시 만들지 않는다.
   - 그 밖: 행 `failed`, `tts-provider` 오류 표의 코드.
   - 결과를 저장하지 못하면(DB 실패) 오디오는 돌려주고 행은 `pending`으로 남는다. 저장된 결과가 없으므로 같은 조합을 다시 누르면 확인 창이 나오고, 그 행이 `unknown`으로 바뀌는 5분 동안은 `in_progress`로 막힌다. 드문 경우라 따로 풀지 않는다.

- 쿨다운 읽기·쓰기는 `voice-cache.ts`에서 함수로 빼내 목록과 함께 쓴다(지금은 모듈 안에만 있다).
- 공급자 클라이언트 인터페이스(`ProviderClient`)에 `synthesize?(input)`을 더한다. 반환은 오디오 바이트와 형식이다.
- 오디오는 oRPC `File`로 보낸다(base64 아님). 이 저장소에서 처음 쓰는 방식이라 계획 첫 작업에서 테스트로 확인한다.

## 6. 오류

| reason | oRPC 코드 | 화면 문구 |
|---|---|---|
| `no_key`, `provider_auth`, `no_permission` | T4 그대로 | T4 사유별 문구 + 연결 상태 링크. 버튼은 끈다(`no_key`) |
| `quota` | `BAD_GATEWAY` | "크레딧이 부족해요. 기본 샘플 ▷은 무료로 들을 수 있어요" |
| `rate_limit` | `TOO_MANY_REQUESTS` | "오전 8:44 이후에 다시 들을 수 있어요"(T4 `retryTime`, 분 올림). 그때까지 그 공급자 버튼을 끈다 |
| `provider_input` | `BAD_REQUEST` | "{공급자}가 이 요청을 받지 않았어요. {사유}". ElevenLabs 무료 플랜 라이브러리 성우는 "무료 플랜은 라이브러리 성우를 API로 쓸 수 없어요", 계정에 없는 라이브러리 성우는 "ElevenLabs 웹에서 내 계정에 추가한 뒤 '내 계정'에서 들어 보세요"(공급자 오류 코드로 가른다, 코드는 실제 1회로 확인) |
| `provider_error` | `BAD_GATEWAY` | "공급자 쪽 오류예요. 잠시 뒤 다시 눌러 주세요" |
| `unknown_outcome` | `GATEWAY_TIMEOUT` | "처리 여부를 확인하지 못했어요. 크레딧이 쓰였을 수 있으니 공급자 사용 기록을 확인한 뒤 다시 눌러 주세요". 다시 누르면 새 요청 id로 확인 창부터 |
| `in_progress` | `TOO_MANY_REQUESTS` | "다른 문장을 만드는 중이에요. 끝난 뒤 다시 눌러 주세요" |
| `free_ended` | `BAD_REQUEST` | "Fish Audio 무료 모델 기간이 끝났어요. 유료 모델로 바꿔 들어 주세요" |
| `request_mismatch` | `BAD_REQUEST` | (화면 버그. "다시 눌러 주세요") |
| `storage` | `SERVICE_UNAVAILABLE` | "지금은 내 문장을 들을 수 없어요. 기본 샘플은 들을 수 있어요" |
| 재생 실패 | (브라우저) | "재생하지 못했어요"와 '다시 듣기'(T4 그대로) |

- 공급자 오류 객체를 `cause`로 넘기거나 로그에 그대로 쓰지 않는다. 로그는 공급자, 상태 코드, 공급자 오류 코드만.
- 한 공급자의 실패가 다른 공급자의 듣기를 막지 않는다(대기 시각도 공급자별).
- 오류는 패널 구역과 행 근처에 한 줄로 보이고 스크린 리더에 알린다.

## 7. 범위

### 포함
- '내 문장' 바, 패널 '내 문장 듣기' 구역(모델·옵션·예상 사용량·버튼·데이터 안내·결과 목록), 행 '내 문장 듣기', 확인 창, 유료·무료 표식.
- 공급자 셋의 합성 메서드, 설정 계약, 예상 사용량, `trialModels`.
- 연결 상태 카드(CS-01): 429에 `Retry-After`가 있으면 그 시각까지 '다시 확인하기'를 끄고(`aria-disabled`) "오전 8:44 이후 다시 확인할 수 있어요"를 보인다(T4 `retryTime`). 유료 듣기와 같은 대기 규칙을 화면에서도 맞춘다.
- `trial_generation` 표와 마이그레이션, 프로시저 여섯, 쿨다운 함수 빼내기.
- 문서: GLOSSARY('시험 생성' 화면 이름 '내 문장 듣기'와 코드 이름 `trial`, '말투 태그', '저장된 결과'), `docs/domain/project.md`(화면 구역·프로시저·표), `docs/research/<공급자>-api-options.md`(조사 합치기), ADR 0003 Consequences(보관 30일, 약관 확인 결과), `tts-provider` 스킬(한 명 소유 예외를 듣기까지, Typecast SDK가 오류 응답 헤더를 버림), 성우 캐스팅 브리프 T5 개정, 로드맵 T5 상태.

### 만들지 않는 것 (ponytail)
| 무엇 | 이유·언제 |
|---|---|
| 설정 저장 | T8 프리셋 |
| 문장 저장·보관함 | T12 |
| 결과 내려받기, 출력 형식 선택 | T9(REQ-10) |
| 여러 성우 한꺼번에 듣기, 결과 비교표 | 일괄 듣기 없음(REQ-03, 2026-10-04 결정) |
| ElevenLabs 라이브러리 성우를 계정에 추가 | 공급자 상태 변경. 웹에서 추가하도록 안내 |
| Typecast 앞뒤 문맥 문장, 쉼 표기(`<\|1s\|>`), 발음 사전, SSML | 짧은 문장 들어 보기에 영향이 적다. 숫자 발음은 T11 |
| `seed`, 스트리밍, 언어 코드(ElevenLabs) | 들어 보기에 필요 없다 |
| 공급자 사용 기록 자동 조회로 미확인 건 판정 | Typecast·Fish Audio는 조회 API가 없고 ElevenLabs는 요청과 맞출 id가 없다 |
| 플랜별 '무료 플랜 불가' 표시 | T4 표시 그대로, 백로그 VC-18 |
| 완료 아닌 결과(실패·미확인)를 목록에 보이기 | 그 자리 알림으로 충분하다 |

## 9. 수용 기준

- **AC1** '내 문장' 바가 모든 탭의 상태 줄 아래·본문 위에 있고, 문장은 탭을 바꿔도 남는다. 글자 수가 보이고 Fish Audio 성우를 고르면 바이트 수도 보인다. 201자째부터 입력되지 않는다. 바에 기본 샘플 무료 안내가 있다.
- **AC2** 패널 '내 문장 듣기' 구역은 고른 성우의 공급자 모델 목록과 그 모델이 받는 옵션만 보인다(4절 표). Typecast는 그 성우가 지원하는 모델·감정만 보인다. 모델을 바꾸면 받지 않는 옵션이 숨고, 받는 값은 남는다. '처음 값으로'가 동작한다. 같은 공급자의 다른 성우로 바꿔도 설정이 남는다.
- **AC3** 예상 사용량이 공급자 단위로 보인다(Typecast 크레딧, ElevenLabs 배율 반영 크레딧, Fish Audio 유료 바이트와 달러, 무료 모델 '무료'). 말투 태그를 고르면 사용량이 늘어난다.
- **AC4** 문장이 비었거나 공백뿐이면 행·패널의 '내 문장 듣기'가 꺼지고 이유가 보인다.
- **AC5** 크레딧이 드는 듣기를 누르면 매번 확인 창이 열린다. 창에 공급자·성우·설정 요약·예상 사용량·남은 크레딧(Fish Audio는 남은 잔액)·기본 샘플 안내와 [기본 샘플 ▷]가 있다. [취소]·Esc는 공급자 호출 0회, [크레딧 쓰고 듣기]는 1회다. 바깥을 눌러도 닫히지 않는다. 확인 버튼을 빠르게 두 번 눌러도 1회다(계획 리뷰 2026-10-05).
- **AC6** Fish Audio 무료 모델은 확인 창 없이 바로 만들고, 무료 표식과 데이터 안내가 보인다. 유료 모델로 바꾸면 확인 창을 거친다. 서버는 Fish Audio 요청에 `model` 헤더를 늘 보낸다.
- **AC7** 같은 성우·모델·설정·문장을 다시 누르면 확인 창 없이 저장된 결과가 재생되고 공급자 호출은 0회다. 새로 고침·다른 화면에 갔다 와도 같다(서버 저장). "저장된 결과 · 크레딧 0"을 알린다.
- **AC8** 만드는 동안 모든 '내 문장 듣기'가 잠기고 기본 샘플은 들을 수 있다. 서버는 소유자별로 1건만 진행한다(브라우저 탭 둘에서 눌러도). 같은 요청 id가 다시 오면 공급자를 다시 부르지 않는다.
- **AC9** 결과와 기본 샘플을 통틀어 한 번에 하나만 재생된다. 결과 오디오의 `blob:` 주소는 바꾸거나 떠날 때 해제된다. 내 문장 결과가 재생 중이면 그 성우 행이 재생 중 표시를 켜고, 행·패널의 '정지'로 멈출 수 있다(1199px 이하 포함)(계획 리뷰 2026-10-05).
- **AC10** 패널 '내 문장 결과'에 이 성우의 완료 결과가 최신순 20개까지 보이고, ▷로 저장본을 재생하며(공급자 호출 0회), '지우기'는 확인 뒤 지운다. 줄마다 버튼 이름이 다르다(문장 앞부분). 결과가 없으면 빈 문구, 받는 중이면 뼈대, 실패하면 '다시 불러오기'가 보인다(계획 리뷰 2026-10-05).
- **AC11** 지금 조합이 저장돼 있으면 패널 버튼 아래에 '새로 만들기'(크레딧 표식)가 하나 있고, 확인 창(소리가 달라질 수 있다는 문장 포함)을 거쳐 같은 조합을 다시 만들며, 예전 결과는 남는다(계획 리뷰 2026-10-05).
- **AC12** 오류는 6절 문구대로 보이고 자동으로 다시 부르지 않는다. 429 대기 시각 전에는 그 공급자의 '내 문장 듣기'를 누를 수 없다. 시간 초과는 처리 여부 미확인 문구이고, 다시 누르면 확인 창부터다. 한 공급자의 실패가 다른 공급자 듣기를 막지 않는다.
- **AC13** 대기 시각 표나 생성 기록을 DB에서 읽거나 쓰지 못하면 공급자를 부르지 않는다.
- **AC14** 소유자가 없는 요청은 여섯 프로시저 모두 `UNAUTHORIZED`이고 공급자 호출과 DB 접근이 0회다. 키가 없으면 공급자를 부르지 않는다.
- **AC15** 소유자 A의 결과는 B가 찾기·목록·재생·지우기로 닿지 않는다(`null`, 빈 목록, `NOT_FOUND`). B가 만드는 중이어도 A의 만들기는 막히지 않는다. 같은 요청 id를 A와 B가 써도 서로 섞이지 않는다.
- **AC16** 30일이 지난 결과는 찾기·목록에 나오지 않고 다음 결과를 쓸 때 지워진다. 재생하면 만료가 30일 연장된다.
- **AC17** 1440·1280·1200·1024·768·390·320 너비와 라이트·다크에서 브리프(T5 개정)와 승인 시안 T5 영역대로 보인다. 페이지 가로 스크롤이 없다. 좁은 화면에서는 서랍 안에 구역이 있다.
- **AC18** 키보드만으로 문장 입력, 모델·옵션 조절(슬라이더 방향키), 듣기, 확인 창(첫 포커스 [취소], Tab 순환, Esc), 결과 재생·지우기를 쓸 수 있다. 접근 이름에 성우 이름과 동작, 크레딧 여부가 들어간다("Jiyoung 내 문장 듣기, 크레딧 사용"). 진행·완료·오류를 스크린 리더에 알린다.
- **AC19** 클라이언트 번들에 공급자 SDK·DB 모듈·키가 들어가지 않는다(`trial-contract.ts`만 화면이 import).
- **AC20** 연결 상태 카드가 429와 `Retry-After`를 받으면 그 시각 전에는 '다시 확인하기'가 꺼지고 "… 이후 다시 확인할 수 있어요"가 보인다(CS-01). 시각이 지나면 다시 누를 수 있다.

## 12. 사용자 테스트 절차 (구현 뒤 드린다)

실제 호출은 건마다 승인을 받는다(공급자·모델·문장 길이·횟수). 15자 안팎 짧은 문장, 최대 5회.
1. Typecast 1회(약 15크레딧): 감정 프리셋 하나로 들어 본다.
2. ElevenLabs `eleven_v4` 1회: 일반 TTS 엔드포인트에서 v4가 되는지 본다. 안 되면 v4를 목록에서 빼고 multilingual v2를 기본으로 한다(대조표의 QA 수정 행에서).
3. ElevenLabs 라이브러리 성우 1회: 계정에 추가하지 않고 되는지, 안 되면 오류 코드를 기록해 6절 문구를 맞춘다.
4. Fish Audio 무료 1회($0): 크레딧 확인 없이 들리는지.
5. Fish Audio 유료 1회(약 $0.0007): 호출 전후로 API 충전 잔액과 웹 플랜 크레딧을 비교해 어느 잔액에서 빠지는지 기록한다(CS-09).
그 뒤 직접 써 본다: 문장을 바꿔 가며 옵션과 모델을 바꿔 듣기, 같은 조합 다시 누르기(크레딧 0), 결과 목록 재생·지우기, 좁은 화면과 다크 테마.

이번에 없는 것(시안에서 비어 있는 자리): 별·담기와 성우 보관함(T7), 프리셋(T8). 결과 내려받기는 T9다.

## 13. 위험과 확인할 것

- **ElevenLabs v4 엔드포인트:** 공식 문서끼리 다르다(Models "Text to Dialogue API" / UI 가이드 "Create speech"). 사용자 테스트 2번으로 정한다.
- **ElevenLabs 라이브러리 성우:** 계정에 추가하지 않고 합성되는지 문서로 확정할 수 없다. 사용자 테스트 3번.
- **Fish Audio 무료 모델이 조용히 유료가 될 위험:** 무료 모델이 공급자에서 먼저 없어지면 `model` 값이 "모르는 값"이 되어 오류 없이 유료 `s2.1-pro`로 처리된다(공식 문서). 확인 창 없이 과금될 수 있다. 짧은 문장 1회는 약 $0.0007이다. 종료일 하루 전부터 무료 모델을 보내지 않고, 분기마다 공급자 문서를 다시 본다.
- **Typecast 글자 수 세기:** 공백·문장부호가 세어지는지 문서에 없다. 예상은 "약"이고, 사용자 테스트 1번 전후 플랜 크레딧 차이로 확인해 기록한다.
- **태그 효과:** 한국어 문장에서 영어 태그의 효과는 문서에 없다. 화면에 "들어 봐야 알아요"를 둔다.
- **oRPC `File` 응답:** 이 저장소에서 처음 쓴다. 계획 첫 작업에서 테스트로 확인한다. 안 되면 사용자에게 알리고 전송 방식을 다시 정한다(ADR).
- **저장 용량:** 결과 하나 약 0.3~0.8MB(Typecast MP3 320kbps가 가장 크다). 30일 보관과 1인 사용에서 Neon 무료 1GB의 일부다. ADR 0003의 500MB 재검토 조건은 그대로 둔다.
- **처리 여부 미확인:** 시간 초과 뒤 실제로 과금됐는지 앱이 알 수 없다. 사용자가 공급자 사용 기록에서 확인한다.
