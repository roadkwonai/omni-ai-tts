## 1. 목표

'성우 캐스팅'에서 Typecast·ElevenLabs·Fish Audio를 탭으로 오간다. 공급자마다 그 공급자가 목록 API로 주는 조건과 정렬로 찾는다. 성우를 고르면 오른쪽 성우 패널에서 설명·언어별 기본 샘플·이용 조건을 본다. 기본 샘플은 한 번에 하나만 재생한다.

뒤 TASK가 그대로 쓸 것을 만든다.
- 성우 행과 성우 패널. T5 내 문장 듣기, T7 담기, T8 프리셋이 여기에 붙는다.
- 성우 식별(공급자 + 출처 + 성우 id).
- Postgres 목록 캐시와 공급자 대기 시각 표.
- 테스트 DB와 2계정 격리 테스트의 틀.

## 3. 목록 호출

- **선택지:** 공식 문서가 값 목록을 주지 않는 조건(ElevenLabs 성별·연령·콘텐츠·분위기, Fish Audio 태그)의 선택지는 2026-10-04 실측 값을 브리프 6절 표로 고정한다. 응답에 표에 없는 값이 오면 행·패널에는 공급자 값 그대로 보이고, 선택지에는 넣지 않는다. 억양은 억양 목록 조회 값을 쓴다.
- **Fish Audio 여러 값(2026-10-04 실측, 무료 조회 2회):** 배열은 반복 키(`tag=a&tag=b`)로 싣는다. 여러 값의 뜻은 **모두 포함**이다. `tag=female&tag=narration`은 100명 모두 두 태그를 가졌고, `language=ko&language=ja`는 100명 모두 두 언어를 가졌다(`total` 557, 11.4초). 그래서 태그 드롭다운 머리에 '모두 포함'을 적는다. 언어는 하나만 고른다(여럿은 그 언어를 모두 하는 성우라 찾기에 쓸모가 적다).
- **Fish Audio 응답 거르기:** 목록 필터에 유형·상태가 없다. 서버가 `type !== "tts"`, `state !== "trained"`, `dmca_taken_down === true`를 뺀다. 첫 페이지 실측은 모두 tts·trained·public이었다. `pvc_release_state === "retiring"`은 빼지 않고 패널에 "공급자가 공개를 끝내는 중"이라고 보인다.
- **응답 검증:** 공급자마다 T3와 같은 항목 단위 검증이다. 응답 모양(배열 아님 등)이 어긋나면 `provider_error`다. 성우 하나의 샘플 주소만 어긋나면 그 샘플만 null이다. 그 밖의 필드가 어긋난 성우는 빼고 로그를 한 줄 남긴다(수·필드 이름만). 한 명 이상인데 모두 빠지면 `provider_error`다.
- **샘플 주소:** https이고 공급자 호스트일 때만 받는다. 허용 호스트는 Typecast `*.typecast.ai`, ElevenLabs `storage.googleapis.com`·`*.elevenlabs.io`, Fish Audio `*.fish.audio`다(실측 호스트: `static2.typecast.ai`, `storage.googleapis.com`, `api.us.elevenlabs.io`, `platform.r2.fish.audio`). ElevenLabs의 `api.us.elevenlabs.io/.../previews/audio?payload=` 주소는 쿼리 토큰이 붙어 있고 만료 여부는 정보 없음이다(11절 위험).
- **ElevenLabs 언어별 샘플:** 라이브러리 응답의 `verified_languages[]`에 언어별 `preview_url`이 있다(실측 100명 모두 `ko` 샘플). 행의 샘플 버튼은 지금 언어 조건의 샘플을 먼저, 없으면 `preview_url`을 재생한다. 패널은 모든 언어 샘플을 언어 이름과 함께 보인다.
- **시간 제한:** Typecast·ElevenLabs는 호출마다 10초(T2·T3와 같은 값)다. Fish Audio 목록은 20초다. 실측 응답이 1.7~11.4초였다(조건이 많을수록 느림). 연결 확인은 그대로 10초다. 자동 재시도는 서버·화면 모두 없다. ElevenLabs 목록은 REST라 재시도 코드가 없고, 연결 확인 SDK는 `maxRetries: 0`이다.
- **ElevenLabs 목록은 REST(계획 리뷰 반영):** 설치본 SDK 2.70.0은 응답 전체를 한 번에 검사(`parseOrThrow`)하고 끄는 옵션이 없다. 성우 하나의 빠진 필드가 목록 전체를 막으므로 목록·억양 세 호출은 REST로 부르고 항목마다 검사한다.
- **억양 선택지:** 억양 목록 값 가운데 조건 값 검사(`^[A-Za-z0-9_-]+$`, 40자)를 통과한 것만 선택지로 둔다. 뺀 수는 로그 한 줄이다.
- **키 권한:** ElevenLabs 키에 권한을 제한했다면 "Voices (read)"가 필요하다(공식 도움말). 없으면 `no_permission`이다.

## 4. 오류

T3 4절 표를 세 공급자에 그대로 쓴다. 공급자 문제를 `UNAUTHORIZED`·`FORBIDDEN`으로 던지지 않는다. 문구의 공급자 이름만 바뀐다. 아래를 더한다.

| 경우 | 동작 |
|---|---|
| 공급자 실패 + 같은 조건의 지난 캐시 행이 있음(만료 뒤 7일 안) | 던지지 않고 지난 목록을 `stale: { reason }`과 받은 시각을 붙여 돌려준다. 화면은 목록 위 안내 줄에 "{공급자}에 연결하지 못해 {N분/시간} 전에 받은 목록을 보여 드려요" + 사유 문구 + '다시 불러오기'를 보인다 |
| 429 | 응답에 `Retry-After`가 있으면 그 시각(1시간 상한)을 공급자별 대기 표에 적는다. 그 시각 전에는 그 공급자의 목록 조회를 부르지 않고 `rate_limit`(지난 목록이 있으면 위 동작)이다. 안내 줄에 "{시각} 이후 다시 불러와 주세요"가 나온다. Fish Audio 429에는 `Retry-After`가 없으므로(문서) 대기 시각을 적지 않는다 |
| '전체' 탭에서 한 공급자 실패 | 그 공급자 묶음 자리에만 사유 안내가 나온다. 다른 묶음은 그대로다(REQ-02) |
| 키 없음 | 그 공급자 탭과 '전체' 묶음에 T3와 같은 '키가 없어요' 안내가 나온다. 공급자를 부르지 않는다 |
| 입력 검증 실패(조건 값 길이·개수·형식) | `BAD_REQUEST`. 화면은 고정 선택지만 보내므로 정상 사용에서는 나오지 않는다 |
| DB가 꺼지거나 캐시 읽기·쓰기가 실패 | 캐시 없이 공급자를 부르고 결과를 그대로 보인다. 화면에 DB 오류를 띄우지 않는다. 서버 로그에 `[voiceCache] {단계} 실패: {오류 이름} {코드}` 한 줄(연결 문자열·SQL 없음). 연결 시간 제한 3초 |

## 5. 목록 캐시 (ADR 0003 서버 목록 캐시)

**표 `provider_list_cache`**

| 컬럼 | 형식 | 내용 |
|---|---|---|
| `id` | uuid, 기본키 | |
| `owner_id` | text, null 가능 | 공개 목록은 null(공용), 계정 목록은 서버가 정한 `context.ownerId`. 외래 키 없음(2절) |
| `provider` | text | `typecast`·`elevenlabs`·`fish_audio` |
| `list_kind` | text | `public`·`account`·`accents` |
| `params_key` | text | 정렬한 조건과 페이지(또는 커서)를 정규화한 JSON의 SHA-256 |
| `contract_version` | integer | 계약 판. 계약이 바뀌면 판을 올려 옛 행을 읽지 않는다 |
| `payload` | jsonb | 계약 스키마로 검사한 결과(성우 목록과 페이지 정보) |
| `fetched_at`, `expires_at` | timestamptz | 받은 시각, 받은 시각 + 24시간 |

- 유니크: (`owner_id`, `provider`, `list_kind`, `params_key`, `contract_version`), `NULLS NOT DISTINCT`. 같은 키는 덮어쓴다(upsert).
- 읽을 때도 계약 스키마로 검사한다. 검사에 실패한 행은 없는 것으로 보고 다시 받는다.
- 쓰기마다 만료된 지 7일이 넘은 행을 지운다(cron 없음). 만료 뒤 7일까지는 공급자 실패 때 지난 목록으로 쓴다. 읽을 때도 이 기간을 넘은 행은 지난 목록으로 쓰지 않는다(쓰기가 없어도 오래된 목록을 내주지 않는다).
- DB가 꺼지거나 실패하면 캐시 없이 공급자를 부른다(4절). `createDb`의 연결 시간 제한은 3초다.
- 같은 키의 동시 요청은 서버 프로세스 안에서 공급자 호출 하나로 합친다. 서버 인스턴스끼리는 합치지 않는다(ponytail: 1인 사용, 필요해지면 advisory lock).
- 공개 목록과 계정 목록은 소유자로 나뉜다. 계정 목록 행은 그 소유자에게만 읽힌다. 공개 행은 모든 소유자가 함께 쓴다.

**표 `provider_cooldown`**: (`provider` 기본키, `until` timestamptz). 429 `Retry-After`로 정한 다음 호출 가능 시각이다. T5 생성 호출도 이 표를 쓴다(`tts-provider` 중복 과금 절).

**새로 고침:** `voiceListRefresh({ provider })`는 그 공급자의 공개 행과 이 소유자의 계정 행만 `expires_at = now()`로 바꾼다. 화면은 이어서 그 공급자의 열린 목록(지금 목록과 '전체' 묶음)을 다시 받는다. 조건이 '전체' 묶음과 다르면 공급자 호출이 2회다(최종 리뷰 2026-10-05). 대기 시각 전이면 아무것도 바꾸지 않고 대기 시각을 돌려준다.

## 6. 범위

### 포함
1. **계약** `providers/contract.ts`:
   - 성우 계약을 넓힌다. 출처(`public`·`account`), 억양, 분위기 배열, 언어 배열, 공급자 성우 종류, 설명(최대 1,000자로 자름), 추가 샘플 배열(이름표 + 주소), 사용량(ElevenLabs 최근 1년 글자 수·Fish Audio 사용 횟수), 이용 조건 값(무료 플랜 허용, 공유 종료 뒤 사용 기간, 실시간 검수, 크레딧 배율, 보증 성우, 공개 종료 중, 제공 성우 종료 예정)을 담는다.
   - 성별에 `neutral`을 더한다.
   - 목록 입력은 공급자·출처별 조건 유니온이다. 결과는 `{ provider, source, voices, next, total, totalExact, fetchedAt, stale }`이다.
   - 이름과 모양은 계획에서 정한다.
2. **공급자 목록:** `elevenlabs.ts`에 `listVoices`(공개 라이브러리·내 계정)와 억양 목록을 더한다. `fish-audio.ts`에 `listVoices`(공개·내 계정)를 더한다. `typecast.ts`는 그대로다. 응답 검증과 Fish Audio 거르기는 3절대로 한다.
3. **DB** `packages/db`: `provider_list_cache`·`provider_cooldown` 스키마와 `db:generate` 마이그레이션. 로컬 컨테이너(5433)와 테스트 DB를 준비한다.
4. **캐시 모듈** `packages/api`: 키 만들기, 읽기 검사, upsert, 7일 지난 행 정리, 동시 요청 합치기, 지난 목록 반환, 대기 시각을 담당한다. 공급자 모듈과 프로시저 사이에 둔다.
5. **프로시저:** `voiceList`(입력을 세 공급자·출처로 넓힘, 캐시 경유), `voiceListRefresh`, ElevenLabs 억양 선택지 조회. 모두 `protectedProcedure`이다. 소유자는 `context.ownerId`에서만 가져온다.
6. **화면** `/casting`(브리프와 승인 시안대로):
   - 탭(전체·Typecast·ElevenLabs·Fish Audio)과 출처 전환(공개 라이브러리 | 내 계정).
   - 공급자별 조건 줄, 상태 줄(인원·받은 시각·'목록 새로 고침'), 성우 행 목록과 '더 보기'.
   - 성우 패널(머리·설명·언어별 기본 샘플·이용 조건·공급자 분류), 지난 목록 안내 줄.
   - 1199px 이하는 패널이 서랍이고, 767px 이하는 전체 화면이다. 조건 줄은 T3처럼 '조건' 버튼 뒤로 접힌다.
   - 목록 조회는 TanStack Query로 하고, 조건·페이지마다 키가 다르다. 늦게 온 응답이 다른 조건의 목록을 덮지 않는다.
   - 검색어는 입력이 0.5초 멈추거나 Enter를 누를 때 보낸다(서버 검색 공급자). Typecast는 T3처럼 바로 거른다.
7. **샘플 플레이어:** T3 플레이어(페이지에 오디오 하나, 한 번에 하나)를 행과 패널이 함께 쓴다. 패널의 언어별 샘플도 같은 규칙이다.
8. **`tts-provider` 스킬:** 한 명 소유 예외(계정 목록), ElevenLabs·Fish Audio 목록 규칙(거르기, 샘플 호스트, 언어별 샘플), 목록 캐시와 대기 표를 반영한다. SDK 판 표도 갱신한다.
9. **문서:**
   - `docs/research/*-api-options.md`: 2026-10-04 재확인과 실측을 합친다. 설계 단계에서 했다.
   - `docs/domain/project.md`: 화면·API·데이터 모델 표를 갱신한다.
   - `GLOSSARY.md`: 계정 성우, 목록 캐시를 넣는다.
   - 사이트맵: `/casting` 행.
   - 로드맵: T4 상태, T5·T6·T7 메모.

## 8. 수용 기준

- **AC1** 탭 넷(전체·Typecast·ElevenLabs·Fish Audio)이 보이고 누르면 바뀐다. 탭을 바꿔도 다른 탭의 조건과 목록이 남는다(같은 페이지 안).
- **AC2** '전체' 탭에 공급자 묶음 셋이 있고 묶음마다 앞의 5명과 인원, '모두 보기 →'가 있다. '모두 보기 →'는 그 공급자 탭으로 가고 검색어를 가져간다. 검색어는 세 묶음에 함께 걸린다. 한 공급자가 실패해도 다른 묶음은 보인다.
- **AC3** ElevenLabs 공개 라이브러리는 한국어로 거른 채 열린다. 인원은 공급자 `total_count`와 같다. 조건(검색·언어·억양·성별·연령·콘텐츠·분위기·성우 종류·추천 성우만·정렬)을 바꾸면 그 조건으로 다시 받는다. 언어를 바꾸면 억양 선택지가 그 언어의 억양 목록으로 바뀐다.
- **AC4** ElevenLabs 내 계정은 계정 성우를 보이고, 출처·성우 종류·성별·연령·언어·억양·콘텐츠·정렬과 방향이 동작한다. 제공 성우에는 "ElevenLabs 제공 성우는 2026-12-31에 종료돼요"가 패널에 나온다.
- **AC5** Fish Audio 공개는 한국어로 거른 채 열리고, 검색·언어·성별·연령·콘텐츠·분위기(모두 태그)·보증 성우만·정렬이 동작한다. 1,000명에 닿으면 "Fish Audio는 조건마다 처음 1,000명까지만 보여 줘요. 조건을 좁혀 보세요."가 나온다. 인원이 정확하지 않으면 "1,000명 이상"처럼 보인다. 내 계정이 0명이면 빈 상태가 나온다.
- **AC6** Typecast 탭은 T3 동작(브라우저 거르기, 조건 없음은 콘텐츠별 묶음, 묶음마다 5행)을 행 목록으로 보인다.
- **AC7** '더 보기'는 다음 페이지를 이어 붙이고 "200 / 5,953명"처럼 보인 수를 갱신한다. 마지막 페이지에서는 사라진다. 받는 중이거나 조건을 바꿔 다시 받는 중에는 누를 수 없다. 다음 페이지가 실패하면 목록은 그대로 두고 "다음 성우를 불러오지 못했어요. {사유}"를 알린 뒤 같은 버튼으로 다시 시도한다.
- **AC8** 1200px 이상에서 목록을 받으면 첫 행이 골라지고 패널이 채워진다. 샘플은 저절로 재생하지 않는다. 다른 행을 누르면 패널이 바뀐다. 1199px 이하는 행을 누를 때만 서랍(767px 이하는 전체 화면)이 열리고, 닫으면 그 행으로 포커스가 돌아온다.
- **AC9** 패널은 이름, 공급자·출처, 공급자 분류, 설명, 언어별 기본 샘플을 보인다. 이용 조건도 보인다(무료 플랜 불가, 공유 종료 뒤 N일, 실시간 검수, 크레딧 배율, 보증 성우, 공개 종료 중, 제공 성우 종료 예정). 공급자가 주지 않은 값은 보이지 않거나 '정보 없음'이다. 추정하지 않는다.
- **AC10** 샘플은 행과 패널을 통틀어 한 번에 하나만 재생된다. 같은 버튼을 다시 누르면 멈추고, 실패하면 "재생하지 못했어요"와 '다시 듣기'가 나온다. 페이지를 떠나면 멈춘다.
- **AC11** 같은 조건을 24시간 안에 다시 열거나 새로 고침(브라우저)해도 공급자를 부르지 않는다(서버 캐시). 상태 줄에 받은 시각이 보인다. '목록 새로 고침'을 누르면 그 공급자의 열린 목록(지금 목록과 '전체' 묶음)을 다시 받는다. 조건이 '전체' 묶음과 다르면 공급자 호출이 2회다(최종 리뷰 2026-10-05).
- **AC12** 공급자가 실패했을 때 같은 조건의 지난 목록이 있으면 받은 시각과 사유 안내를 붙여 보인다. 없으면 T3 사유별 안내가 나온다. 자동으로 다시 부르지 않는다.
- **AC13** 429에 `Retry-After`가 있으면 그 시각 전에는 그 공급자 목록을 부르지 않는다. 대기 시각 전에는 '다시 불러오기'를 누를 수 없고 안내에 대기 시각이 보이며, 안내가 보이는 동안 상태 줄 '목록 새로 고침'은 숨는다(사용자 결정 2026-10-05, 재확인).
- **AC14** 소유자가 없는 요청은 `UNAUTHORIZED`이고 공급자 호출과 DB 접근이 0회다. 키가 없으면 공급자를 부르지 않는다.
- **AC15** 소유자 A가 받은 계정 목록 캐시는 소유자 B에게 보이지 않는다. B의 새로 고침은 A의 계정 행을 바꾸지 않는다. 공개 목록 행은 둘이 함께 쓴다.
- **AC16** 1440·1280·1200·1024·768·390·320 너비와 라이트·다크에서 승인 시안(T4 영역)과 브리프대로 보인다. 페이지 가로 스크롤이 없다.
- **AC17** 키보드만으로 탭, 출처 전환, 조건, 행 고르기, 샘플 재생·정지, '더 보기', '목록 새로 고침', 서랍 열기·닫기(Esc)를 쓸 수 있다. 접근 이름에 성우 이름과 동작이 들어가고, 재생 상태 변화와 목록 갱신을 스크린 리더에 알린다.
  - 행 목록(`ul`)은 Tab 정지 하나다(roving tabindex, 격자 패턴. 묶음마다 하나). 지금 행의 버튼 하나만 Tab으로 닿고, 처음 지금 행은 고른 성우의 행(없으면 첫 행)이며 포커스가 들어온 행·칸을 기억한다.
  - ↑/↓는 이전/다음 행의 같은 칸, Home/End는 첫/끝 행, ←/→는 같은 행의 재생 ↔ 고르기로 포커스를 옮기고, 옮기기만 해서는 고르지 않는다. Enter·Space는 포커스한 버튼의 기본 동작(재생·정지, 고르기·1199px 이하 서랍 열기)이다.
  - '더 보기' 뒤 포커스는 새 첫 행, '모두 보기 →' 뒤 포커스는 인원 글자로 가고, 새 첫 행이 지금 행이 된다. 세 목록(공급자 탭 목록, Typecast, '전체' 묶음)이 같다(사용자 결정 2026-10-05, 브리프 9절).
- **AC18** 클라이언트 번들에 공급자 SDK·DB 모듈·키가 들어가지 않는다.
- **AC19** 메뉴·작업실 흐름 지도·탭 제목은 T3와 같다("성우 캐스팅 · TTS Pilot").

## 11. 사용자 테스트 절차 (구현 뒤 드린다)

1. 개발 서버와 DB 컨테이너(Podman, 5433)가 켜진 채로 `http://127.0.0.1:3001/casting`을 연다(강력 새로 고침 Cmd+Shift+R). DB가 꺼져 있어도 목록은 보이지만 캐시가 동작하지 않는다.
2. '전체' 탭에서 세 공급자 묶음을 보고 검색어를 하나 넣어 본다.
3. ElevenLabs 탭에서 억양·성별·콘텐츠·분위기·정렬을 바꾸고 '더 보기'를 3번 눌러 본다. 내 계정으로 바꿔 계정 성우를 본다.
4. Fish Audio 탭에서 태그 조건과 정렬을 바꾸고 '더 보기'를 눌러 본다.
5. 행을 골라 패널의 설명·언어별 샘플·이용 조건을 보고, 샘플을 두세 개 연달아 들어 앞 소리가 멈추는지 본다.
6. '목록 새로 고침'을 누르고 받은 시각이 바뀌는지 본다. 창을 좁히거나 휴대폰 너비에서 서랍과 '조건' 버튼을 본다. 다크 테마도 본다.

이번에 없는 것과 언제 오는지: 내 문장 듣기(T5), 채널·분류(T6), 별·담기와 성우 보관함(T7), 프리셋(T8). 시안에서 그 자리만 비어 있다.

## 12. 위험과 확인할 것

- **ElevenLabs 샘플 주소 만료:** `api.us.elevenlabs.io/.../previews/audio?payload=` 주소의 만료 여부를 모른다. 24시간 캐시 안에서 재생이 실패하면 "재생하지 못했어요"가 나온다. 그때는 '목록 새로 고침'으로 새 주소를 받는다. QA에서 받은 지 오래된 캐시로 재생해 보고 결과를 적는다.
- **Fish Audio 응답 시간:** 실측 1.7~11.4초다. 목록 시간 제한을 20초로 두지만, '전체' 탭 첫 로드가 느려 보일 수 있다. 묶음마다 따로 불러오고 따로 보인다. 캐시 뒤에는 공급자를 부르지 않는다.
- **응답 크기:** ElevenLabs 100명 원본 약 0.9MB를 계약 필드로 줄인다(설명 1,000자 자름). Vercel 4.5MB 한도와 멀다. 캐시 행 크기도 같은 수준이다.
- **선택지 고정:** 실측 값으로 만든 선택지는 공급자가 값을 더하면 빠질 수 있다. 행·패널은 모르는 값도 그대로 보인다. 분기마다 다시 확인한다(브리프 6절 확인일).
- **로컬 DB:** Podman 머신이 꺼져 있으면 목록 캐시가 동작하지 않는다. 목록은 캐시 없이 그대로 보이지만(사용자 결정 2026-10-04), 그동안 같은 조건도 매번 공급자를 부르고 429 대기 표도 지켜지지 않는다. 구현 첫 단계에서 띄우고, QA와 사용자 테스트 절차에 "DB 컨테이너가 켜져 있어야 함"을 적는다. 연결 시간 제한 3초로 응답하지 않는 DB를 기다리지 않는다.
- **계정 목록의 클론:** 내 계정의 클론(실측 1명)은 보이기만 한다. 앱의 내 보이스 매핑(T13)과는 별개다. 이 성우로 듣기를 허용할지는 T5에서 정한다.
