## 4. 바꿀 것

### 4.1 `quality`
- 랜드마크: 루트 레이아웃의 소유자 아닌 판 `<main>`을 빼고, 소개 페이지는 막대와 바닥 사이 본문을 `<main>`으로, 로그인은 자기 `<main>`을 둔다. 없는 주소 화면도 어느 판에서든 `<main>` 안에 그려진다.
- 움직임 줄이기(`globals.css`): 전역 규칙이 시간을 0.01ms로 줄이는 대신, 위치·크기 전환과 이동·확대 애니메이션만 멈추고 opacity·색 전환은 남긴다. 무한 반복(스피너·스켈레톤)은 멈춘다. DESIGN.md의 해당 문장을 고친다.
- 휴대폰 메뉴 패널 뒤 흐린 얼룩, FAQ 마스코트 위치(데스크톱).

### 4.2 `font`
- `next/font/local`의 2.06MB 가변 글꼴 하나를 Pretendard v1.3.9 가변 동적 서브셋(woff2 92개, 합계 2.96MB, `unicode-range`)으로 바꾼다. 브라우저는 화면 글자에 필요한 조각만 받는다. 파일은 `apps/web/public/fonts/pretendard/`, `@font-face` CSS는 앱 CSS에 둔다. `--font-pretendard` 변수와 폴백(Arial size-adjust)을 유지한다. 라이선스 OFL 1.1.
- `global-error.tsx`의 두 번째 `localFont`도 없어져 쓰이지 않는 CSS preload(T15-04)가 사라진다.
- 내려받기(raw.githubusercontent.com의 v1.3.9 태그 경로 92개 + CSS 1개)는 파일 목록과 총 크기를 보이고 사용자 확인 뒤 한다.

### 4.3 `demo-mode`
- 서버 환경 변수 `APP_MODE`(`owner` 기본, `demo`, 비밀 아님)를 `.env.schema`에 선언한다. 데모 모드인데 공급자·OpenAI 키가 하나라도 있으면 소유자 없음으로 닫고, 배포 스크립트가 대상별로 모드와 키를 검사한다(본인용에 잘못 켜졌을 때 실제 데이터가 열리지 않게).
- 공개 데모(`demo`):
  - 소유자 판정: 세션 없이 예시 소유자(데모 DB의 `OWNER_EMAILS` 한 명)로 정한다. 소유자 id는 여전히 서버에서만 정하고 클라이언트 입력을 받지 않는다.
  - 로그인·가입·로그아웃 경로와 화면을 막는다(`/login`은 `/studio`로, 기존 auth 라우트가 데모에서 모든 경로 404). 앱 틀(메뉴·`<main>`)은 `(app)` 레이아웃으로 옮겨 소개 페이지가 앱 틀 안에 들어가지 않게 한다. 메뉴의 계정 줄(이메일·로그아웃)은 '공개 데모' 표시로 바꾼다.
  - 공급자: 공급자 클라이언트 대신 데모 클라이언트를 쓴다. 만들기·시험 생성·드라마 장면·문단 작업실은 그 공급자의 데모 샘플을 결과로 저장해 돌려주고(드라마 줄 구간은 없음) 화면이 '데모 샘플' 표시를 붙인다. 성우 목록은 시드에 미리 받아 둔 목록 캐시만 보이고(없는 조합은 데모 안내), 연결 상태·클론 만들기·지우기·자동 태그(OpenAI)·목록 새로 고침은 공급자를 부르지 않고 데모 안내를 보인다.
  - 저장은 허용한다(대본·프리셋·분류·성우 보관함). 데이터는 매일 초기화된다는 안내를 데모 머리 띠에 둔다.
- 본인용(`owner`): `/`는 소개 페이지 없이 로그인(소유자면 `/studio`)으로 간다. 모든 응답에 `X-Robots-Tag: noindex`와 robots 차단을 둔다. 나머지는 T14·T15-a 그대로다.
- 두 모드가 같은 코드라 유료 호출의 이중 방어를 둔다: 데모 환경에는 공급자 키를 넣지 않고(1차), 데모 모드에서는 공급자 모듈을 부르지 않는다(2차, 테스트로 확인).

### 4.4 `samples`
- 한 문장(예: "2026년 3분기 반도체 수출액은 1,523억 달러로 집계됐습니다.", 숫자 검수가 드러나는 문장)을 공급자마다 대표 성우 하나로 만든다. Typecast·ElevenLabs·Fish Audio·Airy·Gemini 최대 5회. 호출마다 공급자·성우·문장·예상 비용을 보이고 승인받는다. ElevenLabs·Airy는 지금 계정 문제(백로그 T15-06)로 실패할 수 있고, 실패하면 그 공급자는 샘플 없이 둔다.
- 출처 표기: Typecast는 "Typecast로 만든 AI 음성 · 성우 {이름} · typecast.ai", ElevenLabs는 제목에 "elevenlabs.io", 모든 샘플에 "AI로 만든 음성"을 보인다(무료 플랜 기준, 약관 조사 2026-11-19). Airy 워터마크는 건드리지 않는다.
- 샘플 파일은 `apps/web/public/samples/` 한 벌을 소개 페이지 재생과 데모 결과가 함께 쓴다.

### 4.5 `demo-data`
- 데모 Neon 프로젝트(싱가포르)를 만든다. 브랜치 `seed`(예시 데이터, 로컬 `tts-pilot-app_shots`를 옮기고 데모 샘플·목록 캐시 포함)와 `main`(데모 앱이 쓰는 브랜치).
- GitHub Actions 예약 작업(하루 1회, 한국 시간 새벽)이 `main`을 `seed`에서 다시 만든다. 데모 프로젝트 범위 Neon API 키를 Main이 `gh secret set`으로 넣는다(사용자 2026-11-19 "gh cli로 직접 넣어줘", 값은 파이프로만). 시드에서는 세션·인증 기록·시도 제한 기록을 비우고 예시 계정 비밀번호를 무작위로 바꾸며 실제 공급자 결과 행을 지운다(목록을 보이고 동의).
- 다크 투어 스크린샷 5장을 예시 데이터로 찍어 소개 페이지 투어에 넣는다.

### 4.6 `landing`
- 소개 페이지는 공개 데모에만 있다. 로그인·소유자 로그인 링크를 모두 뺀다. 주 행동은 '데모 써 보기'(→ `/studio`), 보조는 '기능 둘러보기'(→ `#tour`).
- 재설계: critique(2026-11-18)의 구체성 지적에 따라 제품 구조(문단 카드·공급자·숫자 검수)를 닮은 구성과 소리 재생을 넣는다. 구성안은 브리프를 다시 써서 확인받은 뒤 만든다(이 스펙은 범위만 정한다).

### 4.7 `deploy`
- Vercel: 기존 프로젝트 `omni-ai-tts`(본인용, Neon Storage 연결)를 새 이름(예: `omni-ai-tts-studio`)으로 바꾸고, 공개 데모용 새 프로젝트가 `omni-ai-tts`를 쓴다. 기본 도메인이 이름을 따라오는지는 계획 단계에서 확인한다.
- 환경 변수: 본인용은 지금 값 + `BETTER_AUTH_URL` 새 주소 + `APP_MODE=owner`. 공개 데모는 `DATABASE_URL`(데모 DB), `BETTER_AUTH_SECRET`(새 값), `BETTER_AUTH_URL`, `OWNER_EMAILS`(예시 소유자), `APP_MODE=demo`, 공급자 키·OpenAI 키 없음.
- 배포 스크립트(`scripts/vercel-deploy.mjs`)가 두 프로젝트를 다룰 수 있게 한다(대상 이름 → 프로젝트). 릴리스는 한 번(v0.1.0), 같은 커밋을 두 곳에 배포한다.
- 운영 확인: 본인용(get-session 200, 로그인, 시도 제한 429, `/` → 로그인, noindex), 공개 데모(소개 페이지, 로그인 없이 작업실, 데모 샘플 재생, 클론 막힘, 로그인 경로 막힘, 공급자 호출 0).

## 5. 화면

- 바뀌는 화면: 소개 페이지(공개 데모 `/`), 데모 머리 띠(공개 데모 전 화면), 메뉴 계정 줄(데모 표시), 연결 상태(데모 안내), 결과 표시('데모 샘플' 표시), 클론 화면(데모 안내).
- 소개 페이지 브리프(`docs/briefs/landing.md`)를 다시 써서 확인받는다. 데모 표시는 앱 화면 브리프(`docs/briefs/app-shell.md`)에 절로 더한다.

## 6. 범위

### 만들지 않는 것
- 방문자별 분리 데이터(방문자마다 따로 저장). 다시 넣을 조건: 방문자끼리 내용이 섞여 문제가 생길 때.
- 데모에서 실제 공급자 호출(무료 목록 조회 포함).
- 데모용 가입·계정.
- 커스텀 도메인.
- 데모 사용 분석·로그 수집.
- 본인용 작업실의 소개 페이지.

## 7. 수용 기준

1. 공개 데모 `/`는 소개 페이지이고, 로그인·소유자 로그인 링크가 없다. '데모 써 보기'로 로그인 없이 `/studio`에 들어간다.
2. 공개 데모의 메뉴 9개 화면이 예시 데이터로 열린다. 콘솔 오류 0.
3. 공개 데모에서 만들기·시험 생성·드라마 장면은 데모 샘플을 결과로 보이고 '데모 샘플' 표시가 있다. 듣기·받기가 된다.
4. 공개 데모에서 클론 만들기·지우기, 자동 태그, 목록 새로 고침은 막히고 안내가 나온다. 공급자 HTTP 호출은 0이다(테스트와 운영 확인).
5. 공개 데모에서 `/login`과 Better Auth 로그인 경로는 쓸 수 없다.
6. 방문자가 저장한 대본은 다음 초기화 뒤 사라진다(예약 작업을 한 번 수동 실행해 확인).
7. 본인용 `/`는 로그인으로 가고, 응답에 noindex가 있다. 로그인·시도 제한·데이터는 T15-a 수용 기준 그대로다.
8. 첫 화면 글꼴 전송량이 2.06MB보다 작다(실측 기록). 앱 전체 CSS preload 경고 0.
9. 소개 페이지 막대·바닥이 `<main>` 밖이다(banner·contentinfo). 움직임 줄이기에서 위치 움직임은 멈추고 크로스페이드는 남는다.
10. 다크 테마에서 투어 6탭 모두 다크 스크린샷이다.
11. 디자인 감사 16/20 이상, 접근성 3/4 이상(라운드 기준).
12. v0.1.0 릴리스 하나와 두 production 배포, 운영 확인 기록.
13. 두 배포 모두 한국 밖 접속은 막힌다(Firewall 규칙 또는 코드 안내 화면). 한국에서는 그대로 열린다.

## 8. 자동 테스트 (vitest)
- 모드 판정: `APP_MODE=demo`면 세션 없이 예시 소유자, `owner`면 T14 판정 그대로. 데모에서 클라이언트 입력으로 소유자가 바뀌지 않는다.
- 데모에서 공급자 모듈을 부르지 않는다(공급자 fetch를 가로채 0회 확인): 만들기·시험 생성·드라마·목록·연결 상태.
- 데모에서 클론·자동 태그·목록 새로 고침 거절.
- 데모 샘플 결과의 표시 필드.
- 본인용 `/` 리다이렉트와 noindex, 데모 `/login` 막힘(proxy 테스트).
- 글꼴 CSS의 `@font-face` 92개·`unicode-range`·경로(마크업 테스트).

## 9. 테스트 시나리오
- 정상(데모): 소개 페이지 → 데모 써 보기 → 음성 작업실에서 문단 나누기·숫자 검수 → 만들기(데모 샘플) → 듣기·받기 → 대본 저장 → 대본 보관함에서 다시 열기.
- 막힘(데모): 클론 만들기, 자동 태그, 목록 새로 고침, `/login`, `POST /api/auth/sign-in/email`.
- 본인용: `/` → 로그인 → 메뉴 → 로그아웃 → 보호 화면 차단, 틀린 비밀번호, 시도 제한 429(운영은 동의 뒤 한 번).
- 너비·테마: 1440·768·390, 라이트·다크, 움직임 줄이기.
- 초기화: 예약 작업 수동 실행 전후 저장한 대본 유무.

## 10. 사용자 테스트 (구현 뒤)
1. 로그인하지 않은 브라우저로 `omni-ai-tts.vercel.app`을 열어 소개 페이지에서 소리를 듣고 '데모 써 보기'로 들어간다.
2. 데모에서 대본을 붙여 넣고 만들기를 눌러 데모 샘플을 듣고 받는다. 대본을 저장한다.
3. 클론 화면과 연결 상태 화면의 데모 안내를 본다.
4. 본인용 새 주소에서 로그인해 실제 데이터를 본다.
5. 휴대폰 너비와 다크 테마로 소개 페이지를 본다.

## 11. 경계
- 언제나: 유료 호출(데모 샘플 만들기 5회)은 호출마다 사용자 승인. 운영 DB·데모 DB 쓰기는 목록을 보이고 동의 뒤. 비밀값은 출력·파일·커밋에 남기지 않는다.
- 먼저 묻기: 외부 파일 내려받기(Pretendard), 새 Neon 프로젝트·Vercel 프로젝트 만들기와 이름 바꾸기, 데모 시드 정리 목록, GitHub 비밀값 넣기(Main이 gh로), 릴리스 발행.
- 하지 않기: 데모 환경에 공급자 키·OpenAI 키 넣기, 데모에 Route Handler·Server Action 추가, 본인용 주소를 소개 페이지·README에 노출.

## 12. 위험과 확인할 것
- Vercel 프로젝트 이름을 바꿀 때 기본 도메인이 바뀌는지, 비워진 `omni-ai-tts.vercel.app`을 새 프로젝트가 바로 받을 수 있는지(계획에서 확인, 안 되면 사용자에게 다시 묻는다).
- 공개 데모는 로그인 없이 쓰기가 열려 있다. 입력 길이 제한은 지금 그대로이고, 대량 쓰기로 DB가 차는 것은 매일 초기화와 Neon 용량 한도로 막는다. 반복 쓰기로 Neon 계산 시간(CU-hours)이 소모되는 위험은 사용자가 받아들였다(2026-11-19, 데모에 유료 키가 없어 과금 없음, 한도를 넘으면 데모만 멈춤). 공개 쓰기의 남용(불쾌한 글)은 하루 동안 보일 수 있다.
- 데모 모드가 공급자 경로 하나를 놓치면 키가 없어 실패로 끝난다(과금은 없음). 테스트로 모든 공급자 진입점을 덮는다.
- 배포 스크립트·릴리스 검사가 한 프로젝트를 전제로 쓰여 있다(하네스 변경, 리뷰 필요).
- 약관 해석은 공식 문서 요약에 기댄다. ElevenLabs Voice Library 부속 약관과 Fish Audio 요금 페이지는 읽지 못했다. 샘플은 라이브러리가 아닌 기본 성우로 만든다.
- 라운드가 크다. 묶음마다 검사를 끝내고 다음으로 간다.
