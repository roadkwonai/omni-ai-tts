# T7.6 Gemini 공급자 추가 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Google Gemini TTS를 다섯 번째 공급자로 더해 연결 상태·성우 캐스팅·내 문장 듣기·성우 보관함에서 다른 네 공급자와 같은 방식으로 쓴다.

**Architecture:**
- `packages/api`: 공급자 모듈 `providers/gemini.ts`(REST `fetch`, Airy와 같은 틀)가 네 가지를 맡는다.
  - 연결 확인: `quota: null`.
  - 목록: 한국어 목록과 en-US 목록의 대표 30명. 대표 성우에는 참고 음성을 붙인다.
  - 시험 생성: Interactions, `store: false`, WAV.
  - 한 명 조회: 목록에서 찾는다.
- 오류 판정: Google 오류 본문의 이유·상태를 `geminiCodes`가 읽고, 기존 `reasonFromHttp`에 Google 코드 판정 세 줄을 더해 맡긴다.
- 계약:
  - `providerIdSchema`에 `gemini`, `Voice`에 `pitch`·`personas`, 목록 입력 `{ provider: "gemini" }`.
  - 시험 생성 설정 `geminiSettingsSchema`(`model`·`direction`)와 사용량 단위 `usd_micro`.
  - 생성 기록의 오디오 형식은 공급자별로 저장·전달한다(`audioTypeOf`).
  - 새 프로시저는 없다.
- `packages/db`: 검사 제약만 넓힌다. `saved_voice`·`trial_generation`의 공급자 검사에 `gemini`, `trial_generation` 사용량 단위 검사에 `usd_micro`.
- 화면:
  - 연결 상태 카드 다섯(1280px 이상 3열).
  - 캐스팅 Gemini 탭: 공통 몸통 `OneList` 위에 검색과 조건 여섯. '전체' 탭에는 마지막 묶음.
  - 패널: 참고 음성 칸과 샘플 없음 안내.
  - 내 문장 듣기: 말투 지시 입력, 추정 금액, 무료 등급 안내.
  - 보관함 공급자 필터.

**Tech Stack:** Next.js 16.3 App Router, React 19.3(React Compiler), oRPC 1.15.4, TanStack Query 5.103, zod 4, drizzle-orm·drizzle-kit 1.0.0-rc.4, Postgres(로컬 5433), vitest, shadcn `base-lyra`, Tailwind CSS 4, Biome 2, varlock(환경 변수 스키마), turbo 2.

**Spec:** [T7.6 스펙](T07.6-gemini-provider.md)(사용자 확인 2026-10-13 "확인, 계획으로", 구속력 있는 정본).
- 공급자 계약: [gemini-tts-api-options](../../research/gemini-tts-api-options.md)(16절은 2026-10-13 키로 실측).
- 화면 브리프: [성우 캐스팅](../../briefs/casting.md), [연결 상태](../../briefs/provider-status.md). 18행에서 Gemini 절을 더한다(아래 '브리프에 더할 것').
- 그 밖에: [로드맵 T7.6](../implementation-roadmap.md), `GLOSSARY.md`(참고 음성·말투 지시·예상 사용량).

## 스펙과 다른 점 (계획에서 바꾼 것, 계획 리뷰에서 확인한다)

1. **오디오 상한은 라우터의 공통 검사를 쓴다.** `routers/trial.ts`의 `MAX_AUDIO_BYTES`(4 MiB)를 넘으면 `provider_input`·`audio_too_large`다. Gemini 문구는 "결과 오디오가 너무 커요. 문장을 줄이거나 말투 지시를 바꿔 주세요"다(속도 설정이 없다, R6-1).
   - 스펙 2·6절은 "4.5MB 초과는 `provider_error`"였다. 같은 일을 하는 검사가 이미 있어 모듈에 따로 두지 않는다.
   - WAV 4 MiB는 약 87초다. 200자는 약 40초다.
2. **응답에 오디오가 없거나 WAV가 아니면 `unknown_outcome`(처리 여부 미확인)이다.** `runTrial`은 상태 코드를 받지 못한 모든 실패를 그렇게 다룬다. 돈에 안전한 쪽(자동 재시도 없음, "쓰였을 수 있으니 확인")이다. 스펙 6절의 `provider_error` 대신이다.
   - 단, 응답 `status`가 있고 `completed`가 아니면 안전·정책 차단으로 보고 `provider_input`이다(스펙 6절, 계획 리뷰 R2-3). (구현에서 R2-3·Task 2 수정 1회로 좁힘: 유효한 WAV는 status와 무관하게 쓰고, 오디오가 없을 때 status가 failed면 provider_input, 그 밖은 unknown_outcome)
   - 머리말 없는 PCM에 WAV 머리말을 붙이는 코드는 만들지 않는다. 공식 문서(2026-10-13 재확인)가 기본 형식을 "RIFF 머리말이 있는 WAV, 24kHz 모노 16비트"로 명시한다. RIFF·WAVE 표식만 확인한다.
3. **사용량 단위는 `token`이 아니라 `usd_micro`(추정 금액, 백만분의 1달러, 정수)다.**
   - 금액은 모델(Flash·Flash-Lite)과 날짜(2027-01-01 단가 두 배)에 달려 있다. 생성 때 정한 금액을 기록하면 결과 줄이 다시 계산하지 않는다.
   - `usage_amount`가 정수 칸이라 백만분의 1달러로 담는다. 25토큰 × 단가(달러/100만 토큰)가 늘 정수다.
   - 실제 토큰은 T9가 응답 `usage`로 다룬다.
4. **말투 지시의 코드 이름은 `direction`이다(공급자 본문 필드는 `style`).** ElevenLabs '스타일' 슬라이더(`FIELD_LABEL.style`)·Airy '말투'(`style`)와 이름이 겹치면 `settingsSummary`·`Options`의 `style` 분기가 섞인다. GLOSSARY '말투 지시(Style Direction)'를 따른다.
5. **참고 음성 샘플은 `language: null`, `title: "참고 음성 · Chirp 3 HD"`다.** `sampleLabel`은 언어가 있으면 제목을 보지 않는다("한국어 샘플"이 된다). 스펙 4절의 "언어 `ko`" 대신이다.
6. **Gemini 확인 창에는 '남은 크레딧' 줄이 없고 연결 상태 조회도 하지 않는다.** 잔액 조회 API가 없어 늘 "확인하지 못했어요"가 된다. 스펙 5절은 이 줄을 말하지 않았다.
7. **확인 창 근거에서 모델 이름을 뺀다(계획 리뷰 D12).** 바로 위 '설정' 칸이 모델을 보인다. 근거는 금액 아래 별도 줄 "(Gemini 요금 기준: 유료 등급 1분 $0.0135 · 1초에 5글자로 약 2초 가정)"이고 Airy도 같은 배치다(사용자 결정 2026-10-13).
8. **조건 이름은 스펙 초안의 '말씨' 대신 '억양'이다(사용자 결정 2026-10-13).** ElevenLabs 탭·GLOSSARY와 같은 이름이다. 메타 줄은 "남성 · 피치 낮음 · 서울 억양".

## 계획에서 정한 것 (스펙이 정하지 않은 것)

1. **초당 글자 수 가정은 5다(`GEMINI_CHARS_PER_SECOND`).**
   - 근거: 2026-10-13 로컬 DB에 저장된 한국어 결과 6개(Typecast·ElevenLabs·Fish Audio·Airy, 기본 속도)를 ffprobe로 쟀다. 코드 포인트 기준 5.38~8.26글자/초였고 그 가운데 느린 쪽을 골랐다.
   - 오디오를 길게 어림해 추정 금액이 실제보다 작게 나오지 않게 한다. 근거는 `tasks/evidence/T07.6/`(로컬)에 남긴다.
   - 길이 = 올림(코드 포인트 ÷ 5), 최소 1초다.
2. **Google 오류 판정은 `errors.ts` 한 곳에 더한다(tts-provider '판정은 `reasonFromHttp`가 한다').**
   - `API_KEY_INVALID`(상태와 상관없이) → `provider_auth`.
   - 400 `FAILED_PRECONDITION` → `quota`.
   - `PERMISSION_DENIED`는 `PERMISSION_CODES`에 더해 401·403에서 `no_permission`이 된다.
   - 다른 공급자는 이 대문자 코드를 보내지 않는다. 기존 표는 그대로다.
3. **`geminiCodes`는 `details[].reason` → `status` → 문자열 `code` 순서로 담는다.** 연결 카드는 권한 코드가 아니면 첫 코드를 보인다(`API_KEY_INVALID`가 `INVALID_ARGUMENT`보다 먼저). 메시지는 읽지 않는다.
4. **`CheckOutcome.quota`는 `RemainingQuota | null`이다.** 지금은 `runCheck`가 `remainingQuotaSchema.parse(outcome.quota)`를 해서 `null`이면 '확인 실패'가 된다.
5. **`Voice`에 `pitch: string | null`(기본 `null`)·`personas: string[]`(기본 `[]`)을 더한다.**
   - 기본값은 T7.6 전에 담은 보관함 행(`saved_voice.voice` jsonb)을 다시 읽을 때를 위한 것이다.
   - 성우 계약이 바뀌므로 `CONTRACT_VERSION`을 1 → 2로 올린다(목록 캐시 행이 새로 채워진다).
   - 맥락은 `useCases`, 억양은 `accent`, 언어는 `languages`에 담는다.
6. **대표 성우 30명은 공식 문서 이름표를 소문자 id 고정 목록(`GEMINI_CLASSIC_IDS`)으로 둔다.**
   - 참고 음성 주소는 그 id의 첫 글자를 대문자로 바꿔 만든다(`ko-KR-Chirp3-HD-Kore.wav`). 2026-10-13 HEAD 30개가 모두 200이었다.
   - 성우 정보는 en-US 목록 응답에서만 가져온다.
7. **목록은 두 조회를 함께 부른다.** `type=prebuilt&language_code=ko-KR&page_size=1000`(117명)과 `…en-US…`(215명, 2026-10-13 실측, 대표 30명 모두 포함)이다.
   - en-US 항목은 `toVoice`가 대표 성우가 아니면 `null`을 돌려 기록 없이 거른다.
   - 순서는 한국어 목록 → 대표 성우(공급자 응답 순서)다.
   - 다음 페이지 토큰은 따라가지 않는다. 두 목록 모두 1,000명 안이다(`ponytail:` 주석).
8. **화면의 구분은 `languages`로 판정한다.** `ko-KR`이면 '한국어 성우', 아니면 '대표 성우'다(`geminiKind`). 화면 번들에 30명 목록을 싣지 않는다.
9. **억양 조건의 선택지는 한국어 성우의 값만이다(조건 이름은 '억양', 사용자 결정 2026-10-13).** 대표 성우의 영어 억양 값(`Northwest` 등)은 패널 칩에만 원문으로 보인다. 행 메타 줄에서 대표 성우는 억양 자리에 '대표 성우'를 보인다.
10. **행 메타 줄:** 한국어 성우는 "남성 · 피치 낮음 · 서울", 대표 성우는 "여성 · 피치 높음 · 대표 성우"다. 행 알약(앞 둘)은 콘텐츠(맥락)의 한국어 이름이다. 페르소나는 길어서 패널 칩에만 둔다.
11. **패널 샘플 칸:**
    - 참고 음성이 있으면 제목이 '참고 음성'이고, 아래에 "다른 모델로 만든 같은 이름 성우의 한국어 음성이에요. Gemini 소리와 다를 수 있어요."를 단다.
    - 없으면 제목은 '기본 샘플'이고 "Gemini는 기본 샘플을 주지 않아요. 내 문장 듣기로 들어 보세요."다.
12. **확인 창 근거 줄은 공급자 이름으로 일반화한다:** "(Airy 요금 기준: …)" → "(<공급자> 요금 기준: …)". Gemini 근거는 "유료 등급 1분 $0.0135 · 1초에 5글자로 약 2초 가정"이고 금액 아래 별도 줄이다(R6-3).
13. **무료 등급 안내 한 줄(`GEMINI_DATA_NOTE`)을 둔다:** "무료 등급 키는 과금이 없지만 보낸 문장이 Google 제품 개선에 쓰이고 사람이 검토할 수 있어요". 패널 '내 문장 듣기'의 데이터 안내(`dataNote`)와 확인 창에 함께 쓴다.
14. **Gemini 입력 거절 문구:** "Gemini가 이 문장을 받지 않았어요. 문장이나 말투 지시를 확인해 주세요"(공급자 코드는 보이지 않는다). 한도 부족 문구는 "Gemini 결제나 한도 조건에 걸렸어요. Google AI Studio에서 확인해 주세요"다. 둘 다 새 문구라 `[confirm]`에서 확인한다.
15. **확인 창 제목·버튼의 '크레딧' 문구("크레딧을 써서 들어 볼까요?", '크레딧 쓰고 듣기')는 그대로 둔다.** 다섯 공급자 공통 문구다. Gemini에 어색하면 22행 critique에서 정한다.
16. **연결 상태 3열은 `min-[80rem]:grid-cols-3`이다.** 프로젝트 `xl`은 75rem(1200px)이라 스펙의 1280px과 다르다.
17. **`TRIAL_CONTRACT_VERSION`은 올리지 않는다.** 기존 공급자의 조합 글자는 그대로다.

## Global Constraints

- **커밋:** 태스크마다 하지 않는다. 라운드 끝(`prokit-dev-cycle` 5절)에 메인 세션이 한 번 한다. 각 태스크의 마지막 단계는 "변경 파일 목록 보고"다.
- **비밀값:**
  - `apps/web/.env`·`packages/db/.env`를 읽거나 출력하지 않는다. 키를 출력하지 않는다.
  - 테스트 DB 주소는 `source .superpowers/sdd/T07.6-gemini-provider-plan/tools/testdb.env`로만 넘기고 출력하지 않는다. 메인 세션이 T06 `tools/testdb.env`를 이 경로로 복사해 둔다. 증거에는 "로컬 5433 `tts-pilot-app_test`"만 적는다.
- **공급자를 실제로 부르지 않는다**(`generativelanguage.googleapis.com`, `docs.cloud.google.com` 포함).
  - 자동 테스트는 `fetchMock`(`providers/test-utils.ts`)·가짜 `Providers`로만 한다.
  - 구현 서브에이전트는 개발 서버(`127.0.0.1:3001`)로 어떤 요청도 보내지 않는다(브라우저·curl·fetch·테스트 스크립트의 `/api/rpc/*` 모두). 서버를 끄거나 켜지 않고, `pkill`·`killall`을 쓰지 않는다.
  - 유료일 수 있는 호출(`POST /v1beta/interactions`)은 사용자 테스트 3번에서 사용자가 승인할 때 메인 세션만 한다.
- **테스트 키 문자열은 `sk-`로 시작하지 않는다**(`scripts/dev-cycle.mjs` 비밀 패턴). Google 키 꼴(`AIza…`)도 쓰지 않는다. `test-gemini-key-0001`처럼 쓴다.
- **공급자 공식 문서 재확인**(tts-provider '먼저' 1)은 [gemini-tts-api-options](../../research/gemini-tts-api-options.md)와 2026-10-13 메인 세션 재확인(Interactions REST 예시·응답 경로·기본 WAV, 아래 '설치본·코드로 확인한 것')으로 갈음한다. 구현 서브에이전트는 외부 주소를 열지 않는다.
- **메인 세션만 하는 일:**
  - `db:generate`·`db:migrate`, Neon 임시 브랜치 적용.
  - `pnpm env:generate`(varlock이 `apps/web/src/env.ts`를 다시 만든다), `turbo.json` 수정, `pnpm build`.
  - 브리프·사이트맵 갱신(18행), 테스트 DB env 복사.
  - 패키지 설치는 이번 라운드에 없다.
- **경로와 리뷰:**
  - `packages/api/src/providers/`, `apps/web/.env.schema`, `apps/web/src/context.ts`는 `authPaths`다. 대조표 37행 security 리뷰가 붙어 있다.

## 읽은 스킬과 계획에 반영한 것

- **`tts-provider`:** 공급자 호출은 모듈 하나에 둔다. 공통 계약은 `contract.ts`(화면 번들 안전)에 둔다.
  - 오류는 `ProviderHttpError`로 바꿔 담고 `runCheck`·`runList`·`runTrial` 틀을 쓴다.
  - 목록은 항목 단위로 검사한다(`parseVoiceItems`). 모두 빠지면 `provider_error`다.
  - 유료 호출은 재시도 없음·60초이고 자동 테스트에서 부르지 않는다.
  - 오디오는 `File`로 돌려주고 base64 JSON으로 보내지 않는다. 4.5MB 한도가 있다.
  - 금액은 근거를 함께 보이고, 예상과 실제를 구분한다.
  - 문서 갱신은 Task 7에서 한다.
- **`prokit-api`:** 새 프로시저가 없다. 모든 경로가 기존 `protectedProcedure`이고 소유자는 `context.ownerId`다.
  - 입력 검사는 zod로 한다: 목록 입력 갈래, 모델 열거값, 말투 지시 100자·줄바꿈 없음, 성우 id 정규식.
  - 격리 테스트에 Gemini 한 경우를 더한다(Task 3).
- **`prokit-db`:** 검사 제약만 넓힌다.
  - `pnpm --filter @tts-pilot-app/db db:generate`로 만들고 SQL을 읽어 `DROP TABLE`·`DROP COLUMN`·타입 축소가 없는지 본다. 검사 제약은 drizzle이 DROP CONSTRAINT → ADD CONSTRAINT로 바꾸고, 기존 행은 모두 새 검사를 지난다.
  - 로컬·테스트 DB에 적용한 뒤 다시 generate해 "변경 없음"을 본다.
  - Neon(`.neon` 있음)은 `neon-postgres-branches`로 임시 브랜치에 적용하고 지운다(9행).
  - 컬럼 타입·제약은 `supabase-postgres-best-practices`(schema-constraints)를 따른다. 새 컬럼이 없어 타입 결정은 없다.
- **`prokit-web`:** 목록은 `useQuery(orpc.voiceList.queryOptions(...))`이고 캐시 쓰기는 없다.
  - 같은 쿼리 옵션을 부모(데이터로 거르기)·`OneList`(회복·새로 고침)·탭 이름(인원, `enabled: false`)이 함께 구독한다(키 하나, 요청 하나).
  - 자주 바뀌는 입력은 `useDeferredValue`로 넘긴다(lessons 2026-10-07 T7.5).
  - Server Component(`casting/page.tsx`)는 공급자를 부르지 않는다(문구만 바꾼다).
- **`prokit-ui`:** 브리프(캐스팅 14절 신설, 연결 상태 카드 절)가 기준이다. 새 시각 요소는 없다. 리뷰(critique·audit)는 메인 세션이 한다.

```ts
import type { ProviderId } from "./contract";

// 오디오 src에 넣어도 되는 공급자 샘플 호스트(T3·T4 실측). 목록 변환과 보관함 담기 입력 검사(T7)가 함께 쓴다.
// 화면 번들에 들어가도 되는 값만 둔다(SDK·서버 모듈 import 없음)
export const SAMPLE_HOST = {
	typecast: /(^|\.)typecast\.ai$/,
	elevenlabs: /^(storage\.googleapis\.com|([a-z0-9-]+\.)*elevenlabs\.io)$/,
	fish_audio: /(^|\.)fish\.audio$/,
	// Airy 공개 카탈로그 샘플(2026-10-07 실측 assets.airy.so 하나)
	airy: /^assets\.airy\.so$/,
	// Gemini 대표 성우의 참고 음성(Google Cloud 문서의 Chirp 3 HD 한국어, 2026-10-13 HEAD 30개 200). 경로도 본다(SAMPLE_PATH)
	gemini: /^docs\.cloud\.google\.com$/,
} as const satisfies Record<ProviderId, RegExp>;

// 한 호스트에 다른 파일도 있는 공급자는 경로 접두까지 본다(T7.6 스펙 2절). 없으면 경로를 보지 않는다
const SAMPLE_PATH: Partial<Record<ProviderId, string>> = {
	gemini: "/text-to-speech/docs/audio/",
};

// 샘플 주소가 그 공급자의 허용 호스트(와 경로)인가. URL이 경로를 정규화하므로 '..'로 벗어난 주소는 접두가 맞지 않는다.
// https 검사는 계약(httpsUrl)이 한다
export function isSampleUrl(provider: ProviderId, url: string): boolean {
	if (!URL.canParse(url)) return false;
	const { hostname, pathname } = new URL(url);
	return (
		SAMPLE_HOST[provider].test(hostname) &&
		pathname.startsWith(SAMPLE_PATH[provider] ?? "/")
	);
}
```

```ts
// Gemini 출력 오디오 100만 토큰당 단가(달러). 바뀌는 시각부터 두 배
export const geminiUsdPerMillion = (model: GeminiModel, now = Date.now()) =>
	GEMINI_USD_PER_MILLION[model][now < GEMINI_PRICE_UP_AT ? 0 : 1];
// 가정한 오디오 길이(초). 올림이고 1글자라도 1초다
export const geminiSeconds = (text: string) =>
	Math.max(1, Math.ceil(codePoints(text) / GEMINI_CHARS_PER_SECOND));

// 예상 사용량(스펙 4절). 보낼 문장(태그 포함)으로 센다. ElevenLabs 배율을 모르면 1로 센다(화면이 "배율을 확인하지 못했어요"를 붙인다).
// Gemini는 출력 오디오로 과금되어 가정한 길이 × 25토큰 × 단가를 백만분의 1달러로 담는다(입력 텍스트 요금은 200자에 $0.0001 미만이라 뺀다)
export function estimate(
	request: TrialRequest,
	multiplier: number | null = null,
	now = Date.now(),
): Usage {
	const sent = sentText(request);
	if (request.provider === "fish_audio") {
		return isFreeModel(request)
			? { unit: "free", amount: 0 }
			: { unit: "byte", amount: utf8Bytes(sent) };
	}
	if (request.provider === "gemini") {
		return {
			unit: "usd_micro",
			amount:
				geminiSeconds(sent) *
				GEMINI_TOKENS_PER_SECOND *
				geminiUsdPerMillion(request.settings.model, now),
		};
	}
	const chars = codePoints(sent);
	const rate =
		request.provider === "airy"
			? AIRY_CREDITS_PER_CHAR[request.settings.language]
			: request.provider === "elevenlabs"
				? (multiplier ?? 1)
				: 1;
	return { unit: "credit", amount: Math.ceil(chars * rate) };
```

```ts
export function reasonFromHttp(
	status: number,
	codes: readonly string[] = [],
): ProviderErrorReason | null {
	// Google은 틀린 키를 400 INVALID_ARGUMENT + 이유 API_KEY_INVALID로 답한다(T7.6 스펙 6절). 상태보다 먼저 본다
	if (codes.includes("API_KEY_INVALID")) return "provider_auth";
	if (status === 401 || status === 403) {
		return codes.some((code) => PERMISSION_CODES.has(code))
			? "no_permission"
			: "provider_auth";
	}
	if (status === 402) return "quota";
	if (status === 429) return "rate_limit";
	// Google 400 FAILED_PRECONDITION은 결제·지역 같은 계정 조건이다(입력 거절이 아니다). 확정은 실측 뒤(T7.6 스펙 6절)
	if (status === 400 && codes.includes("FAILED_PRECONDITION")) return "quota";
	if (status === 400 || status === 422) return "provider_input";
	if (status >= 500 && status <= 599) return "provider_error";
	return null;
}
```

```ts
export function filterGemini(
	voices: readonly Voice[],
	query: string,
	filters: GeminiFilters,
): Voice[] {
	const needle = normalize(query);
	return voices.filter(
		(voice) =>
			(needle === "" ||
				normalize(voice.name).includes(needle) ||
				voice.voiceId.toLowerCase().includes(needle) ||
				normalize(voice.description ?? "").includes(needle)) &&
			anyOf(filters.kinds, [geminiKind(voice)]) &&
			anyOf(filters.genders, [voice.gender]) &&
			anyOf(filters.pitches, [voice.pitch]) &&
			anyOf(filters.accents, [voice.accent]) &&
			anyOf(filters.contexts, voice.useCases) &&
			anyOf(filters.personas, voice.personas),
	);
```

```ts
export function geminiOptions(
	voices: readonly Voice[],
): Record<keyof GeminiFilters, Option[]> {
	const sets = {
		kinds: new Set<string>(),
		genders: new Set<string>(),
		pitches: new Set<string>(),
		accents: new Set<string>(),
		contexts: new Set<string>(),
		personas: new Set<string>(),
	};
	for (const voice of voices) {
		const kind = geminiKind(voice);
		sets.kinds.add(kind);
		if (voice.gender) sets.genders.add(voice.gender);
		if (voice.pitch) sets.pitches.add(voice.pitch);
		if (voice.accent && kind === "korean") sets.accents.add(voice.accent);
		for (const value of voice.useCases) sets.contexts.add(value);
		for (const value of voice.personas) sets.personas.add(value);
	}
	return {
		kinds: ordered(sets.kinds, GEMINI_KIND_LABEL),
		genders: ordered(sets.genders, GENDER_LABEL),
		pitches: ordered(sets.pitches, GEMINI_PITCH_LABEL),
		accents: ordered(sets.accents, GEMINI_ACCENT_LABEL),
		contexts: ordered(sets.contexts, GEMINI_CONTEXT_LABEL),
		// 이름표가 없어 공급자 값 그대로, 알파벳순
		personas: [...sets.personas]
			.sort((a, b) => a.localeCompare(b, "en"))
			.map((value) => ({ value, label: value })),
	};
}
```
