## 1. 목표

성우 캐스팅에서 마음에 든 성우를 담고, 즐겨찾기·자주 사용·메모·채널·카테고리·타입을 붙인 뒤, `/voices`에서 필터로 다시 찾는다. 새로 고침 뒤에도 남고, 분류를 지워도 성우는 남으며, 공급자 목록에서 사라진 성우는 기록을 지키며 "현재 이용 불가"로 보인다.

뒤 TASK가 그대로 쓸 것을 만든다.
- `saved_voice` 테이블. 작업실 성우 고르기(T9)가 담은 성우를 먼저 보이고, 최근 사용·사용 횟수(T9)와 프리셋 포함 필터(T8)가 이 행에 붙는다. 내 보이스(T13)도 같은 담기 흐름을 쓴다.
- 성우 상세 조회(공급자별 한 명 조회). 시험 생성·생성의 성우 허용 검사(tts-provider '클론 보이스' 절)가 같은 호출을 쓸 수 있다.

## 3. 데이터와 API

**테이블** (`packages/db/src/schema/saved-voice.ts`)

| 표 | 컬럼 | 제약 |
|---|---|---|
| `saved_voice` | `id` uuid, `owner_id` text, `provider` text(`typecast`·`elevenlabs`·`fish_audio` check), `voice_id` text, `source` text(`public`·`account` check), `favorite` bool 기본 false, `frequent` bool 기본 false, `memo` text null, `voice` jsonb(계약 `Voice`), `unavailable` bool 기본 false, `checked_at` timestamptz null, `saved_at` timestamptz 기본 now | 유니크 `(owner_id, provider, voice_id)`. 인덱스 `(owner_id, saved_at)` |
| `saved_voice_channel` | `saved_voice_id` uuid → `saved_voice.id` cascade, `channel_id` uuid → `channel.id` cascade | 기본 키 두 컬럼, 인덱스 `channel_id` |
| `saved_voice_classification` | `saved_voice_id` uuid → `saved_voice.id` cascade, `classification_id` uuid → `classification.id` cascade | 기본 키 두 컬럼, 인덱스 `classification_id` |

- 메모는 T6 메모 규칙(`cleanText`, 0~200자, 비면 null)을 그대로 쓴다.
- `voice` jsonb는 저장·읽기 모두 `voiceSchema`로 검사한다. 읽을 때 검사에 실패한 행(계약이 바뀐 옛 행)은 이름 자리에 성우 id를 보이고 다음 확인에서 새 값으로 바뀐다.

**프로시저** (모두 `protectedProcedure`, 소유자는 `context.ownerId`만. 평평한 이름 + 접두어 관례)

| 프로시저 | 입력 | 하는 일 |
|---|---|---|
| `savedVoiceList` | 없음 | 이 소유자의 담은 성우 전부 `{ id, voice, favorite, frequent, memo, unavailable, channelIds, classificationIds }`, 최근 담은 순. 성우 캐스팅의 별·행 칩·담기 칸도 이 목록으로 "담겼는지"를 안다 |
| `savedVoiceSave` | `{ voice, favorite?, frequent?, memo? }` | 담기이자 바꾸기. 공급자 + 성우 id로 upsert한다: 없으면 만들고, 있으면 저장한 정보·출처와 준 필드만 바꾼다. 같은 성우를 동시에 두 번 담아도 한 행(유니크 + `on conflict`) |
| `savedVoiceLinks` | `{ voice, channelIds, classificationIds }` | 그 성우를 담고(이미 있으면 정보·출처를 넘긴 값으로 바꾸고, `savedVoiceSave`와 같다) 연결을 이 목록으로 바꾼다(한 트랜잭션). 목록의 채널·분류가 하나라도 이 소유자 것이 아니거나 없으면 `NOT_FOUND`이고 아무것도 바꾸지 않는다(담기까지 되돌린다). 각 목록 최대 50개 |
| `savedVoiceRemove` | `{ id }` | 보관함에서 뺀다(연결도 함께 지워짐). `{ deleted: true }`. 없거나 남의 것이면 `NOT_FOUND` |
| `savedVoiceCheck` | 없음 | 확인 시각이 없거나 24시간이 지난 행 가운데 가장 오래된 40명을 공급자 상세 조회로 확인하고 갱신한 뒤 `savedVoiceList`와 같은 목록을 돌려준다. ElevenLabs 공개 라이브러리 성우는 빼고, 공급자마다 동시 2건, 한 건 10초 제한. 키 없는 공급자·대기 시각 전인 공급자는 건너뛴다. 429면 대기 시각(없으면 1분 뒤)을 적고 그 공급자의 남은 확인을 멈춘다 |

- `channelList`·`classificationList` 출력에 `voiceCount`(연결된 성우 수)를 더한다.
- **담기의 `voice` 입력:** 클라이언트가 목록에서 받은 값을 보낸다. 서버는 `voiceSchema`와 공급자별 샘플 호스트 검사(목록 모듈과 같은 함수)를 다시 거친다. 소유자 한 명의 자기 데이터이고 다음 확인에서 공급자 값으로 바뀐다.
- **상세 조회(공급자 모듈에 `getVoice`):** 결과는 `Voice` 또는 "없음". 무료 조회만 쓴다.
  - Typecast `GET /v3/voices/{id}`.
  - Fish Audio `GET /model/{id}`(403과, 응답이 왔지만 합성할 수 없게 된 성우(학습 전·삭제 요청·공개 출처인데 비공개)도 "없음"으로 본다. 목록 규칙과 같다).
  - ElevenLabs 계정 성우 `GET /v1/voices/{id}`(404만 없음). 공개 라이브러리 성우는 한 명 조회 방법이 공식 문서에 없어(2026-10-07 조사) 확인하지 않고 저장한 정보를 그대로 쓴다(이용 불가로 만들지 않는다). 확인에 성공해도 담을 때 고른 샘플 언어를 지킨다.
  - 세 조회 모두 과금 문구가 문서에 없다(무료라고 명시하지도 않는다). 목록 조회와 같은 읽기 호출로 다룬다.
  - 공급자 오류는 기존 매핑(`errors.ts`)을 쓰고 로그에는 공급자·상태 코드만 남긴다.

## 4. 화면과 흐름

**성우 캐스팅 `/casting`**
- **행의 별:** 행 오른쪽 끝에 별 버튼(44px, `aria-pressed`, 접근 이름 '{이름} 즐겨찾기', 툴팁 '즐겨찾기'/'즐겨찾기 해제')을 둔다.
  - 누르면 바로 저장된다(담기지 않은 성우면 담기면서 즐겨찾기).
  - 연타는 차례로 보내고 마지막 상태가 남는다.
  - 담은 성우 목록이 오기 전·실패면 누를 수 없다(툴팁에 이유).
  - 실패하면 별이 서버 값으로 돌아가고 알림 "저장하지 못했어요. 잠시 뒤 다시 해 주세요."
- **행의 roving 칸:** 별이 더해진다(재생 → 고르기 → 내 문장 듣기 → 별). 안내는 '방향키로 성우와 버튼 사이를 옮겨요'.
- **담은 성우의 행:** 공급자 알약 자리에 내 분류 칩(채널 → 카테고리 → 타입, 최대 2 + '+N')을 두고, 이름 옆에 '자주 사용' 배지를 둔다. 이용 불가면 배지 맨 앞에 '현재 이용 불가'.
- **성우 패널의 '담기' 칸('내 문장 듣기' 뒤, '내 문장 결과' 앞):**
  - 담은 성우 목록이 오기 전에는 뼈대, 실패면 한 줄과 '다시 불러오기'를 보인다.
  - 머리 '담기'. 저장 중이면 옆에 스피너가 돈다(컨트롤은 막지 않는다).
  - 즐겨찾기 윤곽 토글 버튼, 자주 사용 스위치.
  - 붙은 분류는 그룹마다 한 줄이다(왼쪽 회색 그룹 이름, 윤곽 칩, 그룹 안은 T6 이름순).
    - 칩의 ×는 접근 이름 '{그룹} {이름} 떼기'.
    - 뗀 뒤 포커스는 같은 그룹 다음 칩 → 이전 칩 → '분류 붙이기'로 간다.
  - '분류 붙이기'(링크 모양)를 누르면 담기 칸 안에서 펼쳐진다.
    - 검색 칸 '이름으로 찾거나 새로 만들기'와 그룹별 체크 목록(이름순)이 있다.
    - 검색어와 같은 이름이 그룹에 없으면 그룹마다 "+ ‘{검색어}’ {그룹} 만들기"가 나온다.
    - 체크하면 바로 저장된다. 만들기는 T6 이름 규칙·중복 검사를 그대로 받는다(중복이면 그 항목을 붙인다).
    - Esc나 버튼을 다시 누르면 접힌다.
  - 메모: 2~3줄 칸, 'N / 200자', 바뀌었으면 "저장하지 않은 변경이 있어요", 바뀌었을 때만 눌리는 '메모 저장'.
  - 담긴 성우면 맨 아래에 회색 글자 버튼 '보관함에서 빼기'를 둔다.
    - 확인 창: "‘{이름}’ 성우를 보관함에서 뺄까요? 즐겨찾기·자주 사용·메모·분류 연결도 함께 지워져요." '취소'·'빼기'(destructive).
    - 성공하면 알림 "‘{이름}’ 성우를 보관함에서 뺐어요."
  - 담기 칸의 모든 동작은 담기지 않은 성우에서도 된다(처음 하는 동작이 담기다).
- **ElevenLabs 공개 라이브러리 성우를 담은 경우:** 패널에 "공개 라이브러리 성우는 이용 가능 여부를 확인하지 않아요".

**`/voices` 성우 보관함**
- **페이지 머리:** 제목 '성우 보관함', 설명 한 줄(문구는 브리프).
- **조건 줄(캐스팅 문법):**
  - 이름 검색, 보기(전체·즐겨찾기·자주 사용 세 칸), 공급자(단일 드롭다운), 채널·카테고리·타입(그룹마다 여러 개 고르는 드롭다운, '카테고리 · 2').
  - 767px 이하는 검색 + '조건' 버튼으로 접는다.
  - 값은 주소 쿼리(`q`, `view`, `provider`, `channel`, `category`, `type`)에 남는다. 검색어는 0.5초 멈춘 뒤 주소에 쓴다.
- **상태 줄:** "담은 성우 40명" / "담은 성우 40명 중 12명", 이용 불가가 있으면 " · 현재 이용 불가 N명", 확인 중이면 " · 이용 가능 여부를 확인하고 있어요". 조건이 있으면 '조건 모두 해제' 링크.
- **목록:** 캐스팅과 같은 행(별, 내 분류 칩, 내 문장 듣기 없음), 최근 담은 순.
- **패널:** 캐스팅 패널과 같은 머리·설명·기본 샘플·이용 조건 + 담기 칸. 이용 불가면 패널 위에 "공급자 목록에서 찾을 수 없어요. 저장해 둔 정보로 보여요. 메모와 분류는 그대로 남아 있어요."
- **확인 중:** 목록은 저장한 정보로 먼저 보이고, 확인이 끝나면 결과로 바뀐다. 확인이 실패해도 목록은 그대로다.
- **조건에서 빠지는 행:** 고른 성우가 조건에서 빠지면(별·자주 사용 해제, 빼기) 다음 행 → 이전 행을 고른다. 포커스가 사라졌으면 그 행으로, 행이 없으면 상태 줄로 보낸다. 서랍은 닫힌다.
- **빈 상태:**
  - 빈 보관함: "아직 담은 성우가 없어요" + '성우 캐스팅에서 찾기'(화살표 아이콘).
  - 조건에 맞는 성우 없음: "조건에 맞는 성우가 없어요" + '조건 모두 해제'(누르면 검색 칸으로 포커스).
- **그 밖의 상태:** 로딩(행 뼈대 5줄)·목록 오류('다시 불러오기')·소유자 없음(`LoopbackNotice` "이 주소에서는 성우 보관함을 쓸 수 없어요")은 T6과 같은 문법.
- **좁은 화면:** 1199px 이하 패널은 캐스팅처럼 서랍.

**`/classes` 채널·분류**
- 행의 메모 뒤, 채널 주소 링크 앞에 '성우 N명' 링크(화살표 아이콘) → `/voices?channel=<id>`(카테고리는 `category=`, 타입은 `type=`). 0명이면 없다.
- 삭제 확인 창 설명 뒤에 "연결된 성우 N명은 보관함에 그대로 남고, 이 {그룹} 연결만 풀려요."(0명이면 없음).

**앱 틀**
- 메뉴 '성우 보관함'을 '다음에 열릴 화면'에서 열린 화면으로 옮긴다(`/voices`, 아이콘 그대로, `bar: false`, '성우 캐스팅' 바로 뒤). 휴대폰 위 막대 4칸은 그대로다.
- 사이트맵 '준비 중'에서 성우 보관함을 지우고 페이지 표에 `/voices` 행을 더한다.

## 8. 수용 기준

1. 세 공급자 성우를 캐스팅 행의 별과 패널에서 담을 수 있고, 새로 고침 뒤에도 별·자주 사용·메모·분류가 그대로다.
2. 즐겨찾기와 자주 사용은 따로 켜고 끈다. 둘 다 꺼도 보관함에 남고, '보관함에서 빼기'(확인 창)로만 빠진다.
3. 같은 성우(공급자 + 성우 id)는 공개·계정 어느 쪽에서 담아도, 동시에 두 번 눌러도 한 행이다.
4. 채널·카테고리·타입을 여러 개 붙이고 뗄 수 있다. 펼친 목록에서 없는 이름을 만들어 바로 붙일 수 있고, 같은 이름이 있으면 그것이 붙는다.
5. `/voices`에서 검색·보기·공급자·채널·카테고리·타입 필터가 2절 규칙(그룹 안 OR, 그룹끼리 AND)대로 걸리고, 주소를 새로 고쳐도 필터가 남는다.
6. 분류·채널을 지우면 연결만 풀리고 성우는 보관함에 남는다. 삭제 확인 창과 `/classes` 행에 연결된 성우 수가 보이고, '성우 N명'은 그 항목으로 걸러진 `/voices`로 간다.
7. 공급자 상세 조회가 404인 성우는 '현재 이용 불가'로 보이고, 기록(메모·분류)은 남는다. 다른 실패는 표시를 바꾸지 않는다. 확인은 24시간에 한 번이다.
8. B 소유자는 A의 담은 성우를 보지 못한다. A의 담은 성우 id로 빼기, A의 채널·분류 id로 연결하기는 `NOT_FOUND`이고 A의 행과 '성우 N명'은 그대로다. A의 성우와 같은 성우를 B도 따로 담을 수 있다.
9. 소유자가 없으면 프로시저 5개가 모두 `UNAUTHORIZED`이고 DB·공급자 접근이 0회다.
10. 자동 테스트·브라우저 QA에서 유료 호출(생성·시험 생성·클론)이 0회다. 상세 조회는 가짜 공급자로 시험한다.
11. 1440·1280·1024·768·390·320px, 라이트·다크에서 가로 넘침이 없고, 키보드만으로 별·담기 칸·분류 붙이기·필터를 쓸 수 있다.
12. 오류 예산(콘솔·개발 오버레이·`get_errors`·서버 로그) 0.

## 9. 자동 테스트

- **API(`saved-voice.test.ts`, 테스트 DB):** 담기 왕복, 같은 성우 다시 담기(한 행, 정보 갱신, 준 필드만 바뀜), 동시 담기 두 번 → 한 행. 바꾸기(빈 패치 `BAD_REQUEST`, 메모 정리·200/201). 연결 바꾸기(추가·제거, 50개 상한, 없는 id 하나 섞이면 아무것도 안 바뀜). 채널·분류를 지우면 연결만 사라짐. 빼기하면 연결도 사라짐. `voiceCount`. 잘못된 `voice`(샘플 호스트·스킴) 거절. 확인: 404 → 이용 불가, 200 → 정보 갱신·이용 가능으로 되돌림, 5xx·타임아웃 → 그대로, 24시간 안 된 행은 조회 0회, 429 → 대기 시각 기록과 그 공급자 나머지 조회 0회, 키 없는 공급자 0회.
- **격리(`saved-voice.isolation.test.ts`):** 8절 8·9번. B가 A의 채널·분류 id를 자기 성우에 붙이면 `NOT_FOUND`.
- **공급자(`*.test.ts`, 가짜 fetch):** `getVoice` 공급자별 200 → 계약 변환, 404(Fish Audio 403 포함) → 없음, 오류 매핑.
- **화면 단위(web vitest):** 필터(그룹 안 OR, 그룹끼리 AND, 검색), 쿼리 ↔ 필터 변환(모르는 값 무시), 연결 수 문구.

## 10. 테스트 시나리오 (브라우저 QA)

공급자 목록·상세 조회는 무료 조회이지만 QA에서는 목록 캐시와 가짜 응답을 우선 쓰고, 실제 조회 수를 서버 로그로 센다. 생성·시험 생성 버튼은 누르지 않는다.

| # | 시나리오 | 기대 |
|---|---|---|
| S1 | 빈 보관함으로 `/voices` 열기 | 빈 상태와 '성우 캐스팅에서 찾기' |
| S2 | 캐스팅에서 세 공급자 성우를 별로 담기, 패널에서 자주 사용·메모 | 별 채워짐, `/voices`에 최근 담은 순 |
| S3 | 패널에서 채널 1·카테고리 2·타입 1 붙이기, 펼친 목록에서 없는 카테고리 만들어 붙이기 | 칩 그룹별 이름순, `/classes`에 새 항목과 '성우 N명' |
| S4 | 별·자주 사용 끄기 | 보관함에 남음 |
| S5 | `/voices` 필터 조합(검색, 즐겨찾기, 공급자, 카테고리 2개 OR, 채널과 AND), 새로 고침 | 결과 일치, 필터 유지, 조건 없음 상태와 '조건 모두 해제' |
| S6 | `/classes`에서 연결된 카테고리 지우기 | 확인 창에 성우 수, 지운 뒤 성우 남음·칩 사라짐 |
| S7 | '성우 N명' 링크 | 그 항목으로 걸린 `/voices` |
| S8 | '보관함에서 빼기' → 취소, 다시 → 빼기 | 취소는 그대로, 빼기는 사라지고 캐스팅 별도 꺼짐 |

## 11. 사용자 테스트 절차 (구현 뒤 드린다)

먼저 알린다: 이번에 없는 것과 그 TASK — 최근 사용·사용 횟수(T9), 프리셋과 프리셋 포함 필터(T8), 작업실에서 담은 성우 고르기(T9), 보관함 패널의 내 문장 듣기(넣지 않기로 함).

1. 성우 캐스팅에서 Typecast·ElevenLabs·Fish Audio 성우를 하나씩 별로 담는다.
2. 한 성우의 패널에서 자주 사용을 켜고, 메모를 저장하고, 채널·카테고리·타입을 붙인다. 없는 카테고리를 '분류 붙이기'에서 만들어 붙여 본다.
3. 메뉴 '성우 보관함'(휴대폰은 더보기 안)으로 `/voices`를 열고 필터로 다시 찾는다.
4. '채널·분류'에서 붙인 카테고리를 지우고, 성우가 보관함에 남는지 본다.
5. 새로 고침해서 그대로인지 본다.

## 12. 위험과 확인할 것

- ElevenLabs 공개 라이브러리 성우는 확인하지 않는다(3절). 그 샘플 주소가 만료되면 캐스팅에서 다시 담을 때(별 등) 새 값으로 바뀐다.
- 상세 조회가 무료인지: Typecast·ElevenLabs·Fish Audio 문서에서 조회 호출 과금 문구를 다시 확인한다(Fish Audio는 요금표에 조회 항목이 없다, research 문서).
- ElevenLabs 샘플 주소(`previews/audio?payload=`)가 만료되는지. 만료되면 확인이 24시간마다 새로 받는 것으로 충분한지 QA에서 본다.
- 행에 별 칸이 늘면 좁은 목록 칸(`@container`)에서 이름이 줄어든다. 320px에서 확인한다.
- `savedVoiceCheck`가 오래 걸리는 것: 한 번에 40명, 공급자마다 동시 2건 × 10초 제한이라 최악(한 공급자에 40명이 모두 시간 초과)은 200초다. 화면은 저장한 정보로 먼저 보여 기다리지 않는다.
