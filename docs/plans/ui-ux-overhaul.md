"투박함"의 공통 원인
1. 모든 컨트롤이 같은 무게의 테두리 상자다(청록 outline 32곳, 회색 테두리 37곳, 버튼 전부 굵게). 화면당 주 행동 하나가 안 보인다.
2. 규격이 없다: 본문 폭 768/1024/1096px, 페이지 머리 3가지, 빈 상태 2가지 모양, 간격 12/16/32/40 혼용.
3. 프리미티브 기본 크기(32px)와 제품 크기(44px)가 달라 `size="lg"` 오버라이드가 156곳이다.
4. 사이드바 9개가 한 덩어리이고 미구현 '다음에 열릴 화면'이 메뉴에 있다.
5. 앱은 색 전환만 있어 대화상자·재생 상태·탭이 순간 이동한다(DESIGN.md 761행 결정).
6. 랜딩은 히어로 뒤로 '듣는 제품' 인상이 약해지고, 핵심인 문단 작업실이 한 줄에 묻혀 있다.

## 1. 랜딩 3판 (새 작업 → 브리프 3판부터)

메시지 위계: 큰 약속 하나 + 매력 넷 + 안심 띠.

| # | 섹션 | 바뀌는 점 |
|---|---|---|
| 1 | 히어로(작동하는 문단 카드) | 헤드라인·부제 교체, "목소리를 눌러 들어 보세요" 안내, 로드 전 시간 `--:--` |

| 3 | 들어 보고 고른다 | 신규: 캐스팅 화면 크롭 + 기본 샘플 재생, 내 문장 듣기, 보관함·채널·프리셋 |
| 4 | 태그라인 | 문구만 교체(대비·모션은 다른 세션) |
| 5 | 문단마다 다르게 연기 | 신규, 가장 큰 섹션: 크롭 3컷(문단 카드 / 태그 도구줄·감정 팔레트 / 받기 막대) 좌우 교차, 자동 태그·이어 듣기·저장된 결과 |
| 6 | 숫자를 제대로 읽는다 | 혜택 한 줄 → 짧은 독립 섹션(숫자 검수 창 크롭) |
| 7 | 드라마와 내 목소리 | 짝 카드 둘(화자 색 칩, 새 마스코트 컷) |
| 8 | 받기와 안심 | 3열 작은 카드: 받기 형식, 유료 호출 전 확인·저장된 결과 재사용, 연결 상태·남은 사용량 |
| 9~13 | 작동 방식 3단계 · 화면 투어(크게) · 만든 방법 · FAQ(순서 변경) · 마지막 CTA(문구 교체) | 유지·강화 |

헤드라인 후보: ① 같은 문장을 다섯 성우에게 읽혀 보세요(추천) ② 어떤 목소리가 맞는지, 들어 보고 고르세요 ③ 대본 하나, 성우는 마음대로.
용어: 본문에서 '공급자'는 '음성 서비스'나 서비스 이름으로, '담는다'는 '저장해 둔다'로. '공급자'는 FAQ·만든 방법에만 남긴다.
시각: DESIGN.md 세계 유지. 섹션 배경 교차(background/card), 제목 크기 위계 강화, 같은 모양 3번 연속 금지, 화면은 전체 축소 대신 크롭.
