# 랜딩 4판 기획 제안 — "들려주고, 만져 보게 하고, 숫자로 증명한다" (2026-11-19, 사용자 확인 전)

근거: 서비스 임팩트 전수 조사(기능 18개, 문서·코드·공개 데모 화면), 외부 랜딩 리서치(ElevenLabs, Typecast, Fish Audio, Murf, WellSaid, Speechify, Vrew, Descript, Suno, Raycast, Replicate, Vercel, Linear, 포트폴리오 사례), 3판 critique(21/28)·audit(19/20).

## 1. 지금 랜딩(3판)의 진단 — 왜 임팩트가 약한가

3판은 기능을 빠짐없이 소개했지만 **"설명하는 랜딩"**이다. 임팩트는 설명이 아니라 증명에서 나온다.

| 약점 | 사실 |
|---|---|
| 방문자가 직접 만지는 순간이 1곳 | 히어로 카드(칩 5개 + 원문/발음용 토글)뿐. 나머지는 이미지와 글 |
| 소리로 증명하는 곳이 1곳 | 연기 태그·드라마 장면·쉼 같은 핵심 주장이 모두 그림과 글, 소리 없음 |
| 히어로 약속이 4/5만 성립 | Airy 샘플이 다른 문장. 재생 전에는 잠긴 플레이어처럼 보임 |
| 숫자가 없다 | 성우 규모·코드 규모·설계 규모가 '만든 방법' 글 속에만. 테스트 수 문구(1,900여 개)도 실제 집계(약 1,838개)와 어긋남 |
| 데모가 약속보다 비어 있다 | 데모 작업실은 빈 화면에서 시작, 대본 보관함에 QA 잔재, 만들기는 어떤 문장이든 같은 소리 |

외부 리서치의 교훈: 강한 음성 랜딩은 **첫 화면에서 소리를 만지게** 하고(Fish Audio: 태그를 눌러 넣고 바로 듣기), **같은 문장의 대비로 차이를 들려주며**(Typecast: 감정만 바꾼 A/B), **측정 조건이 붙은 숫자**로 증명한다(Murf). 반대로 소리 제품인데 소리를 안 들려주는 랜딩(Vrew, Speechify)은 약하다. 포트폴리오 방문자에게는 로고 월·사용자 수 대신 **실측 수치와 설계 결정**이 먹힌다.

## 2. 콘셉트

**"들려주고(Listen) → 만져 보게 하고(Try) → 숫자로 증명한다(Trust)"**

랜딩을 다섯 개의 **증명 장면**으로 짠다. 장면마다 "▶ 들어 보기" 또는 "직접 해 보기" 하나가 있고, 마스코트가 장면 안내자로 등장한다. 글은 장면을 설명하는 한두 줄로 줄인다.

## 3. 임팩트 재료 Top 7 (조사 결과)

| 순위 | 재료 | 왜 '와' 하는가 | 증명 형태 | 자산 |
|---|---|---|---|---|
| 1 | 한국어 숫자 읽기 엔진 | 한국어 TTS의 고질병(숫자 오독)을 정면으로 푼다. 브라우저에서 바로 돈다 | **방문자가 직접 문장을 넣는 놀이터** | 있음(`number-reading.ts` 재사용, 서버·유료 호출 0) |
| 2 | 같은 문장, 다섯 서비스 | 한 문장이 다섯 소리로 갈린다 | 파형 5줄 나란히 + 차례로 듣기 | 있음(Airy만 다른 문장) |
| 3 | 같은 문단, 다른 연기 | 태그 하나로 연기가 바뀐다 | 태그 칩을 누르면 대본에 꽂히고 그 소리가 난다 | 새 샘플 2~4개(Fish 무료 모델) |
| 4 | 드라마 다화자 장면 + 대사별 파일·자막 | 두 사람이 대화하고, 한 번 만든 장면이 줄별 파일·SRT로 자동 분해 | 장면 플레이어(자막 줄 강조) + 분해 도해 | 새 샘플 1개(Fish 무료), 단어 타임스탬프 데이터 있음 |
| 5 | 비용 0 설계 | 같은 문단은 다시 만들지 않고, 유료 호출 전엔 늘 확인 | 짧은 재현 장면("다시 눌러도 호출 0, 크레딧 0") | 화면 재현(소리 없음) |
| 6 | 만든 규모·설계 | 개인이 8주에 이만큼 설계했다 | 숫자 띠 + 아키텍처 한 장 | 집계만 확정(코드 약 5.8만 줄, 테스트 약 1,838개·107파일, ADR 15, 약 8주) |
| 7 | 내 목소리 클론 + 원본 비보관 | 내 목소리로 성우를 만들되 원본은 남기지 않는다 | 동의 흐름 화면 + 신뢰 문구 | 본인용에서 동의 화면 촬영(유료 호출 없음) |

## 4. 제안 구성 (4판)

| # | 섹션 | 장면 | 방문자가 하는 일 | 지금 대비 |
|---|---|---|---|---|
| 0 | 막대 | 들어 보기 · 해 보기 · 드라마 · 만든 방법 · FAQ, 오른쪽 '데모 작업실 열기' | — | 메뉴 이름만 |
| 1 | **히어로: 오디션 무대** | 헤드라인 + 같은 문장 하나, 아래 다섯 서비스의 **파형 5줄**(각 줄에 서비스·성우 이름). '모두 이어 듣기'를 누르면 위에서부터 차례로 재생되고 재생 중인 줄만 파형이 움직인다. 줄을 눌러 하나만 듣기도 된다 | 듣는다 | 칩 5개 → 나란한 파형 무대. 소리 비교가 첫 장면의 주인공 |
| 2 | **숫자 놀이터** `#try` | "숫자가 든 문장을 넣어 보세요" 입력칸 + 예시 칩(‘2026년 3분기’, ‘1,523억 달러’, ‘3.5%’, ‘10:30’, ‘3월 5일’ 등). 입력하는 대로 아래에 한글 읽기가 나오고 바뀐 부분만 강조. "이 읽기로 들어 보기"는 히어로 문장일 때만 실제 소리 | 직접 해 본다 | **새 인터랙션.** 이 서비스만의 기술을 방문자 손으로 확인 |
| 3 | **같은 문단, 다른 연기** | 문단 하나와 태그 칩 3~4개(기본 / [속삭이며] / [웃으며] / [한숨]). 칩을 누르면 대본에 태그가 꽂히는 모습과 함께 그 연기로 재생. "자동 태그가 문단마다 이런 연기를 추천해요" 한 줄 | 고르고 듣는다 | 크롭 이미지 → 소리 비교(Typecast·Fish 패턴) |
| 4 | **드라마 장면** `#drama` | 두 화자(색 칩) 대사 4줄 자막 + 장면 재생. 재생 중인 줄이 강조된다. 끝나면 "이 장면은 대사별 파일 4개와 자막 SRT로 받아요" 분해 도해(장면 파형이 줄별로 갈라지는 정적 그림) | 듣는다 | 마스코트 그림 → 실제 장면 소리 |
| 5 | **작업 흐름 한 줄** | 성우 캐스팅 → 보관함 → 작업실 → 받기를 가로 스트립(크롭 4장 + 한 줄씩). 스크롤하면 단계가 하나씩 강조 | 훑는다 | '들어 보고 고른다'·'문단마다 다르게'·'받기와 안심'을 하나로 압축 |
| 6 | **돈 걱정 없는 설계** | 미니 재현: '만들기'를 누르면 확인 창 → 이미 만든 문단은 "저장된 결과 · 호출 0 · 크레딧 0" 배지. 옆에 "유료 호출은 늘 확인 창을 먼저 거친다" | 눌러 본다(가짜 UI, 서버 호출 없음) | 글 한 줄 → 장면 |
| 7 | **숫자로 보는 제작** `#built` | 숫자 띠: 코드 약 5.8만 줄 · 자동 테스트 약 1,8xx개 · 설계 결정 기록 15개 · 8주. 아래 **아키텍처 한 장**: 키 없는 공개 데모 / 소유자 한 명 허용 목록 / 한국 밖 접속 차단 / 저장된 결과 캐시 / 늦은 응답 이어 저장. GitHub 링크 | 읽는다 | 카드 5개 글 → 수치 + 도해(포트폴리오 방문자용) |
| 8 | 화면 투어 | 지금 탭 6개 유지(보조) | — | 위치만 아래로 |
| 9 | FAQ | 지금 그대로 | — | — |
| 10 | 마지막 행동 | "이제 직접 들어 보세요" + '데모 작업실 열기'(예시 대본이 열린 채로 들어감) + ProKit 표시 | — | 데모 시작 화면 연결 |

시각 방향: 지금 세계(청록·Pretendard·마스코트) 유지. 새로 더하는 시각 언어는 **파형 하나**다. 재생 중에만 움직이는 파형(Web Audio `AnalyserNode`, 캔버스 하나)을 장면 1·3·4의 공통 장치로 쓴다. 자동 재생 없음, 움직임 줄이기에서는 정지 파형, 스크롤 연출은 장면 5의 단계 강조 하나만.

## 5. 데모 쪽 보완 (랜딩 약속과 맞추기)

- 마지막 행동과 막대의 '데모 작업실 열기'가 예시 대본이 열린 작업실로 들어가게(예: `/studio?example=<예시 대본>`).
- 데모 DB의 QA 잔재 대본 정리(백로그 UX-01).
- 테스트 수 문구를 러너 실측으로 맞춤.

## 7. 나누어 만들기

- **1단계(유료 호출 없음, 바로 가능):** 장면 1 오디션 무대(파형·차례로 듣기), 장면 2 숫자 놀이터, 장면 6 비용 재현, 장면 7 숫자 띠·아키텍처, 장면 5 흐름 스트립, 데모 시작 화면 연결. → 이것만으로 "만지는 순간" 1 → 4개.
- **2단계(새 샘플 승인 뒤):** 장면 3 연기 비교, 장면 4 드라마 장면, Airy 교체.

## 8. 하지 않는 것

로고 월·사용자 수·후기, 방문자 문장으로 실제 음성 생성(데모는 공급자를 부르지 않음), 자동 재생, 풀스크린 스크롤 하이재킹·WebGL·3D, 요금제 표, 새 의존성(파형은 Web Audio·캔버스로).

## 9. 정할 것

1. 콘셉트와 4판 구성(위 4절)으로 갈지.
2. 1단계만 먼저 할지, 2단계 샘플(Fish 무료 4~5회, Airy 유료 1회)까지 할지 — 유료·무료 모두 호출마다 승인.
3. Airy 처리(교체 / 넷으로 / 지금처럼 '다른 문장' 표시).
4. 데모 시작 화면을 예시 대본이 열린 상태로 바꿀지.
