## 조사 결과와 설계 결정

이번에는 공개 공식 제품 가이드·도움말·API 문서를 조사했다. 로그인 후 제품 사용, 실제 샘플 청취·과금 생성은 하지 않았다. 과거 가이드와 최신 공지는 분리하고 미확인 기능은 지원으로 간주하지 않는다.

| 참고 서비스 | 확인한 강점 | 우리 설계 | 그대로 옮기지 않을 것 |
| --- | --- | --- | --- |
| Typecast | 문단 왼쪽 성우 변경·일괄 교체, 문단/문장/쉼 구간 재생성, 후보 버전 비교 | 화자와 성우 배정을 문단 계획에서 확인, 지원 모델의 감정·속도·피치 설정, 문단 결과 버전 비교 | 설정 조작 즉시 유료 생성, Studio의 버전 수·무료 재생성 정책을 API 보장으로 표현 |
| ElevenLabs | 성우 라이브러리 필터·샘플·오디오 검색, 모델별 설정, 선택 문단 설정/기록, 원본→대상 성우 변환 | 성우 선택→모델→기본/전문 설정 순서, 클론·유사 검색·변환을 별도 흐름으로 표시, 변경 후 이전 결과 식별 | 웹 전용 Studio Agent를 공개 API 기능으로 표기, 계정 목록과 공개 라이브러리 혼동 |
| Vrew | 문서형 개요/클립 상세 전환, 여러 클립 성우 변경, 문맥을 유지하는 연결 발화 | 전체 원문을 기준으로 문단별 화자·성우·감정 검토, 적용 범위 표시, 문단과 합성·자막 단위를 구분 | 종료된 화자 구분 실험을 현행 기능으로 단정, 자막 줄바꿈마다 합성을 끊기, 초기 화면에 영상 타임라인 추가 |

상세 근거와 URL: [Typecast](../research/typecast-ux-refresh.md), [ElevenLabs](../research/elevenlabs-ux-refresh.md), [Vrew](../research/vrew-ux-refresh.md). 기존 [gowith 소개 화면 분석](../research/gowith-ux-review.md)과 [지정 영상 분석](../research/tts-video-detailed.md)은 비교 자료로 유지한다.

## 화면 구성

시각 시스템은 Wanted와 로컬 Pretendard를 유지한다. 서비스 UI를 복제하는 대신 개인 반복 제작 흐름에 적용한다.

1. 상단: 현재 작업명, 프리셋, 명시적 음성 생성. 생성 버튼은 설정 변경/샘플 청취와 분리한다.
2. **상시 노출 제작 도구:** 대본 준비(가져오기·감정 자동화), 성우 선택(맞춤 추천·목소리 찾기), 내 음성 활용(복제·체인저). 다섯 도구는 상세 작업 영역을 열고 닫으면 대본으로 돌아간다. 목소리 복제는 내 보이스로 이동하는 링크와 복귀 버튼으로 연결한다. 모바일에서도 여섯 이름을 접지 않는다.
3. 작업실: 성우 선택과 원문/발음용 대본. 공급자·모델별 설정은 현재 적용 가능한 항목만 사용한다. 개인 채널·카테고리·타입은 공급자 원본 분류와 구분한다.
4. 문단 제작 계획: 문단 번호·화자·성우·공급자·감정 요약. `대본·화자 편집`과 `감정 검토`를 구분한다. 가져오기에서 작업실 대본을 불러와 기존 배정을 유지한 채 수정한다.
5. 결과: 현재 편집과 생성 시점의 스냅샷을 구분. 실제 API 이관 시 기존 결과 청취·다운로드·해당 문단 재생성을 배치한다. HTML에서는 실제 음원이 없는 상태를 명시한다.

## 기능별 계약과 현재 상태

| 기능 | HTML에서 검토할 흐름 | 실제 앱 구현 시 완료 조건 |
| --- | --- | --- |
| 전체 성우 | 공급자·즐겨찾기·자주 사용·개인 분류→성우 선택. 현재 가상 5명 | Typecast 계정 이용 가능 전체 성우, ElevenLabs 계정 목록 페이지네이션과 공개 라이브러리 별도 조회. 실제 이용 권한·샘플 없음·목록 오류/추가 로딩 처리 |
| 맞춤 성우 추천 | 대본/설명+조건→예시 후보→비교→선택 | Typecast recommendation API 매핑; ElevenLabs 후보 추천은 별도 방식 검증. 추천 이유와 제약을 표시하고 근거 없는 일치율 금지 |
| 내 목소리 복제 | 파일/녹음→원본 확인→이름·본인 음성 동의→상태→내 보이스 | 공급자별 파일·길이·검증 제한, verification 필요/사용 가능 분리, 생성된 voice ID 소유권, 삭제·재시도·시험 생성 |
| 감정 자동화 | 규칙 기반 예시 제안→문단별 검토→일괄/직접 수정→되돌리기 | 공급자 자체 자동 감정과 앱 분석 구분. Typecast smart/preset, Eleven v3 audio tags 차이를 유지; 모델별 검증·비용·원문 보존 |
| 목소리 찾기 | 원본 음성/HTTPS URL 메타데이터→예시 후보 비교 | ElevenLabs similar voices 사용. Typecast 동일 API는 확인 전 지원하지 않음. URL 수집은 권한·접근 방식 별도 설계, 특정 인물 식별 아님 |
| 보이스 체인저 | 로컬 원본 재생→ElevenLabs 대상 성우·변환 설정→시연 상태 | 음성 변환 지원 모델 확인, multipart 업로드, 결과 재생/다운로드. Typecast 공개 변환 API 미확인 상태 유지 |
| 가져오기·화자 | TXT/CSV/SRT/DOCX 로컬 읽기, 표기 규칙 감지, 문단 편집·역할별 성우 배정, 원문 교체/추가 | 저장·서버 검증·문단 생성 연결. 대본 표기 감지와 업로드 음성의 diarization, LLM 화자 추론은 각각 구분 |
| 문단 수정 | 작업실 원문/기존 계획 불러오기, 초안 교체 확인, 화자·성우·감정 보존 후 반영 | 텍스트 변경의 영향 표시, 현재 설정과 이전 결과 비교, 선택/전체 적용 범위, 필요한 문단만 명시적으로 생성 |

생성 설정 상세와 API 필드 매핑은 [기존 옵션 설계](tts-provider-options-and-tools.md), [Typecast 옵션](../research/typecast-api-options.md), [ElevenLabs 옵션](../research/elevenlabs-api-options.md)을 정본으로 사용한다. 제품 웹 UI에 보이는 조작을 공개 API의 존재 근거로 삼지 않는다.

## 이번 HTML 반영 범위

- 여섯 도구 상시 노출 및 세 작업 그룹, 선택 패널/닫기/키보드 포커스.
- 가져오기에 `작업실 대본 불러오기`: 새 원문은 화자 표기 파싱, 기존 계획은 화자·성우·감정·강도 보존. 로컬 초안 덮어쓰기는 확인 후에만 수행. 200,000자·200문단 한도.
- 문단 계획의 대본·화자 편집과 감정 검토 경로 분리.
- 원문 교체는 기존 확인 흐름을 재사용. 실제 API·AI 추천·클론·변환은 이번 변경 범위가 아니며 시연 표기를 유지한다.

## 다음 구현 순서와 검수 기준

기존 TODO ID를 유지한다. 새 SaaS 구조나 추가 공급자를 먼저 만들지 않는다.

1. **P0: 실제 제작 기반.** HTML 앱 이관, 계정 이용 가능 성우 전체 조회·샘플 청취, 공급자+voiceId로 개인 분류·즐겨찾기·자주 사용 저장, 숫자 교정(Typecast 공식 AutoTag는 도입 후보이며 한국어 금액·날짜·단위·전화번호 결과 검증 후 판단), 단일 TTS 생성·다운로드, 본인 간편 클론. 오류·권한·사용량을 실계정으로 검증한다.
2. **P1-03/05/06: 문단 작업.** 가져오기→화자 검토→성우 배정→문단 설정→선택 범위 생성. 문단 추가/삭제/순서/분할/합치기와 실행 취소. 텍스트·설정 변경 시 영향을 받은 결과를 표시하고 나머지는 보존한다.
3. **P1-04/08/10: 부분 재생성과 버전 비교.** 이전/새 결과를 같은 문단에 연결, 비교 후 채택·되돌리기. 실제 공급자 요청별 비용과 실패를 표시한다. 여러 후보를 자동으로 생성해 비용을 숨기지 않는다.
4. **P2-01 / P3-01/02/05: 추천·연출 도구 실연동.** Typecast 추천, ElevenLabs 유사 검색·변환을 API별로 검증. 문맥 감정 제안은 별도 분석 계약을 만든다. API 존재만으로 한국어 품질을 보장하지 않는다.
5. **P2-04/05/06: Vrew 참고 자막.** 생성 오디오의 타임스탬프/정렬 확보→원문 기반 자막 분할/합치기→시간 검수→SRT/VTT 출력. 발음용 텍스트를 그대로 자막에 넣지 않으며 임의 시간값 생성 금지. 음성 문맥과 자막 표시 단위는 분리한다.
6. **후속 미디어 편집.** 파형·정확한 쉼·무음 정리·음량·BGM·영상 씬은 위 제작 루프 이후 별도 구현한다. 공개 가입·팀·청구는 P4 유지.

## 검증과 제한

상시 메뉴의 발견 가능성, PC/모바일 배치, 키보드 포커스, 초안 교체 취소, 반영 전 원문 보존, 기존 화자·감정 왕복을 검증한다. 생성물 품질·유료 사용량·계정 접근 권한·실제 마이크 장치는 이번 HTML 검증의 범위 밖이다. 실행 결과는 [UI 검토 기록](../research/tts-research-ui-review.md)에 기록한다.
