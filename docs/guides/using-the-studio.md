# 작업실 사용 안내

Omni AI TTS로 한국어 음성을 만드는 순서와 화면별 사용법입니다. 화면과 URL의 정본은 [서비스 현재 모습](../domain/project.md)이고, 화면마다 자세한 설계는 [화면 브리프](../briefs/)에 있습니다.

> **먼저 알아 둘 것**
> - 작업실은 소유자 한 명만 씁니다. 로그인하지 않으면 공개 소개 페이지(`/`)와 로그인 화면만 열립니다.
> - 크레딧을 쓰는 호출(음성 만들기, 시험 생성, 클론)은 늘 확인 창을 먼저 띄웁니다. 무료 모델(Fish Audio 무료 모델 등)은 확인 없이 바로 만듭니다.
> - 같은 성우·설정·대본으로 이미 만든 결과는 다시 만들지 않고 저장본을 씁니다. 결과는 30일 보관됩니다.

## 로그인

| 상황 | 화면 |
|---|---|
| 로그인하지 않고 작업 화면 주소를 엶 | `/login?next=…`로 가고, 로그인하면 그 화면으로 돌아옵니다 |
| 소유자가 아닌 계정 | '접근 권한 없음'과 다른 계정으로 로그인 버튼만 보입니다 |
| 세션이 끝남 | 화면에 "로그인이 풀렸어요" 안내와 '다시 로그인' 버튼이 나옵니다 |
| 로그인을 연달아 틀림 | 1분에 5번까지 시도할 수 있고, 넘으면 잠시 뒤 다시 시도하라는 안내가 나옵니다 |

로그아웃은 메뉴 아래 줄의 이메일 옆 버튼입니다. 비밀번호를 잊었을 때는 [소유자 계정](../owner-account.md)의 복구 절차를 따릅니다.

## 한눈에 보는 작업 흐름

1. **성우 캐스팅**에서 성우를 찾고 들어 본 뒤 별(즐겨찾기)을 눌러 보관함에 담습니다.
2. 자주 쓰는 성우·설정 조합은 **프리셋**으로 저장하고, 채널마다 기본 프리셋을 둡니다.
3. **음성 작업실**에 대본을 넣고 문단마다 성우를 고릅니다.
4. 숫자가 있으면 **숫자 발음 검수**로 읽는 법을 정합니다.
5. '전체 만들기'로 만들고, 이어 듣고, **받기** 메뉴로 파일을 받습니다.
6. 다음에 다시 쓸 대본은 **대본 보관함**에 저장합니다.

## 성우 캐스팅
`/casting`
- 위 탭으로 공급자(전체·Typecast·ElevenLabs·Fish Audio·Airy·Gemini)를 바꾸고, 출처(공개 라이브러리·내 계정)를 고릅니다.
- 조건 줄은 공급자가 주는 필터(성별, 나이, 언어, 용도, 모델 등)를 그대로 보여 줍니다. 조건을 바꾸면 그 자리에서 목록을 다시 받습니다.
- 행의 ▶로 기본 샘플을 듣고, 행을 누르면 오른쪽 패널에 자세한 정보가 나옵니다(1199px 이하는 서랍).
- **내 문장 듣기**: 위의 공유 문장 칸(200자)에 문장을 쓰고 행이나 패널의 '내 문장 듣기'를 누릅니다. 모델·감정·속도 같은 옵션은 공급자마다 다릅니다. 유료 모델은 예상 사용량을 보여 주는 확인 창이 먼저 뜹니다.
- 목록이 오래됐으면 '목록 새로 고침'(그 공급자 한 번 다시 조회)을 누릅니다.

## 성우 보관함과 채널·분류
`/voices`, `/classes`
- 별을 누르면 성우 보관함에 담기고, 패널의 담기 칸에서 '자주 사용', 채널·카테고리·타입 분류, 메모를 붙입니다.
- 보관함은 이름 검색과 보기(전체·즐겨찾기·자주 사용·프리셋), 공급자, 채널·분류로 거릅니다. 걸러진 상태는 주소에 남아 그대로 공유·북마크할 수 있습니다.
- 채널·분류 화면에서 이름을 만들고 바꾸고 지웁니다. 지우면 연결만 끊기고 성우는 남습니다.
- 공급자가 성우를 내리면 보관함에서 '현재 이용 불가'로 표시됩니다(24시간마다 확인).

## 프리셋
`/presets`
- 성우와 듣기 설정의 조합에 이름을 붙여 저장합니다. 성우 캐스팅과 작업실의 '프리셋' 메뉴에서 불러오고 덮어씁니다.
- 채널마다 기본 프리셋 하나를 정하면, 작업실에서 그 채널을 고를 때 기본 성우로 불러올 수 있습니다.

## 음성 작업실
`/studio`
- **대본 넣기**: '대본 붙여 넣기'로 전체 바꾸기나 끝에 더하기. 빈 줄 기준으로 문단 카드가 나뉩니다.
- **성우**: 위 '기본 성우'는 모든 문단에 적용되고, 카드마다 다른 성우를 고르면 그 문단만 바뀝니다('기본 따르기'로 되돌림). '설정'에서 공급자별 옵션을 바꿉니다.
- **카드 정리**: ⋯ 메뉴로 위·아래 이동, 문단 추가, 여기서 나누기, 앞·뒤 문단과 합치기, 지우기. 바꾼 뒤에는 '되돌리기' 알림이 잠깐 나옵니다.
- **만들기**: 카드의 만들기, 또는 막대의 '전체 만들기'·'이어서 만들기'. 새로 만들 문단에 유료가 있으면 확인 창이 한 번 뜹니다. '멈추기'는 지금 문단을 마친 뒤 멈춥니다.
- **듣고 받기**: 막대 플레이어로 이어 듣고, '받기' 메뉴에서 한 파일(WAV)·문단마다(zip)·자막(SRT)을 받습니다. 받기는 공급자를 다시 부르지 않습니다.
- 작업 요약에 만든 문단 수, 예상 길이, 공급자별 예상 사용량, 처음 멈춘·막힌 문단 링크가 있습니다.

## 숫자 발음 검수
음성 작업실의 카드 숫자 줄과 '숫자 검수' 창에서 합니다.
- 금액·날짜·시각·전화번호·단위 수량·비율·온도는 확실한 읽기를 제안하고, 범위·분수·제품명처럼 애매한 것은 '확인 필요'로 표시합니다.
- 항목마다 적용·원문 유지·직접 입력·되돌리기를 고릅니다. '확실한 것 모두 적용'도 있습니다.
- 공급자에는 발음용 대본이 가고, 화면의 원문은 그대로 남습니다. 원문을 고치면 그 문단의 결정은 다시 합니다.

## 대본 보관함
`/scripts`
- '저장한 대본'과 '최근 만든 대본'(자동 보관 20개)을 오갑니다.
- 제목·대본 글로 찾고(한글 부분 검색), 채널·카테고리·타입으로 거릅니다.
- 줄의 '열기'는 음성 작업실로 가서 지금 대본과 바꿀지 묻습니다. 고치기·복제·지우기도 줄 메뉴에 있습니다.
- 작업실의 '대본' 메뉴에서 저장·새 대본으로 저장·보관함에서 넣기(이어 넣기·바꾸기)를 합니다. 다른 곳에서 먼저 저장했으면 충돌 창이 덮어쓸지 새로 저장할지 묻습니다.

## 드라마 작업실
`/drama`
- 화자를 최대 4명까지 두고 화자마다 담은 Fish Audio 성우를 붙입니다.
- 줄마다 화자·연기 지시·대사를 씁니다. Enter는 다음 화자의 새 줄입니다. 줄 사이 쉼(초)을 정할 수 있습니다.
- '장면 만들기'는 대본 전체를 한 장면으로 연기시킵니다(테이크가 쌓입니다). '다른 방법 ▾ → 줄마다 읽기'는 다섯 공급자 성우로 줄을 하나씩 읽습니다.
- '받기' 메뉴에서 장면 파일, 쉼을 넣은 한 파일, 대사별 파일(zip)을 받습니다.
- '전체 자동 태그'는 연기 지시를 자동으로 제안합니다(유료 텍스트 호출, 확인 창).

## 내 보이스
`/my-voices`
- '만들기'로 녹음하거나 파일을 올려 내 목소리 클론을 만듭니다(Fish Audio·Gemini). Gemini는 동의 문장 녹음이 함께 필요합니다.
- 보내기 전에 본인 음성 동의와 고지를 확인합니다. 원본 녹음은 서버 메모리에서만 다루고 저장하지 않습니다([ADR 0011](../adr/0011-clone-source-in-memory.md)).
- 준비된 클론은 성우 보관함에 자동으로 담겨 작업실·드라마에서 다른 성우처럼 씁니다. 지우면 공급자 쪽 클론과 보관함·프리셋 연결도 정리됩니다.

## 연결 상태
`/connections`
- 다섯 공급자의 연결, 키 상태, 사용량(공급자가 주는 경우)을 한 화면에서 봅니다.
- 오류가 나면 무엇이 문제인지(키 없음, 인증 실패, 요청 제한, 공급자 장애)와 다시 확인 버튼이 나옵니다. 작업 화면의 키·인증 오류에서도 여기로 옵니다.

## 자주 묻는 것

<details>
<summary><b>결과가 "처리 여부 미확인"으로 나와요</b></summary>

공급자 응답이 시간 제한(작업실 180초) 안에 오지 않으면 미확인으로 적습니다. 결과가 늦게 오면 자동으로 저장되어 다시 보면 완료로 바뀝니다. 같은 문단을 다시 만들기 전에 잠시 기다려 보세요.
</details>

<details>
<summary><b>"요청이 많아요"가 나와요</b></summary>

공급자가 요청 제한(429)을 알렸습니다. 화면에 다시 시도할 수 있는 시각이 나오고, 그때까지 같은 공급자 요청을 막습니다.
</details>

<details>
<summary><b>긴 대본도 되나요</b></summary>

문단은 200개까지, 문단 하나는 공급자 글자 상한(대부분 2,000자, Airy 1,600자) 안이어야 합니다. 결과 오디오는 문단 하나에 32MiB까지 받습니다.
</details>
