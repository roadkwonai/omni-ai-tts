# TTS Pilot HTML 프로토타입

개인 음성 제작 작업실의 UI/UX 검토용 정적 프로토타입입니다. 실제 TTS 제공사·DB·API 키·비용 청구와 연결하지 않습니다. 로컬 파일 읽기·원본 오디오 재생·사용자 클릭으로 시작하는 마이크 녹음은 브라우저에서 동작하며 서버로 전송하지 않습니다.

## 실행

별도 서버 없이 [index.html](index.html)을 브라우저에서 직접 열어 확인할 수 있습니다. 로컬 상대 경로로 Pretendard 글꼴을 참조하므로 저장소 전체를 웹 서버로 공개할 필요가 없습니다.

```sh
open docs/prototypes/tts-studio/index.html
```

Windows에서는 파일 탐색기에서 `index.html`을 열면 됩니다. 브라우저의 로컬 저장소 사용이 제한된 환경에서는 대본 저장 시 오류 상태가 표시됩니다.

## 시연 가능한 동작

- 작업실: 성우 공급자·즐겨찾기·검색 필터, 샘플 재생 **흐름 표기**, 성우 선택/즐겨찾기, 원문과 발음용 대본 전환, 숫자별 적용·유지·직접 수정·되돌리기, 일괄 적용/유지와 미검수 생성 차단
- 대본: 브라우저 `localStorage`에 시연용 텍스트만 저장, 검색·수정·복제, 불러오기에서 삽입/교체, 실패 상태 시연
- 프리셋: 가상 프리셋 확인 및 적용, 현재 선택을 새 프리셋으로 저장
- 보관함: 성우/대본 필터, 채널·분류의 추가/이름 변경/삭제, 내 보이스의 정보→원본→동의→검증 필요/사용 가능→작업실 선택 및 연결 상태 화면
- 생성: 준비·진행 뒤 완료·응답 유실·공급자 오류 중 하나로 끝납니다. 생성 결과의 다운로드는 파일을 만들지 않는 시연 행동입니다.
- 시연 설정: 내비 하단 `시연 모드`(좁은 폭은 `시연`, 모바일은 `더보기`를 펼친 뒤)를 누르면 음성 만들기·AI 보이스 도구·감정 자동화의 결과(성공·빈 결과·오류 등)를 한곳에서 고릅니다. 작업면과 도구 안에는 시연 제어를 두지 않습니다. 새로고침하면 성공으로 돌아갑니다.

## 검토 시나리오

1. 작업실에서 `ElevenLabs` 필터를 누른 뒤 성우 행을 선택하고 하트로 즐겨찾기를 바꿉니다.
2. 원문을 고친 뒤 `발음용 대본`에서 숫자 교정마다 `적용`, `유지`, `직접 수정`을 실행합니다.
3. `음성 만들기`로 완료 상태를 확인합니다. `시연 모드`에서 결과를 `응답 유실`이나 `공급자 오류`로 바꾸면 실패 상태와 `다시 만들기`를 볼 수 있습니다. 완료 상태의 `다운로드`는 실제 파일이나 음성을 만들지 않습니다.
4. 대본 보관함에서 새 이름으로 저장한 뒤 작업실의 `저장 대본`에서 삽입 또는 교체합니다.
5. 내 보이스에서 이름·공급자·입력 방식을 고르고 동의를 선택해 생성 흐름을 검토합니다.

## 명시적 미구현 범위

실제 공급자 음성 합성·합성 결과 재생, 공급자 연결과 인증, 파일 서버 전송·영구 저장, 사용량 계산·결제, 서버 검증은 구현하지 않았습니다. 선택한 로컬 원본 재생과 녹음은 동작합니다. `localStorage`에는 `tts-pilot.prototype.*` 이름공간의 일반 텍스트와 선택 상태만 보관하며 API 키와 실제 음성 파일은 저장하지 않습니다.

숫자 검수는 예제 대본에 있는 날짜·금액·퍼센트·시간·수량 패턴으로 항목별 검수 흐름을 시연합니다. 완전한 한국어 숫자 변환 엔진은 구현하지 않았습니다.

성우 분류 항목·성우별 연결·즐겨찾기·자주 사용은 `tts-pilot.prototype.voice-classification.v1` 로컬 저장소로 보존합니다. 저장 대본 텍스트도 별도 로컬 저장소에 보존합니다. 메모·프리셋·클론 상태는 페이지 세션의 시연 데이터입니다. 최종 디자인 검토 기록은 [검토 문서](../../research/tts-html-review.md), 실제 앱 이관 계획은 [개발 계획](../../plans/tts-ui-first-implementation.md)을 참고하세요.

현재 보이는 성우 5개는 가상 예시이며 양사 전체 카탈로그가 아닙니다. 실제 전체 목록·페이지 탐색·공급자 분류·자주 사용 등록은 [요구사항 REQ-02~04](../../plans/tts-service-requirements.md)에 명시된 다음 구현 범위입니다. 샘플 버튼도 현재는 음성이 재생되지 않습니다.


## 공급자별 설정 확장 (2026-09-26)

[확장 브리프](../../briefs/tts-provider-settings.md)와 [옵션·제작 도구 계획](../../plans/tts-provider-options-and-tools.md)을 기준으로 생성 설정을 보강했습니다. Typecast/ElevenLabs의 모델별 기본·표현·고급 설정과 전체 설정 프리셋, 변경 후 이전 결과 표시를 검토하는 화면입니다. API 필드별 조건과 문서 충돌은 [Typecast](../../research/typecast-api-options.md), [ElevenLabs](../../research/elevenlabs-api-options.md) 조사 문서를 참고하세요.

추천·목소리 찾기·보이스 체인저는 입력부터 비교·선택·처리 상태까지 이어지는 설계 시연입니다. 추천 예시는 실제 AI 분석 결과가 아니고 서버 파일 업로드·음성 변환·새로운 음성 합성은 수행하지 않습니다. 대본 가져오기는 로컬 파일 파싱과 화자·성우 배정, 작업실 반영까지 동작합니다. Vrew식 자막 편집은 이번 확장 범위에 포함하지 않습니다.

설정 변경·프리셋·모델 전환·모바일 검증 결과는 [설정 UI 검토 기록](../../research/tts-provider-settings-review.md)에 있습니다. Eleven v3 연출 태그는 원문을 보존하고 발음용 대본에 반영하는 시연을 지원합니다.


## 성우에 채널·분류 지정하기

1. **성우 보관함 → 성우 행의 분류 편집**을 엽니다. 데스크톱은 우측 패널, 모바일은 전체 화면입니다.
2. 채널·카테고리·타입마다 여러 항목을 선택합니다. 검색하거나 그 자리에서 새 항목을 만들 수 있습니다.
3. **저장**하면 성우 행의 태그와 작업실/보관함 필터에 반영됩니다. **취소/ESC**는 편집 중인 성우 연결을 적용하지 않습니다. 새 항목 만들기는 항목 목록에 즉시 저장하는 별도 동작입니다.
4. **채널 · 분류**에서 항목 이름·연결 성우 수를 확인하고 **성우 보기**로 해당 성우를 모아 봅니다. 이름 변경은 연결을 유지하고 삭제는 연결만 해제합니다.
5. 공급자와 **전체/즐겨찾기/자주 사용** 보기를 조합할 수 있습니다. 분류 필터는 같은 그룹 안 OR, 서로 다른 그룹 사이 AND입니다.

이번 연결 대상은 가상 성우입니다. 실제 API 카탈로그·계정 DB, 대본/프리셋 분류 편집·채널 기본 프리셋·성우 일괄 분류는 아직 구현하지 않았습니다. 저장 실패는 성공으로 표시하지 않으며, 로컬 저장이므로 다른 브라우저나 기기에 자동 동기화되지 않습니다.


## 제작 도구 전체 흐름 (2026-09-26 보완)

작업실 좌측 레일의 **AI 보이스 도구** 타일이나 작업 툴바의 **대본 가져오기**·**감정 자동화**에서 진입합니다. 도구는 오른쪽 드로어에서 열리고, 닫으면 누른 버튼으로 포커스가 돌아갑니다(2026-09-29 구조 개편).

- 추천: 현재 대본/직접 설명과 분류 조건 → 성공/빈 결과/오류 시연 → 최대 3명 비교 → 작업실 성우 선택. 대본·조건 변경과 도구 이탈 시 이전 요청을 취소합니다.
- 찾기: 로컬 원본 또는 HTTPS URL 확인 → 유사 후보 시연 → 비교·선택. URL은 내려받지 않으며 화자 정체를 판별하지 않습니다.
- 체인저: 원본 → ElevenLabs 대상 성우·출력·소음 제거·동의 → 변환 상태 시연. 실제 결과 음원이 없어서 결과 재생·다운로드는 제공하지 않습니다.
- 가져오기: 붙여넣기 또는 TXT/CSV/SRT/DOCX → 화자 감지/문단 편집·성우 배정 → 교체/삽입 확인 → 작업실 문단 계획. 파일 최대 5MiB, 텍스트 200,000자, 문단 200개; DOCX는 word/document.xml의 텍스트만 읽고 압축 해제 출력 1MiB를 제한합니다. 손상/암호화/미지원 압축은 안내합니다. CSV는 구조화된 화자·대사 열을 사용합니다.
- 감정: 현재 문단 → 규칙 기반 제안 → 개별·일괄 수정/되돌리기 → 원문을 보존한 계획 적용. Typecast v30과 Eleven v3 표현을 기준으로 하며 ElevenLabs에는 숫자 강도 옵션을 제공하지 않습니다.
- 복제: 이름/공급자 → 로컬 음성 또는 직접 녹음/예시 원본 → 원본 확인·동의 → 검증/사용 가능 상태 시연. Typecast의 브라우저 녹음 원본은 실제 연결 시 WAV/MP3 변환이 필요합니다. 실제 클론은 생성하지 않습니다.

로컬 음성과 도구 입력·문단 계획은 페이지 세션에서만 유지됩니다. 마이크는 녹음 버튼에서만 요청하며 중지·도구/화면 이탈 시 해제합니다. 새로고침으로 사라질 대본은 기존 대본 저장 기능으로 별도 저장하세요. Vrew식 자막/타임라인 편집은 이번 범위에 포함하지 않습니다.

즐겨찾기는 선택 시 **채워진 노란 별**, 해제 시 **회색 윤곽 별**로 표시합니다. 검증 기록은 [제작 도구 검토](../../research/tts-production-tools-review.md)를 참고하세요.

## 서비스 조사 반영 (2026-09-26)

작업실 좌측 레일(1023px 이하는 툴바 `AI 도구`)에서 제작 도구를 바로 선택합니다. 대본 가져오기에서 `작업실 대본 불러오기`를 선택하면 기존 화자·성우·감정 계획을 유지한 채 수정할 수 있습니다. 초안 교체와 원문 반영은 각각 확인합니다. 실제 음성 API는 연결 전입니다. [설계·후속 계획](../../plans/tts-research-driven-ux.md)을 참고하세요.

## Fish Audio 공급자 (2026-09-28)

작업실 성우 필터에 `Fish Audio`를 더했습니다. 가상 성우는 유나와 도진 두 명입니다. 모델 선택지는 `s2.1-pro`(기본), `s2.1-pro-free`, `s2-pro`, `s1`입니다. 생성 설정은 속도, 음량(dB), 표현력(temperature·top_p), 형식·지연 같은 고급 설정, 서버 자동 처리 안내로 이루어집니다. 감정은 대본 안의 인라인 태그로 표현하므로 문단 감정 강도는 비활성입니다. 대본 길이는 UTF-8 바이트와 문서 단가($15/백만 바이트) 기준의 추정치로 보여 줍니다. 근거는 [Fish Audio API 조사](../../research/fish-audio-api-options.md)입니다.

## gowith 로그인 조사 반영 (2026-09-28)

[로그인 작업실 전수 검토](../../research/gowith-studio-logged-in-review.md)와 [반영 브리프](../../briefs/tts-gowith-reflection.md)를 기준으로 문단 작업 흐름을 더했습니다. 모두 실제 API·과금·파일 생성이 없는 시연입니다.

- **구조 개편 (2026-09-29)**: 반영 체감이 낮다는 critique(24/40)에 따라 대본을 늘 문단 카드 목록으로 다룹니다. 한 덩어리 대본은 카드 1장이고, 새 방문자는 예시 대본이 문단 4장으로 열립니다. 화면은 좌측 레일(문단 일괄 작업·AI 보이스 도구) | 가운데 작업 툴바·보기 탭(`문단`·`원문 전체`·`발음용 대본`)·문단 카드 | 우측 레일(작업 요약·역할별 성우·작업 설정·결과) | 하단 작업 바입니다. 성우 목록과 도구는 오른쪽 드로어(`<dialog>`)에서 엽니다. 1279px 이하는 우측 레일, 1023px 이하는 좌측 레일을 접고, 767px 이하는 툴바·작업 바를 `⋯` 메뉴로 줄입니다. `원문 전체` 탭은 이어 붙인 읽기 전용 원문과 `모두 합쳐 한 문단으로`, 발음 검수는 이어 붙인 대본이 대상입니다. 여러 문단이나 `이름: 대사`를 카드에 붙여넣으면 나눌지 묻습니다.
- **문단 카드** (`paragraph-studio.js`): 요약 줄 하나(방향키로 움직이는 툴바)에 성우 빠른 메뉴(이 대본에서 사용 중·최근 사용·검색·`전체 성우에서 찾기` 드로어), 역할 배지, 예상 길이, 속도·뒤 간격·감정·지시 칩, 예상 사용량, 추천, 미리 생성(비활성·사유), `⋯`(아래에 추가·이 문단 나누기·삭제)를 모았습니다. 칩을 누르면 그 자리에서 팝오버가 열리고, 기본값 칩은 흐리게·바꾼 값은 강조해 보여 줍니다. 위/아래 이동은 카드 왼쪽 거터에 있습니다. 카드당 탭 정지는 선택·조절 툴바·본문 3개이고, 1440px에서 한두 줄 문단 카드는 약 94px입니다.
- **일괄 작업** (좌측 레일): 선택 N/M, 전체 선택, 성우 고르기(드로어)·속도·간격(팝오버), 분할(선택이 없으면 전체), 합치기 확인, 선택 삭제, 되돌리기(최대 20단계)를 2열 버튼으로 늘 보여 줍니다. 선택 전에는 사유와 함께 비활성입니다. 1023px 이하는 한 줄, 모바일에서 선택이 있으면 작업 바 위 시트로 나타납니다.
- **역할별 성우 창**: 역할마다 대사 수, 성우 선택, `N/M 역할 성우 지정` 진행도를 보여 줍니다. 화자 이름과 같은 이름의 성우가 있으면 먼저 배정합니다.
- **하단 작업 바**: 요약(문단·글자·예상 길이·예상 사용량과 근거), 마스터 재생(생성 성공 뒤 소리 없는 시연 재생으로 문단 위치만 이동), 음량(시연), 생성 후 편집(비활성·사유), 내려받기 메뉴(MP3·WAV·SRT·문단별 ZIP, 시연), `음성 만들기 · 시연`으로 이루어집니다. 헤더에 있던 생성 버튼은 이 바로 옮겼습니다.
- **프로젝트** (`project-tools.js`): 프로젝트 보관함에서 새로 만들기·열기·복제·이름 변경·삭제를 할 수 있고, 헤더 `프로젝트 저장`, 작업 제목 인라인 수정을 넣었습니다. 임시 작업은 자동으로 저장되고, 새로고침하면 화면 맨 위 복구 배너(불러오기/나중에/삭제)가 뜹니다. `새로 시작`은 저장 후/저장 없이/취소 가운데 고릅니다. `사용법`은 10단계 목록과 해당 영역으로 이동하는 버튼으로 이루어집니다.
- **성우 선택** (드로어, 적용 대상 표시: 문단·선택한 문단·역할·새 문단 기본 성우): 상세 조건(언어·성별·연령·용도), 정렬(기본·최근 사용·즐겨찾기 먼저), 목소리 ID 검색을 넣었습니다. 최근 사용은 생성 성공 기준입니다(CONTEXT.md 사용 이력).
- **내 보이스**: 녹음 가이드(추천 낭독 대본·권장/전체·예상 낭독 시간·공급자 길이 조건), 입력 장치 선택과 녹음 중 입력 레벨, ElevenLabs `녹음에서 읽은 문장`, 기존 ElevenLabs Voice ID·공유 링크 연결(해제해도 원본 유지), 공급자별 사용 개수 안내를 더했습니다.
- **보이스 디자인** (좌측 AI 보이스 도구 → 드로어): 성별·연령·억양과 강도·감정·발음 스타일·속도·피치·묘사문(칩 덧붙이기)·미리 들을 대사를 받아, 실행 전에 예상 사용량을 보여 주고 후보 3개를 시연합니다. 고른 후보는 내 보이스로 저장합니다. 대상 공급자는 ElevenLabs로 표시합니다.
- **사용 내역**: 연결 상태 화면에 세션 동안의 시연 생성·클론·디자인 기록을 전체/생성/클론·디자인 탭으로 보여 줍니다. 실제 청구가 아닙니다.
- **다크 모드**: 시스템 설정을 따르고, 테마 전환 버튼으로 라이트·다크를 고를 수 있으며 선택을 기억합니다.
