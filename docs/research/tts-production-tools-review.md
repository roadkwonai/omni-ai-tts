# 제작 도구 여섯 흐름 검토

2026-09-26. 범위는 HTML 프로토타입이다. 실제 공급자 추천·유사 검색·음성 변환·클론 결과와 음질은 검증하지 않았다.

## 구현 범위

- 추천: 현재 대본/설명·공급자/분류 조건, 비교 목록, 성우 적용, 성공/빈 결과/오류·재시도·취소 시연.
- 찾기: 로컬 원본 또는 HTTPS URL 확인, 유사 후보 시연·비교·선택. 원격 URL은 가져오지 않는다.
- 체인저: 원본·ElevenLabs 성우·형식·소음 제거·동의, 처리 상태와 전후 비교. 실제 결과 음원이 없음을 표시하고 결과 재생을 비활성화한다.
- 가져오기: 브라우저 내 TXT/CSV/SRT/DOCX 파싱, 화자 감지/문단 편집·성우 배정, 교체/삽입 확인과 작업실 문단 계획 반영.
- 감정: 규칙 기반 시연 제안, 개별·일괄 수정·되돌리기·원문 보존 적용. Typecast 강도와 Eleven v3 태그 계획을 구분한다.
- 복제: 실제 로컬 파일/원본 플레이어와 클릭 기반 마이크 녹음 UI, 동의·검증 필요·사용 가능·삭제 시연. 실제 공급자 등록은 하지 않는다.
- 선택한 즐겨찾기는 빨간 채움, 미선택은 회색 윤곽으로 표시한다.

## 기능 증거

`tasks/evidence/tts-production-tools/verification.json`에 검사 범위를 기록했다. 실제 로컬 테스트 파일은 `/tmp/tts-production-fixtures/`에서 만들었다.

- TXT: 한 줄씩 이어지는 진행자/손님/진행자 3개 문단 감지, 같은 화자 일괄 성우 지정, 교체 취소 시 원문 보존, 확인 후 문단 계획 반영.
- CSV: 인용문 안 쉼표, 닫히지 않은 따옴표 오류, 편집 후 CSV 형식 유지 및 재파싱.
- SRT/DOCX: 각각 2개 문단, DOCX 화자 원문과 파일명 보존. 암호화/미지원 압축·DTD·크기 제한은 코드로 확인했다.
- 파일 5MiB pre-read, 텍스트 200k pre-parse, DOCX 압축 해제 출력 1MiB, 문단 200개 제한. 느린 이전 파일 결과가 탭 이탈 후 초안을 덮지 않으며 읽는 중 계획 반영을 차단한다.
- 감정: 3개 문단 일괄 변경/undo, 원문 및 배정 성우 유지. 문단 생성 시연의 결과에 각 문단 계획을 표시한다.
- 추천: 비교 추가, 대본 수정 시 이전 결과 무효화, 처리 중 도구 이탈 후 재실행 가능.
- 찾기: HTTP 거부·HTTPS 확인, 원격 가져오기 없이 후보 시연. 체인저: 로컬 6초 WAV, ElevenLabs 대상만 선택, 동의·결과 재생 비활성.
- 복제: WAV 원본 길이·플레이어·동의·검증 필요 시 사용 차단. 마이크 권한 거부와 늦게 도착한 stream 해제는 mock으로 확인했으며 실장치는 녹음하지 않았다.
- 비동기 완료 후 결과 포커스·role=status, 파일 이름 지속 표시, IME/caret 유지. 390px 가로 넘침 없음, 제작 도구 진입 버튼 표시.

시각 증거: `import-desktop-final.png`, `import-mobile-final.png` 및 A의 `a-*.png`(같은 evidence 폴더). 같은 세션 앞선 Ego 캡처 timeout 근거로 agent-browser를 대안으로 사용했다.
