# gowith153 로그인 작업실 전수 검토

확인일: 2026-09-28. 대상: [TTS 풀패키지 작업실](https://tts.gowith153.com/tts), 마이페이지, 요금제 페이지. 사용자가 로그인해 둔 체험 계정으로 Ego Browser에서 화면의 모든 버튼·창·도움말을 열어 보았다. 공개 페이지만 본 이전 검토는 [gowith 공개 UI 검토](gowith-ux-review.md)에 있다.

## 조사 원칙과 한계

- 크레딧을 쓰는 동작(전체·문단 음성 생성, 문단 미리듣기, 보이스 디자인 샘플, 저장 및 음성 생성)과 서버 상태를 바꾸는 동작(프로젝트 저장, 복제 생성, Voice ID 연결, 키 발급, 비밀번호 변경)은 실행하지 않았다. 확인 전후 보유 크레딧은 100으로 같다.
- 문단 추가·분할·가져오기는 저장하지 않은 로컬 작업에서만 시험했고, 끝난 뒤 원래의 1개 문단으로 되돌렸다.
- 마이크 권한은 복제 창을 여는 순간 요청됐다. 사용자가 차단했으므로 녹음·실시간 입력 파형은 “마이크 없음” 상태만 봤다.
- 생성 후에만 열리는 화면(마스터 타임라인 재생, 다운로드 창, 자막 싱크·무음 편집, 원본 오디오 복원)은 둘러보기 설명과 브라우저 저장소의 설정 키로만 확인했다. 실제 동작은 미검증이다.
- 계정 이메일, 인증 토큰, 개인 식별 값은 이 문서와 증거에 남기지 않는다.

## 기능별 관찰

### 1. 문단 카드

한 행에 이동(위/아래)·선택 체크·번호·성우 얼굴이 있고, 머리줄에 `성우 ▾`, `🎭 역할`, `예상 길이 N초`, 속도, 피치, 간격, `감정 톤 ▾`, `성우 추천`이 있다. 오른쪽에 `🪙 예상 크레딧`, 정밀 수정(✏️), 문단 미리듣기(크레딧 소모), 문단 음성 다운로드·자르기(생성 전 비활성), 삭제, 아래에 추가가 있다.

- **예상 길이**: 글자 수와 속도로 계산한 초. 문단마다 보여 긴 대본의 분량 감각을 준다.
- **성우 ▾ 빠른 메뉴**: `현재 사용 중인 성우`(예: 한준 · 2곳에서 사용 중), `최근 사용한 성우`, `성우 전체 목록 열기`. 다화자 대본에서 이미 쓰는 성우를 다시 고르기 쉽다.
- **역할 배지**: 누르면 “‘지수’ 역할 성우 선택”으로 전체 목록이 열리고 같은 역할의 문단 전체에 적용된다.
- **속도·간격 입력**: `속도 조절 — 0.5 ~ 2.0 사이` 같은 텍스트 입력 대화상자. 간격은 문단 뒤 무음(초). 피치·간격 도움말에 “생성 후 편집은 크레딧 0”이라고 적혀 있다(후처리로 추정).
- **감정 톤 ▾**: 일반·슬픔·기쁨·화남·톤 업·중간 톤·낮은 톤·속삭임·애교·응원 프리셋마다 A/B/C 변형, `직접 요청 문장`(300자, Ctrl+Enter 적용), `공식 지원 모델 자동 적용` 안내.
- **정밀 수정 창**: 대사 편집, `🪄 단위 한글 자동 정제`, 연기/톤 지시문 입력과 칩(쎈소리/강조, 끊어읽기, 또박또박, 당당하게, 차분하게), 취소/저장/저장 및 음성 생성.
- **문단 성우 추천**: 여성 3명·남성 3명과 점수(64·63·62점), 미리듣기, 선택 후 `선택한 성우 적용하기`. “선택만으로는 크레딧이 들지 않는다”는 안내가 있다.

### 2. 문단 일괄 작업

- 선택 후 `성우`는 “전체 목소리 변경” 목록을, `간격`은 “선택한 문단들의 뒤 무음 간격(0.0~5.0)” 입력을 연다.
- **빠른 분할**은 먼저 기준을 고르게 한다: `직접 자르기(추천)`, `마침표 기준`, `줄바꿈 기준`, `둘 다 적용`. “음성 생성이 끝난 문단은 기존 음성을 유지하면서 함께 분할합니다.”
- **직접 자르기 편집기**: 선택한 문단마다 텍스트 영역이 있고 줄바꿈이 곧 분할선이다. 머리에 `5개 문단 → N개 문단 분할` 실시간 계산, `글자수 조절 ± / 적용`(N자 단위 자동 분할), `마침표 단위 분할`, `원문 초기화`가 있다.
- **합치기**는 “선택한 5개 문단을 하나로 합치겠습니까? 이미 생성된 음성이 있다면 자동으로 병합 재생” 확인을 거친다.
- 일괄 삭제는 없다. 개별 문단 삭제는 확인이나 되돌리기 없이 바로 지워진다.

### 3. 화자와 역할

- `화자 자동 감지 ON`에서 문단에 `서연: …`, `준호: …` 여러 줄을 붙여 넣으면 줄마다 문단이 생기고 역할 배지가 붙은 뒤, **역할별 성우 선택 창이 자동으로 열린다**.
- 역할 창은 역할마다 `성우 미지정`, `같은 역할 대사 N개에 일괄 적용`, `성우 선택`을 보여 주고 `0/5개 역할 성우 설정 완료` 진행도를 센다. 지원 형식은 `이름 : 대사`, `[이름] 대사`, `[이름]` 다음 줄 대사다.
- **대본 가져오기 3단계**: ① 붙여넣기 또는 파일(.txt/.docx/.srt), `0 / 20,000자` ② 감지된 화자 수·분할될 문단 수와 화자별 첫 대사 ③ 화자별 성우 드롭다운과 `기존 작업 중인 대본(N개 문단): 새로 교체하기 / 뒤에 추가하기`, `스튜디오에 적용하기`. 적용 후 “4개의 대사 문단이 추가되었습니다” 확인이 뜬다.

### 4. 성우 선택 창

제공사(타입캐스트/일레븐랩스/내 목소리), 국가, 성별, 연령층, 콘텐츠(다큐멘터리·낭독·강의·안내음성·광고·게임·라디오·음악·예능·사투리·애교/상큼) 다중 선택 패싯과 “N개 선택” 표시가 있다. 정렬은 전체/인기순/최근 사용/즐겨찾기이고, 검색은 이름·목소리 ID·스타일을 받는다. 결과는 670개(Typecast 614, ElevenLabs 56)다. 카드에는 얼굴·이름·`선택`·즐겨찾기·기본 미리듣기와 스타일(#다큐) 미리듣기 두 개가 있다. 복제한 목소리가 없으면 `내 목소리` 필터가 비활성이고, 그 이유를 툴팁으로 알려 준다. 같은 창이 문단 성우, 역할 성우, 일괄 성우 변경에 재사용되고 제목만 바뀐다.

### 6. 생성·재생·편집·내보내기

- 하단 `음성 생성 🪙 3.2`처럼 버튼에 예상 사용량을 붙인다. 문단별 예상치 합(3.0)과 합계(3.2)가 다르고, 이런 차이가 “발음 보정·분할 시 소량 오차”라는 문구로 설명된다.
- 생성 전 `편집`을 누르면 “대사 편집 및 무음 조절을 진행하려면 먼저 음성 생성이 필요합니다. 지금 전체 문단의 음성을 생성하시겠습니까?”가 뜨고, `확인`을 누르면 바로 과금 생성이 시작된다.
- 둘러보기 설명: 마스터 타임라인 파형과 문단 위치 이동, MP3·SRT·문단별 ZIP 통합 다운로드, SRT 밀리초 수정, 무음 압축·제거.
- 브라우저 저장소의 편집 기본값: 무음 기준 -50dB, 최소 무음 길이 1.2초, 목표 길이 0.35초, 압축 끔, 자막 한 줄 최대 25자. ElevenLabs 기본값은 multilingual_v2, 안정성 0.5, 유사도 0.75, 스타일 0, speaker boost 켬이다.

### 7. 프로젝트·복구·사용량

- **프로젝트 보관함**: “최근 30일간 안전 보관”, `+ 새 프로젝트`, 현재 작업 제목 입력 후 저장.
- **새로고침 복구**: 다시 열면 “저장되지 않은 최근 음성 작업” 창이 작업 이름·임시 저장 시각·보관 내용(대사 1개·음성 0개)을 보여 주고 `임시 작업 불러오기 / 나중에 / 임시 작업 삭제`를 묻는다. `나중에`를 고르면 하단에 `복구` 알림이 남는다.
- **초기화**: “현재 작업은 프로젝트에 저장되며… 다시 열 수 있습니다”와 함께 `지금 저장하기 / 프로젝트 저장 후 초기화 / 저장 없이 초기화 / 취소`를 준다.
- **크레딧 내역 창**: 현재 잔여·최근 소모·최근 획득/환불, `전체/차감/충전·환불` 탭, 최근 50건, 빈 상태 안내.
- **마이페이지**: 크레딧을 공급자별 생성 가능 글자 수로 환산(Typecast 약 5,000자, ElevenLabs 약 3,333자), 최근 사용 내역, 최근 음성 프로젝트(불러오기 실패 시 `다시 불러오기`), 비밀번호 변경, 외부 도구 연결(MCP 서버 주소와 키 발급, “키는 돈과 같으니 남에게 보내지 마세요”).
- **요금제**: 엔진별 단가(기본 10자당 0.2, ElevenLabs 10자당 0.3 크레딧)와 “1분당 약 N원·약 N시간” 분량 환산.

### 8. 안내·접근성·반응형

- 둘러보기 16단계에는 번호 목록으로 바로 가기가 있다. 화면에 없는 기능이면 “이 기능은 지금 화면에 보이지 않습니다”라고 알려 준다.
- `?` 도움말 중 목소리 복제·보이스 디자인·역할 배정 3개는 제목과 본문이 빈 창으로 열린다.
- 문단의 성우·역할·속도·피치·간격 조작은 `button`이 아닌 `span`이라 키보드로 도달할 수 없다.
- 녹음 가이드를 연 채 복제 창을 닫으면 가이드 오버레이만 남아 화면 전체 클릭을 막는다. Esc로도 닫히지 않는다.
- 390px 폭에서는 왼쪽(일괄 작업·AI 도구)과 오른쪽(크레딧·프로젝트·작업 요약) 영역이 통째로 사라진다. 문단 머리줄 칩은 세로로 깨지고(“피 치 설 정”), 이동 버튼은 17px, 문단 도구는 25px이다. 복구 알림이 하단 생성 바를 가린다.
- 다크 모드 전환이 있다.

| 추천 이유 문장이 6명 모두 같고 순위와 점수가 어긋남(3순위 64점 > 2순위 63점) | 추천마다 근거가 되는 태그·설명을 다르게 보여 주고, 점수를 쓰면 정렬과 일치시킨다. 근거가 없으면 점수를 쓰지 않는다 |
| 단위 정제가 문장 전체를 한 번에 바꾸고 원문을 덮음. `120km/h`→`백이십 킬로미터/h`, `9월`→`구 월` | 원문 보존, 항목별 적용/유지/직접 수정 검수(기존 P0-13 유지) |
| 프롬프트 칩이 입력한 지시문을 덮어씀 | 칩은 커서 위치에 덧붙이고 되돌릴 수 있게 |
| 복제 창을 여는 즉시 마이크 권한 요청 | 녹음 버튼을 누를 때만 요청(기존 원칙) |
| `편집` 확인 한 번으로 전체 과금 생성 | 과금 동작은 예상 사용량과 대상 문단 수를 보여 주는 생성 확인에서만 |
| 문단 삭제에 확인·되돌리기 없음, 일괄 삭제 없음 | 삭제 후 되돌리기 알림, 선택 문단 일괄 삭제 |
| 가져오기 성우 배정 17명 고정 목록, 화자 이름이 성우 이름이어도 자동 연결 안 됨, 역할 창 상태 불일치 | 전체 성우 선택 창을 재사용하고 역할↔문단 성우를 한 상태로 관리 |
| 빈 도움말 창, 도움말과 실제 기능 불일치 | 도움말은 실제 동작 설명만, 빈 상태 없이 |
| 클릭 가능한 `span`, 17~25px 터치 대상 | `button`, 44px 터치 대상, 모바일에서도 일괄 작업·요약 접근 |
| 인증 토큰과 즐겨찾기를 브라우저 저장소에 보관 | 세션은 Better Auth 쿠키, 개인 데이터는 서버 DB |
| “100% 오류 없이”, “1ms 오차 없는” 같은 과장 문구 | 검증한 수치만 표시 |

## 우리 서비스 반영 결정

HTML 프로토타입에는 아래를 **UI/UX 설계로 먼저 배치**하고, 실제 기능은 `tasks/todo.md`의 항목으로 추적한다. 반영 경로와 TODO ID는 [HTML 반영 기록](#html-반영-기록)에 적는다.

1. 문단 카드: 예상 길이, 사용량 추정, 성우 빠른 메뉴(사용 중·최근), 역할 배지 → 역할 일괄 변경, 문단별 감정 프리셋 강도·직접 지시문, 연기 지시 칩, 문단별 추천, 이동·삭제 되돌리기.
2. 일괄 작업 막대: 선택 수, 전체 선택, 성우·간격·속도 일괄 변경, 분할(기준 선택 + 직접 자르기 편집기), 합치기 확인, 선택 삭제.
3. 화자 자동 감지와 붙여넣기 분할, 역할별 성우 창의 진행도.
4. 성우 선택 창의 패싯(공급자·언어·성별·연령·용도), 정렬(최근 사용·즐겨찾기), 목소리 ID 검색.
5. 복제의 녹음 가이드(추천 대사·예상 시간·장치·입력 레벨), 기존 Voice ID 연결, 슬롯·보관 안내.
6. 보이스 디자인 도구(설명 기반 새 성우, 사용량 사전 표시).
7. 하단 생성 바: 예상 사용량을 붙인 생성 버튼, 마스터 재생(이전/다음 문단), 다운로드 형식 선택, 생성 후 편집 진입.
8. 프로젝트 보관함, 새로고침 복구 창, 초기화 선택지, 작업 요약 카드, 사용 내역.
9. 첫 사용 둘러보기와 도구별 짧은 도움말.
