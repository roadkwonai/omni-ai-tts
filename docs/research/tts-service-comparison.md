# Typecast·Vrew·ElevenLabs 공식 서비스 조사

조사일: **2026-09-26, Asia/Seoul**. 요청 유형: 공개 제품 사용법과 UI 참조 조사. 기준 문서는 [기존 참고 조사](./tts-references.md)와 [작업실 브리프](../briefs/tts-studio.md)다. 이 문서는 공식 기능의 관찰 사실과 우리 제품에 적용할 제안을 분리한다.

## 조사 범위와 증거 수준

- **공식 가이드**: 운영사가 공개한 제품 문서·도움말·기능 소개를 읽었다. 로그인, 가입, 생성, 업로드, 다운로드 결제는 실행하지 않았다.
- **공식 이미지 직접 관찰**: 운영사 가이드에 포함된 이미지 파일을 열어 화면의 배치와 문구를 확인했다. 현재 로그인 에디터를 조작한 증거는 아니다.
- **직접 조작**: 이 조사에서는 없음. 실제 생성 품질, 대기 시간, 샘플의 청취 품질, 키보드 동작과 오류 복구는 미검증이다.
- **미확인**: 문서에서 찾지 못했거나 접근에 실패한 항목. 기능이 없다는 뜻은 아니다.

서비스별 핵심 가이드와 필요한 API 경계 문서를 확인한 뒤 수집을 종료했다. Vrew 공식 홈페이지가 연결하는 `vrew.imweb.me/tutorial`과 일부 FAQ는 HTTP 403으로 접근하지 못해 같은 운영사의 기능 페이지·블로그를 대체 근거로 사용했다. Typecast 일부 도움말과 API 문서는 웹 검색 도구가 읽지 못했지만 공식 URL의 공개 HTML을 직접 가져와 확인했다.

## 핵심 결론

**우리 P0는 개인 제작자의 ‘익숙한 성우로 대본을 고쳐 다시 생성하는 작업’에 맞춘다.** 성우 검색→샘플→선택, 원문→읽는 글 검수, 공급자별 설정, 생성 결과의 재생·다운로드, 본인 클론 생성·재사용에 집중한다. 아래 우선순위는 공식 서비스의 분류가 아닌 제품 설계 제안이다.

| 참고할 방식 | P0에 주는 시사점 | 복잡도를 늘리는 부분 |
|---|---|---|
| Typecast의 대본·감정 중심 작업 | 선택한 대본과 적용할 감정을 가까이 배치 | 감정 적용·미리듣기·다운로드의 과금 조건을 API와 혼동하기 쉬움 |
| Vrew의 텍스트와 성우 선택 중심 편집 | 글을 고친 후 결과를 확인하는 짧은 반복, 보관한 성우로 빠른 복귀 | 영상·이미지·자막·음악까지 한 화면에 들어가면 음성 제작이 묻힘 |
| ElevenLabs의 성우 보관함과 생성 이력 | 성우 재사용, 결과별 입력·설정 기록, 이전 결과 비교 | 모델별 설정 차이, 대규모 탐색 필터, 문단·프로젝트 설정의 적용 범위 |

초기 사용자는 개인 한 명이다. 공개 가입·결제·팀·워크스페이스 공유는 **P4**에 둔다. 향후 확장을 위한 `userId` 소유권과 공급자 어댑터의 최소 경계만 유지한다. 이는 사용자 요구이며, 참고 서비스의 조직·마켓플레이스 구조를 복제할 이유가 되지 않는다.

## 1. Typecast: 대본과 감정, 새 에디터 기준

### 공식 가이드 근거

도움말은 [새 에디터와 클래식 에디터](https://help.typecast.ai/ko)를 별도 컬렉션으로 관리한다. 아래는 새 에디터 기준이다. 2026-06~07월 갱신 문서를 우선 확인했고 클래식 에디터의 조작법을 섞지 않았다.

| 작업 | 확인한 흐름 | 증거 |
|---|---|---|
| 진입·대본 | 프로젝트 생성 후 직접 입력·붙여넣기, 단락 추가, 주기적 자동 저장. 최초 보이스는 임의 선택된다고 안내 | [보이스 추가](https://help.typecast.ai/ko/articles/15347211-보이스-추가), 2026-07-06, 공식 가이드 |

추가 탐색 근거인 [새 프로젝트 만들기](https://help.typecast.ai/en/articles/15347151-create-a-new-project)는 제목·언어 선택과 저장 프로젝트 재열기를, [대본 가져오기](https://help.typecast.ai/en/articles/15509592-import-script)는 붙여넣기/TXT→화자 탐지→보이스 배정을 설명한다. 둘 다 2026-07-15 가이드이며 다중 화자 가져오기는 P0 필수로 확대하지 않는다.

### 공식 이미지에서 본 것

[클론 설정 이미지가 포함된 가이드](https://help.typecast.ai/ko/articles/15360329-클론-만들기)를 직접 열었다. 세로 한 열의 폼에 이름, 성별, 녹음 언어, 이미지 업로드, 동의 문구, 마지막 생성 버튼이 있다. 필수 항목 표시와 동의 위치가 분명하다. **이미지 업로드나 성별 선택은 Studio 폼의 관찰 사실이며 API의 필수 입력이라고 간주하지 않는다.**

우리 클론 폼에서는 생성에 필요한 이름·공급자·녹음부터 보여 주고, 아바타 이미지 등 꾸미기 입력은 뒤로 미루는 편이 적절하다. 최초 성우를 임의 배정하는 방식도 그대로 가져오기보다 마지막 사용 성우나 채널 기본값을 사용하고 선택 상태를 명시하는 것을 제안한다.

### 웹과 API의 경계

- Studio의 감정 강도 UI가 API에서 그대로 제공된다는 뜻은 아니다. [TTS API](https://typecast.ai/docs/api-reference/text-to-speech/text-to-speech)는 모델·보이스에 맞는 감정, 볼륨, 피치, 템포 옵션을 설명한다. 지원 옵션과 범위는 API 계약으로 결정해야 한다.
- Studio 퀵 클론 가이드는 약 1분의 녹음을 안내하지만, [Instant Clone API](https://typecast.ai/docs/api-reference/custom-voices/create-instant-clone)는 WAV/MP3 한 파일, 25 MiB 이하, 5~150초를 명시한다. Studio 안내를 API 업로드 제한에 대입하지 않는다.
- 새 에디터 조사에서 독립적인 한국어 발음 사전 UI는 확인하지 못했다. [AutoTag](https://typecast.ai/docs/bestpractice/autotag)는 기존 조사에서 확인한 한국어 숫자 전처리 후보이며 Studio 발음 사전이나 TTS API의 보편적 SSML 지원을 뜻하지 않는다. 이번 작업에서 도입하지 않는다.
- 성우 검색·즐겨찾기·샘플 클릭의 새 에디터 실제 동작은 미확인이다. API 목록·샘플 범위는 [기존 API 조사](./tts-references.md)를 따른다.

[공식 TTS 블로그](https://vrew.ai/ko/blog/all/tts-ai-voice/)의 [AI 목소리 설정 이미지](https://cdn.sanity.io/images/npl3ondx/production/950d113334f2b8dc2b3a11170410d11e420dd27f-1770x1492.png)를 직접 확인했다.

- 상단에 내 목소리·전체·추천·즐겨찾기 탭과 검색이 있다.
- 왼쪽에 태그·언어·성별·연령 필터, 가운데에 이름·이미지·분위기 태그가 있는 성우 카드가 놓인다.

**좋은 점이라는 해석:** 목록을 이동해도 선택 성우와 시험 문장을 계속 확인할 수 있다. **복잡하다는 해석:** 언어·성별·연령·태그와 개별 성우 설정이 한 다이얼로그에 모여 세로 스크롤이 길어진다. 우리 P0에서는 즐겨찾기·한국어·공급자 중심으로 먼저 좁히고 나머지 필터를 접는 방식을 제안한다. 이미지의 아이콘은 보았지만 클릭 결과·과금 여부는 확인하지 않았다.

### 확인 한계와 범위

Vrew 공개 홈페이지의 다운로드 버전 표시는 조회 시 4.6.2였으나, 검색 색인에는 4.5.1이 남아 있었다. 블로그 스크린샷에는 빌드 번호가 없어 최신 앱과 동일하다고 단정하지 않는다. 제품 페이지·블로그의 성우 수 표현도 서로 달라 수량을 앱 요구사항으로 가져오지 않는다. [공식 홈페이지](https://vrew.ai/ko/)

독립 발음 사전, 클론 실패·삭제·검증 상태, 저장 프로젝트 재개 세부 조작, 내보내기 코덱과 과금 시점은 이번 공개 자료로 확정하지 못했다. 공개 TTS·클론 API도 조사 범위에서 확인하지 못했으며, **Vrew는 UI 참조 서비스이지 우리 P0 음성 공급자가 아니다.** 웹 체험과 데스크톱 앱 기능이 완전히 같다는 주장도 하지 않는다.

| IVC 권장 입력 | [IVC 가이드](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/instant-voice-cloning)는 깨끗하고 일관된 1~2분 녹음을 권장 | ‘권장 길이’와 API의 업로드 강제 제한을 구분 |
| IVC API 응답 | [Create IVC voice](https://elevenlabs.io/docs/api-reference/voices/ivc/create)는 `voice_id` 및 `requires_verification` 반환 | ID 수신만으로 사용 가능 표시 금지. 검증 필요 상태와 후속 행동이 필요 |
| 재생·다시 생성 | [Studio 가이드](https://elevenlabs.io/docs/eleven-creative/products/studio)의 Play는 미생성 문단을 생성할 수 있고, 제한적인 무료 재생성 정책도 설명 | 웹 Studio의 무료 재시도를 API 정책으로 가져오지 않는다. P0 ‘듣기’ 버튼은 기존 파일 재생만 수행하도록 제안 |

보관함에 저장한 외부 성우도 공급자에서 사용 중단될 수 있다. [Voice Library](https://elevenlabs.io/docs/eleven-creative/voices/voice-library)의 notice period 설명을 근거로, 프리셋의 성우가 사라진 경우 다른 성우를 고르게 하되 기존 생성물과 설정 기록은 계속 식별할 수 있어야 한다.

## 4. P0 채택·후속·배제 제안

다음은 위 관찰을 바탕으로 코디네이터에게 전달하는 UX 제안이며 최종 화면·구현 결정은 아니다.

| 동작 | P0 채택 | 후속 | 초기 배제 이유 |
|---|---|---|---|
| 진입 | 마지막 작업/채널 프리셋에서 곧바로 대본으로 | 프로젝트 템플릿 | 서비스 소개 대시보드와 온보딩 투어는 반복 작업에 불필요 |
| 성우 탐색 | 공급자·검색·한국어·즐겨찾기, 현재 성우 고정 | 유사 음성 검색·추천·다중 비교 | 거대한 마켓플레이스와 제작자 수익화는 목적 밖 |
| 청취 | 기본 샘플과 생성 결과의 재생을 분리 | 선택 문장 시험 생성 | 재생 클릭의 숨은 생성·과금은 채택하지 않음 |
| 대본 | 직접 입력·저장·불러오기·복제·저장 상태 | 파일 가져오기·다중 화자 | 장편 챕터/타임라인이 기본 대본 영역을 차지하지 않음 |
| 발음 | 숫자·날짜·금액 등 읽는 글 검수, 원문/제안/직접 수정·되돌리기 | 공급자 발음 사전·IPA·전문 용어 사전 | ‘모든 한국어 정확 발음’ 약속이나 무검수 자동 치환 금지 |
| 설정 | 지원 모델·성우에 맞는 설정만, 적용 범위 명시 | 구간별 세부 연기·Actor Mode | 다른 공급자의 설정을 같은 의미로 억지 통합하지 않음 |
| 생성 | 요청 전 최종 대본·성우·설정·사용량 근거 확인 | 문단 선택 재생성·일괄 생성 | 임의 진행률·무조건 무료 재시도·자동 중복 제출 제외 |
| 결과 | 플레이어·형식·다운로드·입력 스냅샷, 수정 후 이전 결과 표시 | 파형·무음 압축·자막·다중 결과 비교 | 다운로드를 새로운 TTS 요청으로 숨기지 않음 |
| 내 클론 | 공급자→녹음/파일→원본 확인→명시적 생성→상태→시험 생성→사용 | 전문 클론·대량 샘플 관리 | 타인 보이스 마켓·공유·수익화 제외 |
| 재사용 | 대본·성우·채널·프리셋, 변경 영향 미리 보기 | 고급 컬렉션·배치 관리 | 운영자가 없는 개인 앱에 팀 관리 구조를 선도입하지 않음 |
| 서비스 운영 | 개인 데이터 소유권과 공급자 연결 상태 | 공개 가입·결제·팀은 P4 | 초기 제작 작업과 분리 |

## 5. HTML 설계에 넘길 상태와 동작

1. **성우 행:** 이름·공급자·핵심 특성·샘플 재생·즐겨찾기·선택 상태. 샘플 없음/접근 불가/사용 중단을 서로 구분한다. 성우 변경이 대본을 지우지 않게 한다.
2. **대본:** 원문과 읽는 글을 식별하고 교정 검수 중 변경 개수·선택 항목·되돌리기를 표시한다. 제안 적용 전후와 실제 생성에 쓰일 글이 무엇인지 분명해야 한다.
3. **설정:** 모델을 바꾸면 지원되지 않는 설정을 제거하거나 재선택을 안내한다. 프리셋 적용은 바뀔 항목을 보여 준다. ‘기본값’과 개인이 저장한 값을 구분한다.
4. **생성 결과:** 생성 시점의 대본·성우·설정을 묶어 남긴다. 편집 뒤 기존 결과에는 ‘이전 대본으로 생성됨’을 표시한다. 재생/다운로드/새로 생성은 독립 행동이다.
5. **클론:** 원본 청취와 합성 시험 청취를 분리한다. 업로드와 처리 상태를 구분하고 검증 필요·실패·처리 여부 미확인·삭제 중 상태를 설계한다. 제공사 문서로 확인된 조건만 입력 제약에 사용한다.
6. **개인용 초기 상태:** 팀 선택기·멤버 초대·구독 판매·공개 가입 CTA 대신 최근 대본, 즐겨찾기 성우, 내 클론, 자주 쓰는 프리셋을 가까이 둔다.

## 6. 버전·불확실성·후속 확인

- 공식 웹 문서는 고정 버전이 아니며 2026-09-26 조회 결과다. Typecast는 새 에디터, Vrew는 공식 공개 소개 이미지, ElevenLabs는 현재 문서 기준이다. 계정별 기능 노출은 확인하지 않았다.
- ElevenLabs TTS 가이드는 SSML phoneme을 Flash v2/Turbo v2로 설명하지만 Best practices는 Flash v2만 명시한다. v3 IPA는 별도 기능으로 설명된다. 구현 전 사용할 모델의 실제 계약·한국어 결과를 재검증해야 한다. [TTS 가이드](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech), [Best practices](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)
- Typecast Studio와 API의 클론 명칭·녹음 조건·구독 권한을 혼합하지 않는다. 기존 조사에 남은 모델·경로 충돌도 [기존 참고 조사](./tts-references.md)의 미확인 항목으로 유지한다.
- API 키가 연결된 실제 계정에서의 성우 접근권한, 샘플 URL 수명, 모델별 옵션, 출력 형식, 클론 검증·삭제 완료 판단은 아직 확인하지 않았다. 이번 조사에서 비용이 드는 검증은 하지 않았다.
- 공식 이미지의 화면 구조는 시각 참고용이다. 반응형·접근성·실제 처리 상태는 우리 HTML과 앱에서 별도로 검증해야 한다.

**재사용 가능한 요약:** 성우 탐색과 청취를 가깝게, 대본 수정과 생성 상태를 명확하게, 개인이 쓰던 재료로 돌아가는 경로를 짧게 만든다. Studio의 UI·과금 정책과 API의 지원 계약을 분리하고, 공급자·모델에서 확인된 기능만 노출한다.
