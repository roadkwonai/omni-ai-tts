# T17 검증 계획

- origin 검증과 세션 파일 권한, 갱신과 로그아웃 경합을 단위 테스트한다.
- 설치된 CLI를 별도 프로세스로 실행해 도움말, JSON 출력, 오류 코드와 인증 없는 요청을 확인한다.
- 로컬 HTTP 서버에서 Better Auth 및 oRPC 경계를 확인하고 데모의 인증 404를 검증한다.
- 실제 공급자 호출은 사용하지 않는다.

## 실행 결과

- `pnpm --filter @tts-pilot-app/cli test` — 주소, 느슨한 세션 디렉터리 권한 거절, 강제 종료 후 잠금 재획득, 데모 거절, 늦은 갱신과 로그아웃 경합을 확인했다. 별도 CLI 프로세스에서 도움말·입력 오류·사람용 목록·JSON·공급자 필터도 확인했다.
- 기존 Better Auth 설정과 oRPC 라우터를 연결한 로컬 HTTP 서버 및 마이그레이션을 적용한 임시 PostgreSQL 16에서 검증했다. 별도 프로젝트에 `pnpm link`로 설치한 명령으로 합성 테스트 계정에 로그인한 뒤 상태, 동명이인 성우 두 명, 즐겨찾기·채널 필터, 로그아웃 후 조회 거절을 확인했다. 비소유자는 보호 조회에서 거절됐다.
- 빠른 터미널 입력에서 암호가 반향되던 문제를 재현하고 수정했다. 빠른 입력을 다시 실행했을 때 합성 암호가 터미널 출력에 나타나지 않았다. 임시 DB는 확인 뒤 종료했다.
